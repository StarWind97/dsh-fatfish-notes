## 留下有用的内容

肥鱼笔记把会话、文字、图片和文件放在一起，保存在本机，并通过你的专用 GitHub 私有仓库同步。

这本手册只有三篇，可以像普通笔记一样修改、移动或删除。删除后可从设置中的用户手册入口重新添加。

## 从这里开始

1. 点击 **新建笔记**，填写标题，在正文中直接输入或粘贴 Markdown。
2. 用工具栏添加标题、列表、链接、表格和代码块。草稿会自动保存在本机，点击 **完成编辑** 写入正式笔记。
3. 按用途分到笔记本，按需添加标签或摘要。

> **保存与同步是两件事。** 草稿保存在本机，正式保存后才会参与同步。离线时可以继续编辑，联网后再同步。

## 找到并整理

想找一份曾保存的文件，在「搜索笔记或附件名」输入记得的词，例如 `交付检查清单.md`。可以先从「全部笔记」搜索，也可以先选笔记本。

结果太多时，点搜索框旁的「筛选笔记」，选一个标签、修改时间或「有附件」。标签太多就点「查看全部」。结果显示正文片段时，点击即可跳到原句。

### 整理全库标签

例如，已经有「交付」和「项目交付」两个名字，想以后都用「交付」。打开 **「分类管理 → 标签」**，选择「项目交付」，点「合并」，查找并选择要保留的「交付」。确认前，查看受影响的笔记数量，并点开几篇核对正文。改名与移除也可先查看影响范围。

| 想做什么 | 在哪里操作 |
| --- | --- |
| 集中查看重要笔记 | 点击星标，在「全部笔记」下方进入「收藏」 |
| 让常用笔记排在前面 | 条目或正文的更多菜单 → 置顶笔记 |
| 调整笔记本次序 | 拖动笔记本，或在菜单中上移、下移 |
| 一起整理多篇笔记 | 开启多选后，点击条目任意位置选择 |
| 查看之前保存的内容 | 正文更多菜单 → 历史版本 |
