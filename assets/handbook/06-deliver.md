写完以后，可以留给自己继续修改，也可以整理成适合别人阅读的版本。先确定用途，再选择导出方式。

## 让阅读舒服一点

在外观设置中选择合适的界面布局、配色和阅读样式。功能区域可以跟随 DSH；正文则按自己的阅读习惯调整字体、字号与行距。代码默认使用 Regular 字重，也可以调节。

舒适宽度适合连续文字，全宽适合较宽的表格和资料。目录与资料面板用于随时查找，资料区可以放在底部或右侧。

阅读区域获得焦点后，可用 **Home / End** 跳到开头或结尾，用 **Page Up / Page Down** 翻页。编辑文字时仍按编辑器本身的键盘规则操作。

## 保存与同步是两件事

首次使用先接入专用的私有 GitHub 仓库，并完成首次同步。之后可以离线编辑与保存，重新联网后再同步。

“已保存到本机”说明本机已有记录；同步状态说明远端备份是否完成。需要换设备或交付重要内容时，再确认同步状态，而不是仅凭文字出现在页面上判断。

## 选一个合适的交付形式

| 需要做什么 | 选择 |
| --- | --- |
| 把阅读效果发给别人快速看 | 图片，一张 PNG |
| 交付便于打印、翻页的文档 | PDF |
| 保留可继续整理的正文 | Markdown |
| 连同图片、文件原件一起交付 | Markdown 资源包 |

图片导出可以沿用当前目标笔记的阅读宽度，**包括全宽**，也可以选择默认或预设宽度。目标没有正在显示时，会使用明确标注的默认宽度。更高的清晰度提高像素密度，不改变正文排版宽度。

图片和 PDF 中的文件卡片用于说明资料，不包含文件原件；需要原件时选资源包。发起下载后弹窗关闭并轻提示；若生成失败，参数会保留，生成中也可以取消。

## 发出去之前

- [ ] 标题能让收件人理解内容
- [ ] 图片清楚，代码与表格没有遗漏
- [ ] 需要的附件已包含在资源包里
- [ ] 下载后的实际文件已打开检查

这篇手册可以像普通笔记一样修改或删除。以后在设置中打开“用户手册”；整册移除后也可以主动添加新的副本，系统不会用更新覆盖你的修改。
