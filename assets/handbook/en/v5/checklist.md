# Project handoff checklist

Use this when handing a project guide to someone new to the project.

- [ ] Describe the purpose, readers and maintainer
- [ ] Check the repository, preview and help links
- [ ] Follow the instructions from a clean working directory
- [ ] List the environment requirements without credentials or personal settings
- [ ] List unfinished work and known limitations
- [ ] Check examples, screenshots and attachments
- [ ] Record preview, save, commit and release status separately
- [ ] Ask a reader which step needed the most clarification

Record the content version, review date, reviewer and any follow-up.
