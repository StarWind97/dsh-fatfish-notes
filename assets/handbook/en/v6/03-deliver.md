## Save locally and check sync

On first use, connect a dedicated private GitHub repository and finish the initial sync. After that, you can read, edit and save offline. Sync resumes when the connection returns.

- While editing, the draft stays on this device.
- Finishing an edit saves the note locally and queues it for sync.
- A synced note has been backed up to the private repository.
- If sync fails, check **Settings → Sync and storage**, then retry. Your local save is available while you resolve the issue.

Concurrent edits on different devices can create multiple versions. Review them before choosing one or saving a merged copy.

## Set up a comfortable reading space

Use **Settings** to choose a layout, palette, font size and line height. DSH supplies the default theme. The code font is bundled. If a selected text font isn't installed, the system uses a fallback.

Place the materials panel below or beside the text. The paperclip shows the number of supplemental files and the link icon shows how many notes link here. Open the panel and pin it if you want it to stay in view. Use the outline to jump between headings; when a note has no headings, the outline collapses automatically and can be opened from the edge handle or the toolbar button.

With the note focused, use **Home**, **End**, **Page Up** and **Page Down** to read. In the main page and separate window, **+** opens the overview. Drag notes' tabs to reorder them or right-click to close one, the others or all tabs. In a conversation sidebar, use the back arrow in the note header or the **Note list** tab to return to your previous search.

## Keep your library tidy

- Restore notes from **Trash** while they are still there. Review the selection before deleting anything permanently.
- Keep access tokens, passwords and keys in a credential manager.
- Layout and fonts are local preferences. Notes, attachments, pinned status and notebook order sync.
- Duplicate a note to start with a copy of its contents.
- To report a problem or suggest an improvement, open **Settings → Help** and use **Issues & suggestions**.
