## Keep what you want to return to

Fatfish Notes keeps conversations, text, pictures and files together. Notes are saved on your device and synced through your dedicated private GitHub repository.

This handbook has three chapters. You can edit, move or delete them like any other notes. Open **Settings → Help** to reopen existing handbook chapters for the active language; the option to add a fresh copy appears only when none remain.

## Write your first note

1. Click **+ New** at the top of the note list, enter a title, then type or paste Markdown in the body.
2. Use the toolbar for headings, lists, links, tables and code blocks. While editing, click **Edit details** below the title whenever you want to change the notebook or add tags and a summary.
3. Your draft is saved locally. Click **Done editing** to save it as a note.

> Saving and syncing happen separately. You can keep editing while offline. Saved notes sync when the connection returns.

## Find and organize your notes

Enter a word or filename, such as `Project handoff checklist.md`, in the search box. Search all notes or choose a notebook first. Switch between **All**, **Favorites** and **Recent** in the list toolbar (**Recent** tracks notes opened in this local browser on this device). Use filters for tags, modification time or attachments. Click a text match to jump to the original passage.

In the main view or separate window, press **Alt+K** (**⌥K** on macOS) or click the quick switcher in the top bar to search note titles, body text, attachment names, notebooks, tags and common actions in one place.

To consolidate tags such as `handoff` and `project-handoff`, open **Organize → Tags**. Select the source tag, choose **Merge**, then look up the tag to keep. Review the affected notes before confirming. The same view previews renames and removals.

| To do this | Use this control |
| --- | --- |
| Jump to a note, tag or action | Press **Alt+K** (**⌥K** on macOS) or use the top-bar quick switcher |
| Keep important or recent notes handy | Star notes for **Favorites**, or switch to **Recent** (local browser history) |
| Keep a note near the top of its list | Choose **Pin note** in its menu |
| Change notebook order | Drag a notebook or use **Move up** and **Move down** |
| Organize several notes | Enable selection and click anywhere in each row |
| See an earlier save | Open **Version history** from the note menu |
