## Put images and files where they belong

Pasted screenshots and images added on their own appear inline by default. Images added together with other file types appear as download links. Use the image menu to switch between an inline image and its download link.

Drag a file into the body to keep it next to the relevant paragraph. Keep related files that don't belong in the body under **Supplemental files**. Try downloading the [project handoff checklist](handbook-file:checklist) and opening the CSV file in the materials panel.

## Save a conversation

If a conversation helped you figure out why an uploaded image didn't appear, save the useful exchanges and add your verification results later.

1. Click **Save to notes** below a completed reply. Select the turns to keep and click **Next**.
2. In **Save options**, review the selected messages, images and files and choose a notebook. Available images show thumbnails directly. A wide window shows the three sections side by side; in a narrow window, use **Expand layout** to show all three. Your selection and text carry across layouts.
3. Keep the prefilled conversation title or type a title you can find later. **AI suggestions** uses the selected message text to suggest a title, summary and tags. Click **Save to notes** when ready, or **Cancel** at the bottom to exit capture.

Edit the resulting note as usual. **Original material** shows the source messages and materials. The save dialog reports files it can't retrieve.

## Export what you need

| Format | Use it for |
| --- | --- |
| Image | Share a single PNG at the current or preset reading width |
| PDF | Send or print a paginated document |
| Markdown bundle | Keep an editable copy with the selected original files |

Use the Markdown bundle or individual file downloads when you need the original attachments. The export window closes once the download starts. You can cancel while it generates or retry with the same options after a failure.
