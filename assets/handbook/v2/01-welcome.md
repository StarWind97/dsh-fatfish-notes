## 留下有用的内容

肥鱼笔记把会话、文字、图片和文件放在一起，保存在本机，并通过你的专用 GitHub 私有仓库同步。

这本手册只有三篇，可以像普通笔记一样修改、移动或删除。删除后不会自动补回；需要时可从设置中的用户手册入口重新添加。

## 从这里开始

1. 点击 **新建笔记**，填写标题，在正文中直接输入或粘贴 Markdown。
2. 用工具栏添加标题、列表、链接、表格和代码块。编辑中的草稿会自动保存在本机；点击 **完成编辑**，写入正式笔记。
3. 按用途分到笔记本，按需要添加标签或摘要。搜索框能查标题、正文和标签。

> **保存与同步是两件事。** 草稿保存在本机；正式保存后的笔记才会参与备份。离线时可以继续编辑，恢复联网后再同步。

## 找到并整理

| 想做什么 | 在哪里操作 |
| --- | --- |
| 集中查看重要笔记 | 点击星标，在“全部笔记”下方进入“收藏” |
| 让常用笔记排在前面 | 条目或正文的更多菜单 → 置顶笔记 |
| 调整笔记本次序 | 拖动笔记本，或在菜单中上移、下移 |
| 一起整理多篇笔记 | 开启多选后，点击条目任意位置选择 |
| 查看之前保存的内容 | 正文更多菜单 → 历史版本 |

收藏用于集中查看，置顶用于排列，两者可以同时使用。顶部标签保留本次打开的笔记；关闭标签不会删除笔记，退出后不恢复这些标签。
