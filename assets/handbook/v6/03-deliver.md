## 先保存，再看同步状态

首次使用需要连接专用 GitHub 私有仓库并完成首次同步。此后，断网不影响本机阅读、编辑和保存；网络恢复后会继续同步。

- **编辑中**：草稿留在当前设备。完成编辑后，正式笔记进入同步队列。
- **已同步**：本次正式保存已备份到私有仓库。
- **同步失败**：先查看设置中的原因，再重试；本机已保存内容仍保留。

同时在两台设备修改同一篇笔记时，可能出现并发版本。先核对各版本内容，再决定保留或合并。

## 让阅读更顺手

设置中可以分别调整界面布局、配色、中文与西文字体、字号和行高。默认配色与明暗跟随 DSH；代码字体随插件提供，无需另行安装。选择本机没有的正文字体时会使用回退字体。

资料区可放在底部或右侧：回形针旁是补充附件数，链接旁是引用本篇的笔记数。展开后可固定；未固定时点击外部即可收起。目录用来跳转章节；正文没有章节标题时目录列会自动收起，需要时可从边缘手柄或顶栏目录按钮展开。

正文获得焦点后，可以使用 **Home / End / Page Up / Page Down** 阅读。在主界面和独立窗口，标签栏末尾的「+」可打开概览，再选一篇最近的笔记。可以拖动笔记标签调整次序，右键可关闭当前、其他或所有标签。关闭的笔记仍可从列表找回。

在会话侧栏，用正文头部的返回箭头或「笔记列表」标签回到列表，继续刚才的查找。

## 需要留意

- 回收站中的笔记可以恢复；彻底删除前请确认是否仍有需要的内容。
- 私有仓库用于备份，不是密码保险箱。不要保存访问令牌、密钥等凭据。
- 布局和字体是本机偏好；正文、附件、置顶和笔记本手工顺序随仓库同步。
- 笔记可以直接复制为副本；插件不提供模板机制。
- 遇到问题或有功能建议，可在 **「设置 → 帮助」** 点击「问题与建议」前往反馈。
