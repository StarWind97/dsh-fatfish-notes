## 图片放在需要的位置

截图粘贴、单独添加一张或多张图片时，默认在正文中展示；图片与其他文件一起添加时，默认显示下载链接。正文中的图片可在“图片展示”和“下载链接”之间切换。

文件可以拖入正文，放在相关段落旁；暂时不属于某一段的资料可以放进补充附件区。

下载示例：[交付检查清单](handbook-file:checklist)。下方资料区另有一份小型 CSV 文件，可以试着展开并下载。

## 把会话留下来

例如，与 AI 一起排查“文件上传后没有显示”的问题，可以选中排查过程和结论，保存到笔记后再补上验证结果。

1. 点已完成回答下方的 **「保存到笔记」**，在会话中勾选要保留的轮次，再点 **「下一步」**。
2. 在「保存选项」核对消息、图片与文件，并选择笔记本。可用图片会直接显示缩略图；宽窗并排显示三部分，窄窗可用标题栏的「展开布局」展开，切换布局会保留选材和已填内容。
3. 确认预填会话标题，或改成便于查找的名字。需要时点 **「AI 建议」**，根据所选消息的文字生成标题、摘要和标签。最后点 **「保存到笔记」** 保存，或点底部 **「取消」** 退出转存。

转存后可以编辑正文，「原始素材」保留当时的会话记录。无法取得的文件会在保存时提示。

## 阅读与交付

| 导出形式 | 适合用途 |
| --- | --- |
| 图片 | 分享当前笔记的阅读排版；可选当前阅读宽度或预设宽度 |
| PDF | 打印和分页阅读，使用随包字体保证中文可读 |
| Markdown 资源包 | 保留可编辑正文和选中的文件原件 |

图片和 PDF 展示内容或文件卡片，不把附件原件一同打包。需要文件原件时，选择 Markdown 资源包或单独下载。发起下载后弹窗会关闭；失败时保留选项，生成中可以取消。
