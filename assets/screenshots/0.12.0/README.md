# 肥鱼笔记 0.12.0 实拍 / Fatfish Notes 0.12.0 screenshots

每个场景都在 DSH 0.2.2-rc.5 的隔离 Web 中分别以简体中文和英文拍摄。两种语言用同样的窗边工作台照片，演示会话、笔记、文件名和界面按各自语种呈现。图文笔记和深色代码沿用 0.11.1 候选中已显示字数的原图。会话转存、外观设置、图解中的转存选项以及英文标签目录取自 0.12.0 候选。

Each scene was captured in Simplified Chinese and English in an isolated DSH 0.2.2-rc.5 Web profile. Both languages use the same window desk photos, with localized conversation text, notes, filenames and interface labels. The image journal and dark-mode code screenshots come from the 0.11.1 candidate and show the word count. The saved conversation, appearance settings, capture options and English tag directory were captured with the 0.12.0 candidate.
