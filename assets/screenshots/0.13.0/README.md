# 肥鱼笔记 0.13.0 实拍 / Fatfish Notes 0.13.0 screenshots

每个场景均从通过同包核验的 0.13.0 候选在 DSH 0.2.2-rc.5 隔离 Web 中分别以简体中文和英文重新拍摄。两种语言使用相同的窗边工作台演示内容，展示新版工作台（主色 `+ 新建`、全部/收藏/最近分段、`3 px` 选中竖条、胶囊标签与阅读标签栏）、统一顶栏会话侧栏、炭黑深色代码块独立顶栏与圆角表格，以及三套布局、六套配色与同步状态的现代设置页。

Each scene was newly captured from the verified 0.13.0 release candidate in an isolated DSH 0.2.2-rc.5 Web profile in both Simplified Chinese and English.
