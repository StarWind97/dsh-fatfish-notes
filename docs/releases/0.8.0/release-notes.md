# 肥鱼笔记 / Fatfish Notes 0.8.0

私人笔记管理：让笔记与 DSH 会话并行使用，让内容更容易查找、整理和复用。

## 本次更新

- **独立窗口与三栏布局**：可以单独打开笔记，继续在 DSH 会话中工作。宽窗展开笔记本、笔记列表与正文三栏，窄窗自动收起笔记本栏；列宽可调。同篇笔记在两个窗口之间安全交接编辑，不同篇可分别编辑。
- **收藏与查找**：收藏常用笔记、查看本机最近访问；支持多关键词搜索、标题优先、上下文摘要、正文高亮及下一处定位，填写标签时提供已有标签建议。
- **历史与批量整理**：预览历史版本，恢复为新版本或独立副本；复制笔记，多选移动到其他笔记本、添加或移除标签。
- **文章关联与模板**：内部链接先预览，再打开全文；查看引用当前文章的笔记。可将内容保存为独立模板，从模板新建，支持日期和标题变量。
- **响应速度**：减少重复读取历史文件、重复查询和重复渲染。在同一套 83 个笔记对象、282 个修订的 Windows 隔离资料中，笔记本切换中位数从 3.6–5.3 秒降至约 0.16–0.18 秒。实际速度仍受设备和资料规模影响。

会话原样转存、Markdown 图文编辑、自动保存、私库双向同步、附件、导入导出和回收站继续保留。

## 安装与升级

适用于 **DeepSeek Harness 0.2.2-rc.1 / Windows**。安装包为 `dsh-fatfish-notes-0.8.0.tgz`，不要使用自动生成的 Source code 压缩包。按照 README 安装到自己的 DSH profile，安装或升级后重启。

从 0.7.0 升级无需卸载或重新绑定。先确认同步完成，关闭独立笔记窗口及 DSH，保留本机笔记资料夹和 `DSH_HOME/fatfish-notes` 的备份，再安装新版。同一私库的各端应一起升级：新版的收藏和模板等字段旧版不识别，不能直接装回旧版继续使用已更新的资料。

## 使用边界

- 独立窗口目前使用 Windows 上已安装的 Chrome 或 Edge，并依赖 DSH 保持运行；它不是另一个常驻笔记服务。关闭 DSH 后暂停编辑，重启相同资料后重新连接。
- 收藏和模板随私库同步；最近访问保存在当前浏览器资料中，不跨设备同步。模板是独立内容，不随来源笔记的后续编辑而变化。
- 历史恢复会创建新版本，保留恢复前内容。彻底删除仍不重写 Git 历史，不是安全擦除。
- macOS、两台物理设备与大型真实资料库尚未实测。AI 仍仅在会话转存时可选建议标题、摘要和标签；会话侧栏和 AI 正文处理不属于本次更新。

问题与建议可从插件顶部入口提交到 GitHub。
