# Rename DSH Notebook to Fatfish Notes (肥鱼笔记) and update to 0.6.0

Rename the existing `data/plugins/StarWind97__dsh-github-notebook.yml` entry to `data/plugins/StarWind97__dsh-fatfish-notes.yml` and update its product name, repository/icon URLs and release tarball. This is the same project under a new name, not an additional plugin listing. The GitHub repository was renamed in place.

Fatfish Notes saves conversations, edits Markdown notes with images, exports files, and syncs through the user's own private GitHub repository. Version 0.6.0 adds chapter navigation and a system folder picker alongside the new identity.

Supported host: DSH 0.2.1-rc.5. Tested on Windows; macOS has not been verified. Historical 0.5.x releases retain their original package names. The developer's isolated data was migrated once; the new package does not silently adopt the old plugin identity.

Only the existing plugin YAML entry is renamed and updated. Generated README files are unchanged. Repository screenshots and descriptions have been refreshed.
