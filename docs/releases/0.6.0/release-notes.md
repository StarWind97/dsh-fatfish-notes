# 肥鱼笔记 / Fatfish Notes 0.6.0

私人笔记管理：保存会话、编辑图文、导出文件，通过自己的 GitHub 私有仓库在设备间继续工作。

- 产品与安装标识统一更名，安装包为 `dsh-fatfish-notes`；新私人库建议名为 `fatfish-notes`。
- 阅读和编辑都支持章节目录、点击跳转与当前章节高亮；宽窗使用右栏，窄窗使用浮层。
- 正文、列表和目录分别滚动，半透明双箭头可展开或收起目录。
- 首次设置通过系统窗口选择父目录，自动补全与云端库同名的子目录；支持取消和恢复默认，拒绝占用非空本地资料夹。
- 保留自动保存、私库双向同步、会话原样转存、Markdown 图文编辑及 ZIP/PDF/图片导出。

本次是一次性身份整理。开发者既有测试资料已转换；新版不自动读取旧包的控制目录或旧私库标记。历史 0.5.x 包保留原名。

适用于 Windows / DeepSeek Harness 0.2.1-rc.5。macOS 尚未实测。AI 仅在会话转存时可选建议标题、摘要和标签；正文手动编辑。本地 Markdown 导入暂未提供。

下载 `dsh-fatfish-notes-0.6.0.tgz`，按照项目 README 安装；不要使用 Source code 压缩包。首次使用需 Git、GitHub CLI 和自己的 GitHub 账号，初始化页面会提供引导。

问题与建议可从插件顶栏直接前往 GitHub 提交。
