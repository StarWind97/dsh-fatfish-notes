# 肥鱼笔记 / Fatfish Notes 0.10.0

- **全库标签整理。** 从「分类管理」预览受影响的笔记，再改名、合并或移除标签。可按名称搜索标签，在右侧核对正文。
- **统一查找。** 主界面、独立窗口和会话侧栏使用同一套搜索与筛选。可以从全库搜起，也可以先选笔记本。回到会话查找列表时继续原来的搜索。
- **阅读标签。** 并排保留笔记与概览，拖动排序。空间不足时从溢出菜单切换。会话侧栏可通过「笔记列表」回来。

本版已在 DSH 0.2.2-rc.5 的 Windows 桌面与 Web 实测。声明支持 `>=0.2.2-rc.3 <0.2.3-0`。升级插件前先完成同步，再将安装包装入原 DSH 资料并重启。已有手册可继续使用，首次设置的空库和需要补入手册的笔记库使用新版。[图解使用说明](../../user-guide.zh.md) · [实测记录](review.zh.md)

## English

- **Library-wide tag management.** Review the affected notes and their contents before renaming, merging or removing a tag.
- **Consistent search.** Search the whole library or start from a notebook. Search and filters work the same way in the main view, separate window and conversation sidebar.
- **Reading tabs.** Keep notes and overviews side by side, reorder tabs by dragging, and return to your results from the sidebar's note list.

This release was verified on DSH 0.2.2-rc.5 for Windows Desktop and Web and declares support for DSH `>=0.2.2-rc.3 <0.2.3-0`. Finish syncing, install the package in the same DSH profile, and restart DSH.
