# 肥鱼笔记 / Fatfish Notes 0.12.0

- 笔记主界面、会话侧栏、转存、设置和独立窗口都跟随 DSH 的简体中文或英文。新增转存正文与导出的系统标签采用操作时的语言。
- 随包补齐英文用户手册。首次初始化空库按选择的语言提供手册，已有库可从「设置 → 帮助」打开或添加对应语言的手册。
- 中英文说明提供同场景的独立实拍，英文新增图解和详细操作参考。[中文图解](../../user-guide.zh.md) · [验收记录](review.zh.md)

声明支持 DSH `>=0.2.2-rc.3 <0.2.3-0`。先完成同步，在原有 DSH 资料安装版本包，然后重新启动。

## English

- The main notebook view, sidebar, capture, settings and separate window follow Simplified Chinese or English in DSH. New captures and exports use the selected language for generated labels.
- The bundled handbook is available in English. New empty libraries get the handbook for their selected language. Open or add that edition through **Settings → Help** in existing libraries.
- The English README and guide show English screenshots of the same workflows as the Chinese versions. [Illustrated guide](../../user-guide.en.md) · [Detailed reference](../../user-guide-reference.en.md)

Fatfish Notes declares support for DSH `>=0.2.2-rc.3 <0.2.3-0`. Finish syncing, install the package into the same DSH profile, and restart DSH.
