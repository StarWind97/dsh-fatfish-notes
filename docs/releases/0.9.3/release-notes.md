# 肥鱼笔记 / Fatfish Notes 0.9.3

现在可以按关键词或附件名找笔记，叠加笔记本、标签和时间等条件。点带正文片段的结果，可直接跳到原句。概览汇集最近打开和最近修改的笔记。[图解使用说明](https://github.com/StarWind97/dsh-fatfish-notes/blob/v0.9.3/docs/user-guide.zh.md)

声明支持 DSH `>=0.2.2-rc.3 <0.2.3-0`。本版验证了 rc.5 Windows 桌面与 rc.4、rc.5 Web。完成同步后，在原 DSH 资料中安装 `dsh-fatfish-notes-0.9.3.tgz` 并重启即可升级。[验证记录](https://github.com/StarWind97/dsh-fatfish-notes/blob/v0.9.3/docs/releases/0.9.3/review.zh.md)

## English

Find notes by text or attachment name, combine notebook, tag and date filters, and jump straight to a matching passage. The overview brings recently opened and recently edited notes together.

The declared DSH range is `>=0.2.2-rc.3 <0.2.3-0`. This release was verified on rc.5 Windows Desktop and rc.4 and rc.5 Web. To upgrade, finish syncing, install the `.tgz` in the same DSH profile and restart DSH.
