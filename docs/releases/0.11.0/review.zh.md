## 初次候选与基线

- 本地候选版本为 `0.11.0`。固定名 `dsh-fatfish-notes.tgz` 与带版本名的 `dsh-fatfish-notes-0.11.0.tgz` 逐字节一致。262 个包内文件，SHA-256 为 `6c0dc31894bd1f98290d96bce2b7a97131343e77078c379fef8a534d9119106c`。三份本地产物位于 `dist/release0110/final/`。
- 实测宿主为官方 DSH 0.2.2-rc.5 Windows 桌面及同一官方桌面发行包的 Web 模式。声明范围为 `>=0.2.2-rc.3 <0.2.3-0`。两端都装回公开的 0.10.0，再在原有隔离资料中升级并核对候选的全部 262 个文件。

### 手册与回归

- 用公开 0.10.0 在临时库写入并编辑 v4 手册。0.11.0 读取同一笔记和修订，库内保有原三篇。用解包的正式候选完成空库提供和按需添加 v5，验证三篇、两处笔记互链、一张图及两份附件。隔离桌面与 Web 也都从「设置 → 帮助」打开了各自已有的 v1 手册的原修订。
- Node.js 24.21.0 的类型检查与构建通过。首轮全量 428 项中通过 425 项，两项报 Windows 重命名权限错误，一项报本机模拟同步失败。三项分别在独立临时目录复测通过。第二轮全量 428 项全部通过，失败、取消和跳过均为 0，用时约 17 分 1 秒。

### 界面与同步

- 桌面对 10 轮、20 条消息、24 张图片的合成会话核对宽窄布局、手动展开和切回自动、选区减选、材料核对取消、标题预填及手填保留。真实模型建议返回 200，生成并填入元信息。保存并读回 18 条消息和 20 张所选图片。
- 桌面主界面与会话侧栏随宿主切换浅色和深色。独立窗口临时切换后，重开或宿主变色可以恢复跟随。保存笔记标题后，打开同一篇的独立窗口自动刷新。
- 桌面写入的转存笔记修订及其原始素材已在指定私库核对，抽查了一个图片对象。Web 实际读回同一修订、正文与原始素材。Web 的匿名笔记请求返回 401，宿主授权后返回 200。
- Web 重新走过三栏、紧凑、手动展开和选材确认，用笔记界面编辑标题并完成保存。候选将该修订同步到指定私库。重启后的桌面主界面和独立窗口读回同一修订，Web 重启后也读回同一修订。两端核对原始素材仍为 18 条消息和 20 张图片。
- 桌面与 Web 的 DSH 原生设置在重启后仍为笔记顶栏选定的深色，完成验证后恢复初始浅色。Web 首次验收的辅助脚本遇到窗口标识过期。重新登记验收窗口后，同一转存样本通过界面保存与自动同步完成反向验收。
- 从这个候选实拍并复核了图解所用的 1280 × 780 转存三栏，以及 1256 × 635 的 Web 外观设置图。中英文 README 和公开截图清单引用新版设置图。既有生图、会话侧栏和代码实拍仍能说明对应场景。[转存图解](../../user-guide.zh.md#保存会话里的问答) · [截图记录](../../../assets/screenshots/0.11.0/README.md)

### 常见操作抽查

使用同一台 Windows、同一 rc.5 宿主和 `1360 × 920` 的无头独立窗口，初测时本机库有 159 篇笔记和 25 本笔记本。以正文或列表可见、再等待两帧作为完成标准。每项首测 1 次、热切换 5 次，单位为毫秒。

| 操作 | 0.10.0 首次／热中位／热最大 | 0.11.0 首次／热中位／热最大 |
| --- | --- | --- |
| 打开普通笔记 | 231／250／260 | 233／234／266 |
| 打开长文 | 452／250／270 | 403／250／851 |
| 切换笔记本 | 117／117／133 | 117／100／117 |

候选长文有一次 851 毫秒的热切换，其余四次为 150–252 毫秒。初测与回归和宿主启动同步有时间重叠，单次长尾的来源未定位。

同步空闲后再次用同一篇普通笔记、长文和笔记本测量。此时库中有 160 篇笔记，新增一篇同步验收样本。普通笔记结果为 214／216／262 毫秒，长文为 328／234／251 毫秒，切换笔记本为 100／100／100 毫秒。补测未再次观察到初测长尾。

## 发布前发现的宽窗限宽

使用同一候选在 rc.5 桌面进入已有的手册整理会话。内容区为 1540 × 960 CSS 像素，保存选项已打开三栏，实际宽度仍为 680 像素，标题与轮次内容被挤窄。浏览器记录显示，后挂载的 `.paper-dialog[data-layout]` 宽度声明覆盖了转存专用宽度。多图验收会话实测为 1280 像素，用户图解使用该实拍。复现数据和截图为 `desktop-layout-diagnosis.json` 和 `desktop-guide-width.png`。[通用外观样式](../../../src/client/paper/appearance-style.ts) · [转存样式](../../../src/client/capture-options-style.ts)

修正候选由共享弹窗统一计算外框和视口边界，外观样式只提供弹窗的视觉风格。各入口声明所需的尺寸。同一会话在同一视口复验，结果为 1280 × 780 像素，宽度只有共享弹窗的一条计算规则。证据见修正候选目录中的 `desktop-original-layout.json`。[共享尺寸规则](../../../src/client/paper/dialog-style.ts) · [浏览器回归](../../../test/browser/README.md#共享弹窗尺寸)

## 修正候选实装复验

- Node.js 24.21.0 类型检查、构建及 428 项全量回归通过，失败、取消和跳过均为 0。全量用时约 17 分 21 秒。独立浏览器回归还验证了后挂载外观样式、嵌套弹窗尺寸和 104 × 120 的视口边界。
- 两端实际走完转存紧凑、展开和选材。宽窗三栏 1280 像素，紧凑 556 像素，核对轮次 680 像素。在 320 × 240 的视口中展开为 308 × 228 的单列，可滚动、收起和关闭，切换时保留标题。快捷键说明、历史预览和会话引用通过实际入口核对，宽窗分别为 680、940、620 像素。Web 模拟保存失败验证旧版转存弹窗为 1220 像素。会话导出保留的样式由离线浏览器回归覆盖，当前产品从笔记界面提供导出入口。
- 同一候选在隔离桌面完成真实 AI 建议和转存，保存 18 条消息与 20 张图片，核对指定私库的修订、来源和一张图片。Web 读回后编辑并上传。重启后的桌面主界面、独立窗口和 Web 均读回同一反向修订及原始素材。主题切换与重启恢复通过，两端保有旧手册修订。
- 用修正候选重新检查解包手册 v5 的三篇、两处互链、配图和两份附件。公开 0.10.0 写入并编辑的 v4 手册保留原修订。复拍的合成会话转存图解和 Web 设置图分别与公开素材逐字节一致。[转存图解](../../user-guide.zh.md#保存会话里的问答) · [设置截图](../../../assets/screenshots/0.11.0/README.md)

### 常见操作补测

修正候选在同步空闲后，用 161 篇笔记、25 本笔记本和 1360 × 920 的独立窗口完成抽查。普通笔记首次／热中位／热最大为 333／279／342 毫秒，长文为 883／368／379 毫秒，切换笔记本为 141／122／125 毫秒。每项首测 1 次、热切换 5 次。

为复核跨轮长文时延差异，在同一个 rc.5 进程和同一份空闲资料上，分别加载初次候选和修正候选的独立窗口构建产物，按前、后、后、前交替测量。每版首测 2 次、热切换 10 次。下表单位为毫秒，结束点为目标正文或列表可见后再等两帧。原始结果见 `desktop-performance-compare.json`。

| 操作 | 初次候选热中位／最大 | 修正候选热中位／最大 |
| --- | --- | --- |
| 打开普通笔记 | 268／351 | 297.5／383 |
| 打开长文 | 347／1371 | 350.5／861 |
| 切换笔记本 | 159／179 | 160.5／195 |

初次候选在本次同场对照中也出现了约 350 毫秒的长文热切换中位数。两轮之间的具体差异来源未进一步拆分。保存后的双窗口刷新通过实际同步流程核对。
