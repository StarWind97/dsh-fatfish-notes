# 肥鱼笔记 / Fatfish Notes 0.11.0

- **选材更容易核对。** 宽窗并排显示会话消息、图片与文件、笔记信息。窄窗可以展开，布局切换会保留选择和已填内容。
- **直接沿用会话标题。** 标题会预填，可以手动修改。需要时点「AI 建议」，根据所选消息的文字生成标题、摘要和标签。
- **从笔记顶栏切换 DSH 明暗。** 主界面切换会保存到宿主设置，独立窗口仍可临时调整本次视图的明暗。

声明支持 DSH `>=0.2.2-rc.3 <0.2.3-0`。升级前完成同步，在原 DSH 资料中安装并重启。随包手册更新了转存步骤，已有手册继续作为笔记打开。[图解使用说明](../../user-guide.zh.md) · [验收记录](review.zh.md)

## English

- Review conversation messages, images and files, and note details side by side when there is room. Expand the compact layout when needed. Switching layouts keeps your selection and edits.
- Start with the conversation title and edit it as needed. Optional AI suggestions use the selected messages’ text to propose a title, summary, and tags.
- Change and save the DSH theme from the notes toolbar. The separate window can temporarily change its own appearance.

Fatfish Notes declares support for DSH `>=0.2.2-rc.3 <0.2.3-0`. Finish syncing, install the package in the same DSH profile, and restart DSH. New handbook copies explain the updated capture steps.
