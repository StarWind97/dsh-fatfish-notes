# 肥鱼笔记 / Fatfish Notes 0.9.1

**发布准备稿，尚未公开。**

## 本次更新

- **补齐宿主访问检查**：插件在处理宿主 HTTP 请求前执行 DSH 的登录与来源检查，并保留原有的本机、Host、Origin 及跨站限制。根据插件市场维护者的反馈修复；登录失效的请求不能继续读取或修改笔记。
- **统一品牌与小尺寸图标**：采用已确认的「莓紫春芽」配色，深色环境适度提亮；按显示尺寸采用原版或尾部特调鱼形，保留 DSH 入口所需的单色形态。
- **改善 Windows 任务栏辨识度**：独立窗口直接向系统提供多尺寸图标来源，减少浏览器小图标放大导致的柔化。窗口仍由已有 Chrome / Edge 打开，不增加常驻辅助进程。

沿用已接受的实际使用场景展示。笔记功能与资料格式不变。

## 安装与升级

候选适用于 **DSH 0.2.2-rc.3 / Windows**。正式发布确认后提供 `dsh-fatfish-notes-0.9.1.tgz`；Source code 压缩包不能作为插件安装包使用。

从 0.9.0 升级无需重新绑定私库，也没有新的资料格式迁移。升级前确认同步完成，关闭独立窗口和 DSH，并保留本机笔记资料夹与 `DSH_HOME/fatfish-notes` 的备份。若从 0.8.0 升级，仍须遵循 [0.9.0 的宿主与资料兼容说明](../0.9.0/release-notes.md#调整与升级)。

## 验证与边界

候选检查及安装包摘要见[发布审核](review.zh.md)。实际测试只使用项目隔离资料与指定私库。Windows 原生任务栏为实际 100% 缩放环境；物理高 DPI、macOS、浅色系统任务栏及用户固定快捷方式不声明已实测。

本次 DSH 身份检查针对宿主注册的路由。独立窗口使用单独的本机入口，继续执行自己的来源与窗口校验；不把它描述为经过 DSH 登录认证。当前公开市场的 0.9.0 提醒在新版发布并验证后才申请更正。
