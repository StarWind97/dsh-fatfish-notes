# DSH笔记 0.5.0-rc.12 候选说明

这是首次公开发布前的验收候选，目前尚未公开分发。适用于 DSH `0.2.1-rc.5`，本轮验收平台为 Windows；macOS 尚待实测。

## 可以用它做什么

- 从回答下方保存当前问答，在会话内增加轮次或细选消息，也可保存整个会话。保留原始文字与可归档图片，手动整理后的正文独立保存。
- 原地编辑 Markdown 图文，手动维护标题、摘要与标签。会话转存时可选择 AI 元信息建议。
- 将笔记或会话导出为 Markdown、含图片附件的 ZIP、PDF、长图或分页图片。
- 使用同一个专用 GitHub 私有仓库跨设备继续工作。首次使用必须完成接入，之后可断网保存，联网后自动重试同步。

## 本候选的改动

修复异常退出后遗留同步锁阻止后续同步的问题：确认持锁进程已退出后恢复，同时保护正在运行的同步。锁状态无法确认时保留原文件。补齐安装、升级、卸载、备份恢复与反馈说明；笔记存储格式未改变。

体验反馈后补充样式修复：阅读与编辑区顶部留白统一为 8 像素，吸顶工具栏的背景完整覆盖上方留白，防止滚动正文透出。深浅色、标准宽度、全宽和窄窗口已在隔离宿主检查。

首次设置增加面向新手的三步引导，解释同步工具用途、GitHub 私有笔记库与本机副本，补充安装帮助、账号注册及失败后的操作提示。首次使用默认推荐新建私人笔记库，原有用户可连接已有库。工具安装、账号登录和首次同步分别显示，存储与同步机制沿用原实现。

## 安装与验证

安装包：`dsh-github-notebook-0.5.0-rc.12.tgz`。安装前先启动一次 DSH 完成资料初始化，再退出并安装；具体操作见[使用说明](../user-guide.zh.md#安装升级与卸载)。

本候选基础包通过类型检查、构建及 197 项自动测试；后续纯样式修补按第一档重新构建、检查实际页面并更新隔离安装，未重复全量回归。真实宿主、私库和安装覆盖范围见[验证记录](../verification-log.zh.md)。本轮不扩大平台兼容声明，首次新建云端仓库和重新人工登录的验证边界也在该记录中列出。

新手引导按第二档完成类型检查、构建、2 项初始化专项测试及隔离宿主页面检查；登录等待与失败状态使用模拟响应，已有私库预检使用真实测试仓库。没有重新发起人工认证或新建云端仓库。

升级前保存笔记、确认同步并备份本机资料。`rc.11` 到本候选无需迁移数据；需要回退时，关闭 DSH 并安装保留的 `rc.11` 包。

用户体验本候选并确认后，再进入公开发布和市场收录步骤。
