## 本次发布内容

- 自动保存标题、标签、摘要和正文；离开或正常关闭后，回来默认从最新内容的阅读态继续。
- 前台每五分钟双向同步，顶栏区分同步中、已同步和需要处理的问题；点击查看提示，不直接跳离笔记。
- 已绑定笔记库也能登录 GitHub。登录原账号后恢复同步，账号不符时提示切回，不重建笔记库。
- 垃圾桶图标展开轻量确认，移入后可撤销；增加「问题与建议」入口。

产品名称保持 **DSH Notebook · 私人笔记管理**，默认私人笔记仓库仍为 `dsh-notes`。不更改存储格式或依赖版本。

## 实测范围

类型检查、构建、207 项全量回归通过；最终包已安装到隔离 Desktop/Web 并逐项核对 126 个文件。普通 Desktop 使用系统 GitHub 登录资料，旧版升级保留图文与绑定，未点击保存直接关闭后重启恢复最新内容。真实私库双向同步和图文导出结果见验证记录。

Windows / DSH 0.2.1-rc.5 已验证。macOS、两台物理电脑、断电和强制结束进程未覆盖。本轮不重复人工 OAuth；授权等待、失败和账号不符由受控接口验证，实际 GitHub 账号沿用用户已完成的正常桌面授权。0.5.1 → 0.5.0 回退未另做整套宿主验收，回退建议基于存储格式保持不变，仍应先备份。
