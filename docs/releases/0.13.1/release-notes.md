# 肥鱼笔记 / Fatfish Notes 0.13.1

- 「设置 → 阅读与代码」提供正文排版与代码显示两张卡片。字重、字号、折行与行号会即时反映在代码预览中。
- 阅读、编辑和历史预览中的代码统一使用内置 Cascadia Code。中文等字符按本机字体补足。
- 整理笔记时，列表没有匹配结果便隐藏「多选」，回收站也收起「清空回收站」。侧栏已在多选时仍能查看已选或退出。移走列表最后一篇后仍可撤销。

声明支持 DSH `>=0.2.2-rc.3 <0.2.3-0`。先完成同步，在原有 DSH 资料中安装版本包，再重启 DSH。上一公开安装包见 [0.13.0 发布页](https://github.com/StarWind97/dsh-fatfish-notes/releases/tag/v0.13.0)。[中文图解](../../user-guide.zh.md) · [详细参考](../../user-guide-reference.zh.md) · [验收记录](review.zh.md)

## English

- **Settings → Reading and code** gives typography and code display their own cards. Use the live preview to check font weight, size, wrapping and line numbers as you change them.
- Code in reading, editing and version history uses the bundled Cascadia Code font. Other scripts use system fonts where needed.
- Empty results hide **Select notes**, and Trash also hides **Empty trash**. If you are already selecting in the conversation sidebar, you can still review your selection or exit after switching to an empty group. You can undo a move to Trash after removing the last note from the list.

Fatfish Notes declares support for DSH `>=0.2.2-rc.3 <0.2.3-0`. Finish syncing, install the package in the same DSH profile, and restart DSH. The previous package is available from the [0.13.0 release page](https://github.com/StarWind97/dsh-fatfish-notes/releases/tag/v0.13.0).
