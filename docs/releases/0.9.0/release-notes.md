# 肥鱼笔记 / Fatfish Notes 0.9.0

把值得留下的会话整理成自己的笔记，在会话旁阅读、修改和复用。

## 本次更新

- **会话旁的笔记**：侧栏可以浏览、搜索、新建笔记，关联当前会话，并为工作区指定默认笔记本。引用会把笔记副本的读取说明加入输入框，保留已有问题，由你检查后发送。
- **更完整的转存与文件处理**：选择问答、消息或整个会话，勾选用户上传和 AI 交付文件；正文保留文件所在位置，补充资料集中展示。正文和资料区支持粘贴、拖入；纯图片默认展示，混合文件默认链接，图片可切换展示形式。
- **界面与阅读**：八套布局、十种配色、正文中西文字体、代码高亮与字重选择；外观设置在当前 DSH 的主页面、独立窗口和侧栏间共享。临时笔记标签便于切换，目录与资料面板可以收起或固定。
- **更紧凑的整理与操作**：收藏和置顶分开，笔记本可手动排序；多选时整行用于选择，标题单行省略，菜单不占内容宽度。设置按类别整理，管理页使用完整内容面板。
- **阅读式图片导出**：输出一张 PNG，可用当前阅读宽度（包括全宽）或预设宽度。PDF 用于文档阅读与打印，Markdown 资源包用于保留正文和附件原件；下载发起后关闭弹窗，失败保留设置，生成中可取消。
- **上手与响应**：空的新库提供三篇可编辑的用户手册，既有库可从帮助页主动添加；更新肥鱼品牌。减少后台同步重复扫描及文件添加排队，已有本机内容不必等待网络再打开。

## 调整与升级

适用于 **DeepSeek Harness 0.2.2-rc.3 / Windows**。安装 `dsh-fatfish-notes-0.9.0.tgz`，不要使用 Source code 压缩包。不需要卸载插件或重新绑定笔记库。

升级前确认同步完成，关闭独立笔记窗口及 DSH，备份本机笔记资料夹和 `DSH_HOME/fatfish-notes`。同一私库的各端应一起升级宿主与插件：新版保存后可采用 v3/v4 笔记清单，**旧 0.8.0 不能继续读取/写入这些新格式**。仅打开旧库不强制迁移；这不代表新旧版可以混用。回退需要配套宿主、旧插件和升级前资料备份，不能只装回旧插件。

- 移除独立模板机制，旧模板保留为普通笔记，正文、文件、历史及字面占位符不丢失。
- 会话先保存为笔记，再从笔记导出；移除会话独立导出入口及分页图片。
- PNG/PDF 不额外打包附件原件；需要原文件时使用 Markdown 资源包。
- 既有笔记库升级不会自动插入用户手册，也不会覆盖用户修改过的手册。

## 验证与边界

验证记录与安装包摘要见[发布审核](review.zh.md)。实际验收使用隔离 Windows 宿主及指定私有测试仓库；macOS、两台物理设备、硬断电与大型真实资料库不声明已实测。

独立窗口依赖 DSH 运行；外观偏好只在同一 DSH 资料内共享，不跨设备同步。引用使用读取说明，尚未直接接入宿主原生附件栏。AI 只在转存时可选建议标题、摘要和标签，正文由用户编辑。彻底删除不重写 Git 历史，不等于安全擦除。
