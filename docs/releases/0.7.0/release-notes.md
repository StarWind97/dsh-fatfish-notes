# 肥鱼笔记 / Fatfish Notes 0.7.0

私人笔记管理：保存会话，整理图文和附件，通过自己的 GitHub 私有仓库跨设备同步。

## 本次更新

- **笔记本管理**：独立的「笔记本」页面；未指定位置的笔记进入默认本。移除普通笔记本时，可保留笔记并移入默认本，也可确认后一起移到回收站。
- **笔记导入与整库导出**：导入 Markdown 文件、文件夹或 ZIP，预览后再保存；整库或单本导出为 Markdown ZIP，包含图片、附件和相对链接。支持常见 Obsidian 图片与文章链接。
- **普通文件附件**：保存和下载 PDF、音频、视频等文件。大文件会提示同步负担，超过限制时拒绝添加；不提供预览和播放。
- **笔记互链**：编辑时搜索并链接另一篇笔记，阅读时点击跳转或返回，目标改名或换本后仍能跳转。
- **批量清理**：列表支持多选移入回收站；回收站支持单篇、多篇彻底删除和清空。清理独有图片与附件，保留仍被其他笔记引用的文件。
- **依赖修正**：移除插件没有直接使用的 Schemastery 宿主依赖要求，减少不必要的兼容警告。

自动保存、会话原样转存、章节目录、私库双向同步，以及单篇 Markdown/PDF/图片导出继续保留。

## 安装与升级

适用于 **DeepSeek Harness 0.2.2-rc.1 / Windows**。下载 `dsh-fatfish-notes-0.7.0.tgz`，不要使用 Source code 压缩包。按照 README 安装到自己的 DSH profile，安装或升级后重启。

从 0.6.0 升级无需卸载或重新绑定笔记库。已初始化但还没有内容的笔记库，升级后会提供默认笔记本。若有内容，先确认已同步并保留资料备份。同库的各端应一起升级；本次包含数据格式更新，不能仅装回旧包继续使用新版资料。

## 使用边界

- 导出文件可在 Obsidian 中打开；实际验证版本为 1.10.6。导入导出面向 Markdown、图片、普通附件及基础属性，不转换第三方插件、白板或数据库，也不与其他软件共同编辑肥鱼笔记的内部资料目录。
- 普通附件超过 10 MiB 需确认，单文件上限 50 MiB。视频等大文件会增加同步耗时和仓库体积。
- 彻底删除不重写 Git 历史，不是安全擦除，也不会立即缩减历史仓库体积。
- macOS 尚未实测。AI 仅在会话转存时可选建议标题、摘要和标签，正文由用户手动编辑。

问题与建议可从插件顶部入口提交到 GitHub。
