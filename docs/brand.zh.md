# 肥鱼笔记品牌使用

品牌为已确认的「墨鱼·叠页」鱼形，完整组合含「肥鱼笔记」与「Fatfish Notes」。中英文字均为矢量轮廓，不依赖用户电脑字体；阅读字体设置不会改变品牌字形。

2026-11-16 按[统一主色与任务栏规划](plans/2026-11-16-brand-color-and-taskbar.zh.md)，所有现行品牌资源的主色统一为提亮绿 `#3F5A4E`，替代旧 `#26362F`。包括鱼身、品牌文字及完整组合/应用图标中的绿色底；米白 `#F7F4EB`、标准页片绿 `#B7C9B3` 和微型页片绿 `#809D7B` 保持。历史原稿与旧发布证据不改写。

2026-11-16 用户在实际尺寸评审中选择 A「保留叠页」用于微型入口。按[接入规划](plans/2026-11-16-small-logo-a.zh.md)，small 系列源稿使用 24 × 24 坐标，简化尾部并加大透明眼孔；完整品牌与标准双色图形维持原确认稿。旧稿和两版方案保留于[评审目录](brand/reviews/2026-11-16-small-mark/README.zh.md)。生成脚本同时输出微型 viewBox，组件与 favicon 采用该坐标，避免复制路径后仍使用旧坐标。

| 场景 | 资源与尺寸 |
| --- | --- |
| DSH 左导航、会话顶部工具入口 | 16／17 px 单色 A，继承宿主界面色 |
| 主/独立窗口顶栏、会话侧栏标题 | 20／17 px 双色 A，浅色鱼身提亮绿，深色米白，页片保持微型绿 |
| 首次接入、宿主插件设置 | 44 px 容器中的 28 px 双色 A，复用宿主/视图明暗；分组同步表单保持隐藏 |
| 笔记欢迎区 | 64 px 双色纯鱼形；回收站继续使用回收站图标 |
| 设置 → 帮助 | 透明底完整组合，浅／深跟随所在视图，宽度最大 480 px；窄／矮窗口缩小并允许内容自然滚动 |
| 插件列表、市场资源 | 提亮绿圆角方块、米白标准鱼形；`icon.svg` 与 `assets/icon-180.png`，不把名称塞进微型图标；市场更新另行发布 |
| 浏览器标签、独立窗口标题/任务栏 | 同款提亮绿方块、米白微型 A；SVG、16／32 px PNG 及 16–256 px ICO 后备。真实 Windows 覆盖见本轮交付，不能把页面显示等同所有系统行为 |
| README、介绍封面 | 完整组合，通常至少 256 px；根据实际底色使用浅／深或透明版本 |

完整组合在浅色页面使用提亮绿主体与文字、浅绿叠页，在深色页面使用米白主体与文字、浅绿叠页。透明版本的底色、鱼眼和页间镂空都透出所在页面颜色。保持长宽比和已确认的字形，不加描边、阴影或拉伸；品牌不随界面强调色重新染色。

页面内品牌跟随肥鱼所在视图已解析的明暗。DSH 入口与会话侧栏跟随宿主；主界面和独立窗口允许临时明暗，宿主主题变化后沿用原有恢复规则。favicon 与应用图标自带提亮绿底，明暗环境采用同款，不跟随系统变回单色。32 CSS px 及以下使用 A，48 px 及以上展示使用标准稿；高倍率 favicon 位图仍来自 A，因为实际显示槽位没有变大。

2026-11-17 用户要求重新比较原版在任务栏及 16／17／20 px 入口的表现，见[完整图册与复核范围](plans/2026-11-17-brand-gallery-and-original-shape.zh.md)。上段是当前候选实现，不是小尺寸必须简化的设计结论；最终图形选择待本轮评审后更新。

设置齿轮、用户手册书本、全部笔记／笔记本、保存会话、引用和导出继续使用功能图标。帮助页底部为设置中完整品牌的专用位置，其他分类不额外放大图，不向用户导出的笔记添加水印。

当前矢量源稿在 [assets/brand/](../assets/brand/)。设计原稿、用户选择、文字参考、编辑数据与 PNG 见[素材索引](brand/README.zh.md)；接续本轮代码和验证见[Logo 交接](handoffs/2026-11-16-brand-logo.zh.md)。这些必要设计依据已归档到项目，不依赖原会话目录。

[generate-brand.ts](../scripts/generate-brand.ts)从标准/微型 SVG 生成客户端常量、透明完整组合、彩色 favicon 和根 `icon.svg`；[render-brand.mjs](../scripts/render-brand.mjs)用本地 Chrome 渲染 PNG 和多尺寸 ICO，无新增产品依赖。两步骤不会反向修改原 SVG 几何或历史资料。当前 58 份 PNG 在 [current-png/](brand/current-png/README.md)，旧 `png/` 保留归档。[Brand.tsx](../src/client/Brand.tsx)只渲染可信本地路径，不解析外部 SVG、不请求字体或网络素材。

原接入范围见[初次实施规划](plans/2026-11-16-brand-logo.zh.md)，本轮完成情况和真实任务栏边界见[主色统一验证](plans/2026-11-16-brand-color-and-taskbar-results.zh.md)。本轮为本地候选，公开市场与发布包不会因此自动更新。
