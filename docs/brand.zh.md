# 肥鱼笔记品牌使用

品牌为已确认的「墨鱼·叠页」鱼形，完整组合含「肥鱼笔记」与「Fatfish Notes」。中英文字均为矢量轮廓，不依赖用户电脑字体；阅读字体设置不会改变品牌字形。

2026-11-16 用户在实际尺寸评审中选择 A「保留叠页」用于微型入口。按[接入规划](plans/2026-11-16-small-logo-a.zh.md)，small 系列源稿使用 24 × 24 坐标，简化尾部并加大透明眼孔；完整品牌与标准双色图形维持原确认稿。旧稿和两版方案保留于[评审目录](brand/reviews/2026-11-16-small-mark/README.zh.md)。生成脚本同时输出微型 viewBox，组件与 favicon 采用该坐标，避免复制路径后仍使用旧坐标。

| 场景 | 资源与尺寸 |
| --- | --- |
| DSH、会话入口与顶栏 | 单色小尺寸纯鱼形，分别沿用 16／17／20 px，继承当前界面色 |
| 首次接入、宿主插件设置 | 44 px 容器中的 28 px 单色鱼形；分组同步表单保持隐藏 |
| 笔记欢迎区 | 64 px 双色纯鱼形；回收站继续使用回收站图标 |
| 设置 → 帮助 | 透明底完整组合，浅／深跟随所在视图，宽度最大 480 px；窄／矮窗口缩小并允许内容自然滚动 |
| 插件列表、市场资源 | 正方形纯鱼形；`icon.svg` 与 `assets/icon-180.png`，不把名称塞进微型图标 |
| 浏览器标签页 | 小尺寸 SVG，16／32 px PNG 后备；不等于 Windows 任务栏图标已被定制 |
| README、介绍封面 | 完整组合，通常至少 256 px；根据实际底色使用浅／深或透明版本 |

完整组合在浅色页面使用墨绿主体与文字、浅绿叠页，在深色页面使用米白主体与文字、浅绿叠页。透明版本的底色、鱼眼和页间镂空都透出所在页面颜色。保持长宽比和已确认的字形，不加描边、阴影或拉伸；完整品牌不随界面强调色重新染色。

页面内品牌跟随肥鱼所在视图已解析的明暗。DSH 入口与会话侧栏跟随宿主；主界面和独立窗口允许临时明暗，宿主主题变化后沿用原有恢复规则。favicon 属于浏览器标签栏，其 SVG 跟随浏览器的系统主题；后备 PNG 自带浅底。

设置齿轮、用户手册书本、全部笔记／笔记本、保存会话、引用和导出继续使用功能图标。帮助页底部为设置中完整品牌的专用位置，其他分类不额外放大图，不向用户导出的笔记添加水印。

当前矢量源稿在 [assets/brand/](../assets/brand/)。设计原稿、用户选择、文字参考、编辑数据与 PNG 见[素材索引](brand/README.zh.md)；接续本轮代码和验证见[Logo 交接](handoffs/2026-11-16-brand-logo.zh.md)。这些必要设计依据已归档到项目，不依赖原会话目录。

[generate-brand.ts](../scripts/generate-brand.ts)只从三个源文件读取客户端路径：`fatfish-mark-small-mono.svg`、`fatfish-mark.svg`、`fatfish-brand-square-light.svg`，另生成浅深透明组合及小尺寸 favicon SVG。它**不会**自动改齐所有图形变体、PNG、根目录 `icon.svg` 或 `assets/icon-180.png`；修改时按素材索引的依赖表逐项核对。[Brand.tsx](../src/client/Brand.tsx)只渲染可信本地路径，不解析外部 SVG、不请求字体或网络素材。历史设计与验证截图保留原样。

接入范围和验证见[实施规划](plans/2026-11-16-brand-logo.zh.md)。本轮为本地候选，公开市场与发布包不会因此自动更新。
