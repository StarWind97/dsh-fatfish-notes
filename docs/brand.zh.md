# 肥鱼笔记品牌使用

品牌为已确认的「墨鱼·叠页」鱼形，完整组合含「肥鱼笔记」与「Fatfish Notes」。中英文字均为矢量轮廓，不依赖用户电脑字体；阅读字体设置不会改变品牌字形。

2026-11-18 按[莓紫春芽接入规划](plans/2026-11-17-berry-brand-adoption.zh.md)完成接入后，用户明确确认以「莓紫春芽＋深色小幅提亮」作为后续品牌基线。鱼形与字形保留原设计，颜色不随 UI 配色选项跳变。品牌基线确认不等于新版已发布。

| 角色 | 浅色环境 | 深色环境 |
| --- | --- | --- |
| 透明鱼身 | `#A337A0` | `#BA3FB6` |
| 透明上弧 | `#529849` | `#5DAC53` |

应用方块固定莓紫 `#A337A0` 底、米白 `#FFF7EE` 鱼、浅春芽 `#B5EDA2` 上弧，明暗环境同款。`-light`/`-dark` 应用方块文件名为兼容保留，现配色相同。旧提亮绿、原稿和评审记录保留，不改写。

2026-11-17 按[分尺寸接入规划](plans/2026-11-17-brand-size-adoption.zh.md)，用户确认 D2 用于 16/17 px、D1 用于 20/24 px、C0 用于 28 px，更大尺寸回到原版。C0 保留 C 的前景，简化背景鱼尾；D1/D2 在此基础上增厚圆润尾瓣，上弧独立。图形与颜色来自[第二轮评审](brand/reviews/2026-11-17-tail-d123-v2/README.zh.md)，不重新绘制原版或文字。旧 A 及各轮素材保留，不再作为当前小入口。

完整组合中的鱼身、上弧、字标分别使用上表颜色，深色环境保留莓紫主体。透明版本的底色、鱼眼和页间镂空都透出所在页面颜色。保持长宽比和已确认的字形，不加描边、阴影或拉伸；品牌不随界面强调色重新染色。

页面内品牌跟随肥鱼所在视图已解析的明暗。DSH 入口与会话侧栏跟随宿主；主界面和独立窗口允许临时明暗，宿主主题变化后沿用原有恢复规则。favicon 与应用图标自带莓紫底，明暗环境采用同款，不跟随系统变回单色。按显示槽宽：≤17 px D2，17–28 之间 D1，28 px C0，>28 px 原版；设备倍率不改变几何。通用 PNG 也按这套显示尺寸规则，窗口专用 PNG 则固定 D1。

可直接打开[当前品牌图册](brand/current.html)查看尺寸、明暗、形态、典型位置及下载；[原版/A 图册](plans/2026-11-17-brand-gallery-and-original-shape.zh.md)和其他评审作为历史保留。当前选择是用户本轮比较后的决定，不是所有小尺寸都必须简化的普遍结论。

设置齿轮、用户手册书本、全部笔记／笔记本、保存会话、引用和导出继续使用功能图标。帮助页底部为设置中完整品牌的专用位置，其他分类不额外放大图，不向用户导出的笔记添加水印。

当前矢量源稿在 [assets/brand/](../assets/brand/)。设计原稿、用户选择、文字参考、编辑数据与 PNG 见[素材索引](brand/README.zh.md)；接续本轮代码和验证见[Logo 交接](handoffs/2026-11-16-brand-logo.zh.md)。这些必要设计依据已归档到项目，不依赖原会话目录。

[generate-brand.ts](../scripts/generate-brand.ts)从命名为 d2/d1/c0 及原版的 SVG 生成客户端常量、透明完整组合、D1 favicon 和原版根 `icon.svg`；[render-brand.mjs](../scripts/render-brand.mjs)用本地 Chrome 渲染 PNG 和多尺寸 ICO，无新增产品依赖。两步骤不会反向修改原 SVG 几何或历史资料。当前 75 份 PNG 在 [current-png/](brand/current-png/README.md)，正方形槽位内等比显示；旧 `png/` 保留归档。[Brand.tsx](../src/client/Brand.tsx)只渲染可信本地路径；[尺寸规则](../src/client/brand-size.ts)同时供组件与 PNG 生成使用，不解析外部 SVG、不请求字体或网络素材。

原接入范围见[初次实施规划](plans/2026-11-16-brand-logo.zh.md)，主色依据见[主色统一验证](plans/2026-11-16-brand-color-and-taskbar-results.zh.md)；当前分尺寸接入、原生图标缓存修正和真实任务栏边界见[分尺寸历史验证](plans/2026-11-17-brand-size-adoption-results.zh.md)。本轮为本地候选，公开市场与发布包不会因此自动更新。

Windows 任务栏通过窗口属性指定多尺寸 ICO；短进程退出后由 Windows 持有文件资源，不持有临时 HICON。窗口标题栏仍由浏览器 favicon 渲染。只核验本插件专用资料、网址、PID/启动时间与窗口归属后设置；失败保留浏览器行为，无常驻服务。源文件为 `src/host/focus-window.ps1` 与 `window-native.cs`，构建一起复制到包内。

当前候选的安装核对、实际任务栏及性能见[莓紫春芽接入结果](plans/2026-11-18-berry-brand-results.zh.md)。
