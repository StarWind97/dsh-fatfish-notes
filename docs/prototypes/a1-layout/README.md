# A1 三栏布局交互样稿

这是历史交互样稿，不是已发布插件。用户已确认布局，接入真实插件的结果见 [A2 交付](../../plans/2026-11-09-a2-layout-results.zh.md)。本页复用阅读、目录及 CodeMirror 编辑组件；导航、数据、跨窗口提示为独立样稿模型，不连接 DSH 或 GitHub。

在项目目录执行：

```powershell
node node_modules/typescript/bin/tsc -p docs/prototypes/a1-layout/tsconfig.json
node docs/prototypes/a1-layout/build.cjs
powershell -NoProfile -ExecutionPolicy Bypass -File docs/prototypes/a1-layout/open.ps1
```

也可以直接打开生成的 `output/playwright/a1-layout/index.html`。页面是单文件，无后台服务和联网依赖；生成结果与截图由 Git 忽略。需要项目已有的 Node 和依赖，不额外安装工具。打开脚本使用项目内独立 Chrome 资料；Chrome 不存在时使用系统关联浏览器打开文件，不更改默认浏览器。

## 体验内容

1. 顶部切换「DSH 内 / 独立窗口」，拉宽和缩窄窗口。规则依据笔记内容区宽度，DSH 侧栏仅作为空间示意。
2. 宽屏点击「收起笔记本栏」，或拖动两条列分隔线。分隔线也可用 Tab 聚焦，再按左右方向键调宽。
3. 窄屏通过列表上方下拉选择笔记本；重新拉宽时恢复原偏好。两种窗口分别记住列宽与收起选择。
4. 点击编辑，修改标题、标签、摘要或正文；可在原地阅读与 Markdown 编辑之间切换。保存只写当前浏览器的示例记录，刷新仍可读回。
5. 勾选「模拟另一窗口编辑」，查看提示和「在这里继续编辑」的布局。此按钮只演示交互，没有服务端互斥或真实窗口交接。
6. 查看深色、浅色、正文标准宽度/全宽及章节目录。主题切换是演示控件，正式版继续跟随宿主。

样稿不演示附件导入、实际导出、笔记本增删、真正跨窗口更新或 GitHub 同步。这些原有功能和 A3/A4 待开发能力不能通过此页验收。「独立窗口」按钮在样稿中切换空间示意，实际浏览器应用窗口的补验结果见 [A1 记录](../../plans/2026-11-09-a1-layout-window-results.zh.md)。

## 当前建议参数

- 笔记本栏初始 196 px，可调 164–260 px。
- 笔记列表初始 312 px，可调 240–440 px；空间不足时临时收窄，不覆盖偏好。
- 正文区域优先保留约 460 px。样稿以桌面窗口为目标，不是手机布局方案。
- 内容区首次达到 1140 px 默认三栏；已展开后缩到 1100 px 以下再收起，避免断点附近闪动。
- 目录继续使用已有宽窄模式，不能因为笔记本栏展开而挤压正文。

上述参数已用于 A2；本样稿的假数据接口或模拟占用代码不进入产品。
