# 肥鱼笔记产品与存储设计

2026-11-11：A—D 与性能优化已随 0.8.0 发布；本文同时记录尚未发布的 E 开发版行为，交付见 [E 阶段结果](plans/2026-11-11-stage-e-results.zh.md)。

本文记录当前有效设计，产品为「肥鱼笔记 / Fatfish Notes」，当前正式版本 `0.8.0`。安装标识为 `dsh-fatfish-notes`，新私人库默认名为 `fatfish-notes`。0.6.0 已完成一次性更名，不保留旧品牌兼容分支。日常操作见[使用说明](user-guide.zh.md)，历史迁移范围见[改名规划](plans/2026-11-06-fatfish-notes-rename.zh.md)。旧名称下已发布的 `0.5.1` 作为历史版本保留。

## 宿主基线

当前版本直接适配 DSH 0.2.2-rc.1。会话图片读取使用宿主完整图片引用；引用随固定截止点的读取结果在服务端短暂传递，不写入原始素材或发送到选择界面。E 开发版在既有图片/附件存储上增加会话关联和选材记录，启用 notes manifest v3。

宿主依赖要求只声明本插件实际消费的契约。0.7.0 移除未直接使用的 `@deepseek-ai/schemastery` peer 与直接开发依赖；官方组件自己的间接依赖仍由其管理。保留 DSH 0.2.2-rc.1 及其他实际使用的宿主契约，不通过升级用户环境中的共享库或关闭检查消除警告。市场的声明读取失败与插件自身未声明是两种情况，不能把「宿主要求未知」直接解释为插件未适配。

## 产品范围

产品名称为 **Fatfish Notes**，当前副标题为 **私人笔记管理**，中文简称保留 **肥鱼笔记**。首发以现有笔记能力介绍产品；长期探索利用宿主 AI 进行知识组织与内容输出，具体功能另行规划。代码仓库和安装包标识继续使用 `dsh-fatfish-notes`，默认私有笔记库名仍为 `fatfish-notes`。

将 DSH 会话原样保存为个人笔记，手动编辑 Markdown 图文，通过同一个 GitHub 私有仓库在自己的设备之间继续使用。笔记和会话均可导出为本机文件。

正文由用户手动修改。标题、标签和摘要也可手动修改。E 体验修正版在会话转存的保存选项中提供「AI 建议」按钮，先生成并填入可编辑表单，再明确保存；标题必填，摘要和标签选填。原始选材和已归档图片作为来源资料保存，日常正文编辑独立于原始素材。

## 首次接入与同步

首次使用需要 Git、GitHub CLI、GitHub 个人账号及一个专用私有笔记仓库，并在完成首次同步后进入笔记操作。缺少工具时提供安装链接与重新检测，账号认证使用 GitHub 浏览器授权。

首次引导面向没有 Git 知识的用户，按「准备同步工具 → 登录并选择云端笔记库 → 确认保存位置并同步」展示。解释资料保存在本机及用户自己的 GitHub 私有库，默认不公开，不存放在插件作者的服务器。Git 用于同步文件，GitHub CLI 用于账号授权，用户无需学习命令。分别标明工具已安装、账号已登录、首次同步完成，安装或登录成功不等同于上传下载成功。首次使用默认选择新建，换设备可连接已有库；推荐名称仍为 `fatfish-notes`。本轮只调整引导、帮助与状态呈现，沿用现有身份校验、首次同步和存储机制。

初始化分为选择模式、检查、只读确认和已绑定四个状态。用户单选接入已有库或新建私有库。新建建议名称为 `fatfish-notes`，可修改。首次初始化本地目录末级与云端库名一致；「更改位置」用系统弹窗选择父目录，自动追加库名并展示完整路径，取消保留原选择，可恢复默认位置。第二步只填写或选择目标，检查通过并最终确认后才创建云端库。确认页展示账号、仓库、完整本机位置及同步范围，绑定后设置页提供当前状态和位置管理。

首次初始化仅接受新建或空的最终目录，不导入未绑定的旧本地资料。同名非空目录保持不动：新建云端库时可修改第二步库名或更换父目录；接入已有库时更换父目录。服务端再次校验名称和空目录后才创建云端库。本次尝试的目录准备记录允许中断重试，但单独的旧目录标记不能授权接管。已有绑定的恢复及切库位置记忆保持原行为。

已有库通过 `notebook.json` 核对格式、所有者及仓库稳定身份，同时校验笔记清单。首次连接与每次上传均核对私有状态。

已绑定后，编辑自动保存到本机，临时断网不影响保存。停笔约 0.8 秒保存，持续输入最长约 2.5 秒发起保存；图片导入和中文组词完成后再提交。快速修订以约 5 秒一批同步，失败按现有退避节奏重试。打开或返回笔记库、恢复网络、完成编辑和离开时检查双向更新；前台可见时每 5 分钟检查远端，短时间反复打开会合并检查。手动同步同样同时推送和拉取。保存修订、原始选材、附件和笔记本随私有仓库同步，回收站内容包含在同步范围内。

顶栏区分正在保存、本机已保存等待上传、实际同步、已同步和失败；仅实际同步转圈，确认同步后显示绿色对号。悬停或点击状态展开小提示，鼠标离开按钮和提示区域、点击外部或按 Esc 收起，不直接导航。失败可原地重试，确需处理账号等设置时才提供设置入口。设置页持续订阅同一同步状态，首次同步完成仅在初始化结束时短暂提示。

已绑定设置页提供独立的同步账号区域，复用首次设置的浏览器授权、验证码和轮询。登录原绑定账号后恢复同步；账号不符时保留原绑定并提示切回，不执行重置或换库。

账号检查区分没有账号、明确的认证失败和连接失败，不能仅因在线状态检查失败而要求重新登录。本机记录最近一次同步失败的时间与分类，不记录凭据或正文；历史失败不覆盖当前成功状态。远端对象采用有字节上限的批量读取，保留身份、私有性、哈希和结构校验，减少逐对象启动 Git 的开销。

异常退出遗留的同步锁，在确认所属进程已退出后恢复。正在使用的锁、无法识别的锁和无法确定进程状态的锁不会自动清除；锁的存续时间本身不作为回收依据。

并发修改同一篇笔记时保留带冲突版本后缀的独立文档，供用户改名、编辑或删除。重复同步保持已有冲突结果。

## 读取与响应性能

0.8.0 复用已经校验的仓库状态。每次读取仍扫描路径、文件身份、体积和高精度修改/变更时间，发现变化后重新校验结构、引用与哈希；写入、失败和换库会丢弃缓存。缓存不写入私人仓库，也不改变存储格式。对外返回独立副本，调用方不能修改缓存。同步导入同一不可变修订时，复用刚核验过的本机对象，新增修订仍完整校验。

切换笔记本或搜索时复用笔记本统计，保存、整理、手动刷新和跨窗口变化后重新读取；笔记列表完成后先显示，不等待笔记本统计。新的选择取消旧读取，旧响应不能替换最新选择。轮询未发生变化时不重复刷新列表或渲染正文。

关联产生新修订后，按文件及依赖文件的变化指纹复用有效校验，避免重新读取全部历史。仍扫描路径、大小及变更时间；图片、附件、来源文件改变或换库后重新校验。连续关联仅更新对应条目，复用服务端约 5 秒的同步批次，不逐次额外发起同步。

编辑态「完成编辑」旁提供「取消」。编辑过程持续写入本机草稿；有改动时确认取消便丢弃草稿，原笔记及历史不变，新建草稿也不进入回收站。完成或离开才统一生成正式版本，再批量提交与同步。详细恢复和附件规则见下文「阅读与编辑」。

首次校验、保存后的重新校验与网络同步仍有实际成本，不用“瞬时完成”描述未测场景。测量与验收规则见[性能专项](plans/2026-11-10-performance.zh.md)。

## 本机位置与仓库切换

默认控制目录由 `DSH_HOME/fatfish-notes` 确定；未指定 `DSH_HOME` 时使用用户主目录下的 `.dsh/fatfish-notes`。新绑定的资料夹默认为控制目录下的 `libraries/<仓库名>`。活动绑定、各库最后使用的位置及本机身份保存在当前设备。

更换本机位置会暂缓写入和同步，复制并核验笔记、附件、本机任务和 Git 缓存，再切换位置并清理已迁移的插件文件。失败继续使用原位置，断网期间也可搬迁。

日常跨设备使用同一个私库。需要换用另一套资料时，通过重置入口从 A 切到 B。目标库先在独立资料夹完成同步，离开 A 前再次取回 A 的远端更新，并在暂停本机写入时确认本机与远端一致。两边成功后才切换，取消或失败继续使用 A。

从 B 切回 A 时，按 GitHub 账号 ID、仓库 ID 和本机资料标识验证记住的 A 位置。验证通过后由用户确认复用；原位置失效时提供选择原资料夹位置或新建本机资料夹两个入口。新资料夹从远程 A 同步。成功搬迁或切换后更新本机位置记录。

## 笔记本组织

E 体验修正版在新建和改名时检查同库在用笔记本名称：忽略首尾空格和英文字母大小写，排除自身，已移除本的名称可重用。界面就地提示并禁用确认，保存端在已有串行写入区再次检查；沿用笔记本 ID 和原存储格式。工作区名已被使用时，新建输入留空并提示选用已有本或填写新名称。按目录导入遇到重名时新建带“（导入）”及必要序号的笔记本，记录在报告中，不将内容暗中合并到已有本。现有隔离资料重名已按用户要求通过普通改名整理，见[名称规则与交付](plans/2026-11-12-notebook-names-results.zh.md)。

2026-11-08 按[默认笔记本规划](plans/2026-11-08-default-notebook.zh.md)完善逻辑分类，已随 0.7.0 发布。每篇笔记归属一本笔记本，可有多个标签；笔记本不对应正文目录。初始化创建「默认笔记本」，旧的未分类笔记归入默认本，正文、来源、附件和原修改时间保持不变，原修订继续保留。

在某本笔记本内新建时使用当前本，从全部笔记新建及未指定目标的会话转存使用默认本。默认本可改名；「管理笔记本」可以将另一本设为默认，不搬动已经归类的笔记。默认选择随私库同步，当前默认本不能直接移除。

顶部「笔记库｜笔记本｜同步与设置」并列。「笔记本」使用限宽列表管理名称、数量和默认设置，新建与改名在页面内完成；点击名称进入该本的笔记列表并清除其他搜索/标签筛选。左栏下拉框继续快速选择笔记本，「管理笔记本…」跳转到同一页面。切页复用自动保存，普通返回保留原笔记、筛选和阅读位置；管理完成后留在笔记本页面。详见[独立选项卡规划](plans/2026-11-09-notebooks-tab.zh.md)。

移除普通本时，弹窗显示名称和在用笔记数量，名称过长截断并可悬停查看全文。默认选择保留笔记并移入默认本，也可选择将笔记一起移入回收站。危险选项使用醒目确认按钮；取消或关闭不执行移除。已在回收站的笔记仍保留在回收站；恢复后归入默认本。确认期间笔记数量或本的版本变化时要求重新核对，不静默扩大移除范围。

笔记本修订增加可选 `defaultSelectedAt`，默认本由有效笔记本中的最近选择确定，并采用一致的并列取舍。初始默认本使用固定身份，避免各设备重复创建。旧格式可以读取；旧运行版本不认识新增字段，参与同步的实例需要一并升级。批量操作逐篇保留新修订，全部保存后才标记笔记本移除；中断后保留内容，重新查看剩余数量再继续。

## 独立窗口与本机编辑保护（0.8.0）

顶栏「独立窗口打开」使用 Windows 上已有的 Chrome 或 Edge 应用窗口，复用一个专用本机浏览器资料。先保存当前编辑，再传递当前笔记；重复点击复用窗口，系统不允许抢焦点时提示从任务栏切回。另一窗口编辑不同笔记时，提供「保存并切换」「留在当前笔记」，不强制切走。

同一个 DSH 笔记服务提供额外的 loopback 页面入口，不启动第二个资料写入服务或常驻代理。入口端口与浏览器资料保留在控制目录，重启沿用同一来源，使恢复记录可继续读取。窗口使用同一组件和资料、分别记住布局；本机保存后的列表和阅读态约两秒内刷新，不必先经过 GitHub。DSH 的深浅主题由嵌入端传递到独立窗口。

服务端在资料队列内按篇核对编辑资格。同篇只有一处编辑，不同篇可以分别编辑；正文、元数据、图片附件、删除、批量动作和笔记本移除共用保护。批量动作先检查全部对象，有占用时整批不执行并提示数量。更换本机位置或重置仓库要求先结束编辑。同步导入仍遵循现有修订及冲突保留规则，不以本机占用阻止其他设备的同步。

「在这里继续编辑」请求原窗口保存后交接，中文组词和附件导入完成后再保存；可以取消等待，失败保留原编辑。每个窗口使用独立恢复槽，恢复前核对仓库、版本及编辑资格。编辑资格过期、服务重启或切库后，旧请求不能写入；旧恢复稿不会静默覆盖后来修订，继续使用既有保留两份规则。

关闭 DSH 后独立窗口暂停写入，并提示重新打开；不继续显示旧的「已同步」。重启后连接原服务，核对恢复内容并返回阅读态。离开笔记和刷新会结束编辑；临时窗口失焦只保存本机草稿，返回可继续编辑。不承诺断电前尚未持久化的每个按键。当前自动开窗仅在 Windows 提供，其他平台继续使用宿主内界面；macOS 和两台物理电脑未实测。

## 阅读与编辑

笔记库跟随宿主的浅色、深色和跟随系统设置。左栏顶部可选择笔记本或全部内容，列表显示正文摘要，默认最近修改在前，可切换为最早修改在前。列表宽度随窗口适应并允许在约束范围内拖动，阅读和编辑区域支持标准宽度与全宽。

**0.8.0：**按插件实际可用宽度展开笔记本导航栏，首次达到 1140 px 展开、已展开时低于 1100 px 收起；窄窗继续使用下拉选择。笔记本栏初始 196 px、可调 164–260 px，列表初始 312 px、可调 240–440 px，空间不足时临时收窄。拖动、方向键调宽，双击复位；手动收起和列宽按宿主内/独立入口分别保存在本机。导航共用既有筛选和管理功能，折叠不会重新挂载编辑器。布局细节见 [A2 交付](plans/2026-11-09-a2-layout-results.zh.md)，完整窗口能力见[阶段 A 交付](plans/2026-11-10-stage-a-results.zh.md)。

阅读页展示标题、最后修改时间、标签、摘要和正文。时间采用 `2026-11-03 18:21` 格式；标签在同栏靠右，窄窗换行。摘要以引用式样呈现，在标签下方与正文之间用分隔线区分。点标签筛选时，左栏显示可清除的筛选标记，清除后保留搜索、笔记本和排序条件。

从 `0.6.0` 起提供阅读、编辑共用的章节目录。正文及目录的可用宽度充足时使用约 220px 右栏，较窄时改用浮层。每次进入插件，宽窗默认展开、窄窗默认收起；本次使用中切换笔记或阅读/编辑保留手动选择，跨越宽窄布局时采用对应默认状态。不再读取旧的全局持久化开关。目录自动识别正文 H1—H6 与下划线式标题，排除笔记名称、摘要、原始素材及代码中的伪标题。长标题两行截断并提供完整悬停提示，无标题时显示空态。

顶部操作栏独立于正文与目录分列，目录从操作栏下方开始，展开/收起不移动顶部按钮。正文可视区域的垂直中点提供约 16px × 44px 的半透明双折线箭头：展开时左边界穿过箭头水平中点，形如 `》`，收起后在阅读区右边缘反向显示，按钮右侧定位间距为 13px（由 26px 减半）。无边框、无底色，悬停或聚焦时线条更清晰，文字提示为「收起目录」或「展开目录」。点击区域为 24px × 56px，保留正文滚动条滑块的操作空间。目录左内边距为 8px，各级标题缩进不变。顶部目录按钮继续保留。玻璃材质仅保留独立预览，暂未采用。

窄窗点击章节只定位，目录继续显示；鼠标离开目录及开关区域约 200ms 后收起，及时移回则保持展开。点击外部、键盘 Tab 主动移出或 Esc 也可收起；定位编辑器产生的程序焦点变化不触发收起。宽窗点击正文和鼠标移出均保持展开，由用户主动关闭。

正文与目录分别滚动，正文滚动条位于正文区域右缘、目录左侧。目录右侧保留 12px，窄窗浮层与正文滚动条之间保留 12px；笔记列表滚动条靠近分栏边缘，外侧约 7px，避开分栏拖动区。正文、目录和笔记列表统一采用原生滚动条，固定预留 14px 操作宽度；滑块平时显示约 6px，悬停或拖动时加粗至约 10px 并加深，轨道悬停时显现，正文不因悬停重新换行。

阅读态点击章节滚动到对应标题，避开顶部操作栏；编辑态定位到对应标题并移动光标，避开吸顶的格式工具栏，不重建编辑器或改变撤销历史。手动滚动与章节跳转均高亮当前章节，保持单项高亮；长章节持续高亮，到达可滚动正文底部时选中最后一章。当前条目超出目录可见区时适度滚入。目录收起期间保持收起，重新展开按正文位置更新。标题修改后短暂合并更新，中文组词期间暂缓。切换阅读和编辑保留目录展开状态，沿用原有正文位置恢复；进入原始素材时暂时隐藏。目录仅由正文生成，不改变存储或导出文件。

阅读与编辑的位置锚点取自实际吸顶栏下方。完成编辑前先记录当前章节位置，避免模式切换后回到最初进入编辑的旧位置。

点击编辑或双击段落后，在原阅读位置打开 Markdown 编辑器。标题、笔记本、标签、摘要、正文和附件持续保存为本机草稿，覆盖同一草稿，不生成正式修订，也不参与 Git 提交、同步或导出。摘要使用独立输入框，自动保存不重建编辑器或撤销历史。编辑工具栏显示「草稿已保存到本机」；顶部同步状态只说明正式笔记的云端状态，不因每次草稿保存而触发同步。

「完成编辑」、切换笔记、离开笔记页/侧栏时，把最新草稿保存为一个正式版本，返回阅读态，再由后台合并提交与双向同步。无内容变化不增加版本；空白新建草稿退出不创建笔记。「取消」经确认丢弃本次草稿，原笔记保持不变；新建草稿直接丢弃。临时切到其他应用、文件选择框或窗口失焦，只保存草稿，仍可回到本次编辑继续。

宿主把草稿原子写入本机资料夹的 `local-drafts/`，不放入 `notes/` 同步模块。浏览器恢复记录保留尚未送达宿主的末次输入，按私库与窗口隔离。正常关闭尽力结束编辑；崩溃或强制退出后，下次启动自动完成已落盘草稿，再由浏览器补齐未送达的输入。完成/取消回执和编辑序号防止旧请求重复保存或复活已取消草稿。断网不阻止本机完成；突然断电只能恢复已落盘输入，不能承诺网络在关闭前完成。

图片和附件仍使用内容寻址文件，只有正式修订引用的文件才同步；草稿登记引用并保护共用文件，完成或丢弃后清理不再引用的草稿文件。拉取远端不直接替换正在编辑的正文；结束编辑时以原修订为依据，冲突保留两篇。按篇窗口占用检查继续生效。原始会话素材始终只读。详见[本机草稿方案](plans/2026-11-12-local-edit-drafts.zh.md)。

编辑器支持各级标题、粗体、斜体、删除线、有序和无序列表、任务列表、引用、行内代码、代码块、链接、图片、表格、分隔线、缩进、查找与撤销重做。编辑区按光标位置显示语法和预览，工具栏使用图标并随宽度收纳次要功能。

图片可通过剪贴板、文件选择器、拖放或公网 HTTPS 图片地址导入。图片以附件归档并在编辑区预览。剪贴板只有文件路径文字时提示使用文件选择器。

正文与只读原始素材可便捷切换并恢复阅读位置。顶栏在空间允许时展示操作，窄窗使用锚定菜单。移到回收站使用带悬停标签的垃圾桶图标，点击向下展开轻量确认，显示取消和确认移入，不遮罩页面、不重复长标题、不挤动正文。回收站常驻左栏，支持移入后立即撤销和日后恢复。

## 问题与建议

笔记库与设置页的顶栏右侧常驻气泡图标和「问题与建议」，首次初始化及宿主内的独立插件设置页也提供相同入口。窄区域显示「反馈」，颜色跟随宿主主题。已有顶栏入口时不在设置内容中重复显示。

链接在新页面打开代码仓库的 GitHub 新建 Issue 页面，用户自行登录、填写和提交；原笔记的编辑草稿会保存，临时离开窗口不会结束编辑。入口不附加笔记内容、私库信息或凭据，不需要插件完成初始化即可使用。

## 会话转存

已完成回答下方并列展示保存到笔记与导出。默认图标和文字，也可在本机外观设置中选择仅图标。

点击保存到笔记后，留在会话并默认勾选当前问答。其他已完成回答下方可勾选轮次，输入区上方显示数量和操作。「下一步」、数量和转存条空白区域都打开「保存选项」，纯文字也必须确认后才保存。弹窗按主窗口宽度布局：宽屏预览与选项分列，窄屏上下排列，标题和底部操作固定。Esc、关闭和返回会话保留选择，转存条「取消」退出；长素材在预览区滚动。只选择已有笔记本，不承担新建或设置工作区默认本。

转存 AI 建议通过宿主公共模型服务单独发起辅助请求，沿用会话选定的模型；不发送会话 prompt、不增加问答、不调用 Agent 工具。E 体验修正版改为保存前生成，输入仅为本次固定范围的选材及所选图片。标题最多 60 字符，摘要建议 50—120 字且最多 200 字符、单段，标签至多 5 个；格式不合格最多重试一次，仍失败保留表单原值并提示。等待时元信息输入暂时禁用；停止后可手填，生成后可修改。辅助请求可取消、限时三分钟；宿主重启后需重新生成，旧聊天通道的未完成任务不自动恢复。辅助请求仍有正常模型费用和宿主用量记录。

点击保存才创建笔记，内容来自固定截止点的选中消息，保留角色、顺序和可归档图片。原始选材另存为只读来源。模型只建议标题、摘要和标签，不修改正文；失败或取消生成不会创建笔记，仍可手填后保存。

选材使用宿主提供的回答操作、轮次末尾和输入区扩展位置，按记录序号关联已完成回答。首次接入规则适用于会话入口。

## 文件导出

笔记从阅读页打开导出弹窗，支持取消、关闭和 Esc。导出使用已保存修订，可分别选择包含标签、包含摘要，以及是否附上原始素材。内容顺序为标题、修改时间、标签、摘要、正文；Markdown 的文件头与可见字段使用同一选择。

会话导出默认当前问答，也可选择整个会话或自选消息。范围以固定截止点的可见记录为准，按原顺序区分用户与 AI，在内存中直接生成下载文件。

纯文本 Markdown 为单文件，带归档图片时提供包含同名 Markdown 和相对路径附件的 ZIP。另支持 PDF、单张长图和分页图片。过长内容可使用分页图片。历史不完整、图片缺失或网页图片仅保留链接时，在下载前提示用户选择。

## 迁入迁出与普通附件（0.7.0）

左栏底部「导入 / 导出」打开独立弹窗。可扫描 Markdown 文件、文件夹或 ZIP，先预览篇数、文件体积和异常，再选择目标笔记本；也可按一级目录新建笔记本。导入始终新增笔记，不修改来源文件、不覆盖已有文章。同一次导入中重试会跳过已完成项，关闭弹窗后再次导入则视为新的复制操作。

保留正文、标题、标签、摘要和来源路径；导入时间作为本机新增时间，不承诺保留第三方全部属性。处理标准 Markdown 相对路径、常见 Obsidian `[[笔记]]` 与 `![[图片]]`。代码中的链接示例不转换；歧义、缺失文件、块嵌入和无法转换的引用列入报告。网络图片默认保留链接，可选择下载归档；失败时保留引用并提示。E 开发版取消固定批次 200 MiB 限额，单篇 Markdown 仍为 10 MiB；文件、图片与数量规则见下节。

PDF、音频、视频及其他普通文件仅作为附件保存和下载，不内嵌预览、播放、执行或解析。编辑工具栏提供附件入口，也支持文件粘贴和拖入；文件卡片显示名称、大小和「下载 / 另存」。E 开发版超过 50 MiB 确认提醒，超过 100 MiB 不接收；取消每篇普通附件累计 200 MiB 限额。大文件会增加同步耗时与 Git 历史体积，首版不引入 Git LFS。

整库或单本导出为 ZIP：笔记本映射为目录，标题映射为 `.md` 文件，重名加序号，图片和普通附件集中随包携带并改写为相对路径。YAML 保存标题、标签、摘要、修改时间和笔记本等基础属性。默认排除回收站、历史修订和原始素材；未包含在选定范围内的链接目标会生成导出说明。单篇导出继续支持 Markdown、PDF 和图片，普通文件随 Markdown 包携带，PDF/图片中仅保留正文中的附件文字链接。

编辑器「链接 → 链接到笔记」可搜索目标，内部引用稳定的笔记 ID；标题、笔记本变化不破坏跳转。阅读时支持跳转和返回上一篇，回收站/彻底删除目标给出提示。导出转换为文件路径，导入为所选文章建立新身份与对应关系。暂不做关系图谱、块引用或跨软件共同编辑内部资料目录。

列表多选支持全部笔记、单本及回收站，0.7.0 用于删除，0.8.0 增加移动和标签整理；全选仅覆盖当前筛选结果。「移到回收站」确认后可撤销。回收站单篇、多篇彻底删除及清空均使用危险动作确认，清空针对整个回收站，不受搜索筛选限制。彻底删除清理文档、全部修订和独有的来源/图片/附件；其他笔记（包括回收站与保留的历史修订）仍使用的文件保留。

此前 `attachments`、`originPath` 与删除标记使用 manifest v2；E 的 `sessionLinks`、来源选材及容量规则启用 v3，新版继续读取 v1/v2。最小删除记录参与双向同步，旧设备未同步的编辑不能复活已彻底删除的笔记。旧版插件不识别新格式，参与同一私库的实例需要一起升级；回退需配套恢复升级前资料备份。删除不重写 Git 历史，不承诺安全擦除，也不立即减少历史仓库体积。

## 存储与运行边界

资料夹中的 `notes/` 保存笔记文档、不可变修订、原始选材、归档图片和笔记本，Git 缓存位于 `backup/repositories/`。同步按笔记对象合并并校验结果。

采集与模型任务日志、本机位置及界面偏好保存在本机，模型凭据由 DSH 管理。HTTP 接口执行 loopback、Origin 和 sec-fetch-site 校验，文件操作校验路径与仓库身份。字体及必要许可证随安装包分发。

## 查找、整理与复用（0.8.0）

按 [B—D 连续实施方案](plans/2026-11-10-bcd-implementation.zh.md)增加收藏、最近访问、多关键词查找、标签建议、历史恢复、批量整理、复制、反向链接和轻量模板。使用方法见[使用说明](user-guide.zh.md)。

收藏 `favorite`、模板 `isTemplate` 为可选的笔记修订字段，复用对象同步与校验。模板从笔记复制，移除原始会话来源关联，保留图片和普通附件；与普通列表、计数和笔记本移除分开，删除普通笔记本不删除模板。普通副本保留来源。无需额外配置同步协议或数据库。旧数据可由新版读取，旧包不能写带新字段的数据；回退配套恢复备份。

最近访问按仓库身份保存到本机浏览器，最多 50 篇；不会生成修订或触发 Git。多词以空白分隔、按 AND 匹配，标题命中优先；上下文和标记仅用于界面，不改原文或导出结果。当前标签统计排除回收站和模板，不维护多级标签。高级组合筛选、标签统一改名/合并及保存筛选仍属后续备忘。

历史按时间分页，每页 30 条，读取指定修订预览。恢复以当前 heads 为父创建新修订，保留当前来源、收藏与模板身份，旧笔记本已移除时归入默认本；恢复前版本及历史附件继续可用。恢复、复制、模板新建、批量移动和增删标签走同一仓库队列，先校验全部版本、目标本及窗口占用。预检失败时不应用所选更改；磁盘故障仍可能部分完成，应刷新核对，不宣称跨文件事务。

反向链接从当前有效 Markdown 链接及被实际引用的定义计算，排除代码、图片和未使用定义；不保存第二套关系。点击内链按需加载预览，再明确打开目标。模板仅做文本变量替换，不执行脚本。E 会话关联已接入，F AI 输出未实施。

## 会话侧栏与文件流转（E 开发版）

使用 DSH 公共右栏 tab，会话工具栏提供入口，不自动抢占其他工具。侧栏复用笔记阅读、Markdown 编辑器、自动保存和按篇编辑保护。侧栏可见且会话相符时，转存完成立即选中新笔记。关闭侧栏、切换会话先保存编辑；已关闭的侧栏不会被转存结果打开。

「从本会话保存」位于「关联的笔记」内，作为与「全部关联」并列的来源筛选，与手动关联去重。来源显示「已关联 · 来自本会话」；手动关联可解除和撤销。一篇可以关联多个会话，解除一处不影响其他会话、正文和笔记本归属。关联只是便于查找，不自动发送给 AI。关联状态就地更新，后台刷新保留已加载页和现有顺序；重新切换筛选后按时间重排。

搜索只放在「查找笔记」中。浏览阶段显示笔记本与笔记两列，笔记本列默认 220 px，随可用宽度收缩，可拖动或键盘调节 160—340 px 并记住本机偏好；侧栏宽度不超过 520 px 时改为单列配笔记本选择弹层，跨过宽窄边界关闭临时弹层。宽时名称只作说明，不设置无效的下拉状态。条目右侧竖排关联图标和更多菜单：未关联为链接加号，已关联为柔和强调色对号，悬停显示操作文字。进入正文后仅保留阅读编辑区，返回保留笔记本、搜索词和滚动位置。本机按私人仓库及工作区记住有效笔记本，其次使用工作区默认本；都没有时展示本列表，空搜索不默认列出全部笔记。选择一本后在该本搜索，可明确切到全部笔记。映射存在时显示独立的「工作区笔记本」页和实际书名，不因此把其中每篇都关联到会话。

侧栏顶部「新建笔记」直接编辑，默认使用工作区默认本、其次全局默认本，可改归属；首次有效保存便关联当前会话。空白退出不建笔记。「查找笔记」的笔记本列底部固定普通新建入口；可选设为当前工作区默认本，默认不勾选。未设置工作区默认本时，「关联的笔记」工具行右端提供轻量设置入口；已设置后书名右侧为新建笔记、设置、导出。设置弹窗支持改名、更换、新建并绑定、解除关联，不混入全局默认和移除操作。更换绑定不搬动笔记，同一本可用于多个工作区；改名会影响该本的所有使用位置。

主界面、独立窗口及侧栏的笔记/笔记本条目支持省略号和右键菜单。笔记可改名、收藏、移动、复制、导出及移入回收站；笔记本可新建笔记、改名、设全局默认、导出及移除，沿用修订和编辑占用检查、默认本保护与删除确认。主列表上方的笔记本、搜索、过滤和多选控件固定，只有条目区滚动。正文所属本单独高亮，保留全部/搜索等原筛选条件。

主列表的视图、排序与多选入口排列在同一行；批量操作仅在多选状态展开。

工作区笔记本设置初始仅展示当前名称与操作入口；铅笔原地编辑名称，「选用其他笔记本」「新建笔记本」按点击展开字段。同类轻量行内操作统一使用字段旁的对号接受、叉号放弃，并提供悬浮提示和无障碍名称；同时只展开一项。Esc 先退出未确认操作，普通状态再关闭弹窗。确认后的改名立即生效，不随取消后续选用撤回。取消侧栏新建笔记直接回到原选项卡、筛选和列表滚动位置；取消已有笔记编辑保持阅读原文。具体边界与验证见[原地操作交付](plans/2026-11-12-sidebar-inline-actions-results.zh.md)。

保存前的 AI 建议使用 `/notes/suggest`，读取本次固定范围和所选材料，使用宿主辅助模型请求；不会向会话追加消息，也不提前创建笔记、来源文件或转存日志。普通附件仅提供名称，不宣称读取其内容；图片遵循宿主模型限制。生成可停止，失败保留人工输入；重新生成覆盖手填信息前确认。改变选材会废弃未完成的旧结果，已有手填内容提示复核。最后确认时把元信息连同原样正文一次保存，摘要建议为单段 50–120 字、最多 200 字，标签最多 5 个。旧保存回执仍可恢复，不主动启动旧的会话提示任务。

普通转存成功提示约 5 秒收起；解除关联和移入回收站的撤销提示约 8 秒收起。悬停或键盘焦点暂停计时，上下文切换清除旧撤销入口；错误、部分结果和 AI 待确认不会按成功提示自动隐藏。提示消失不取消后台任务，回收站和重新关联入口仍可使用。

来源由不可变 sourceId 解析，手动关联 `sessionLinks` 随笔记修订同步。正文编辑、换本和历史恢复保留当前关联；复制、模板新建不继承手动关联。跨设备没有原会话不影响笔记内容。工作区默认笔记本保存在控制目录，按仓库稳定身份及工作区 ID 隔离，书名或路径不用于猜测对应关系；不存在时回到私人库默认本。每次仍可选择任意本。

未映射工作区在侧栏提供新建/选择已有本的入口，新建建议名采用当前工作区名称并允许修改；工作区改名不自动改书名。归档、恢复保留关系；移除工作区保留笔记本与笔记，失效默认不继续使用；同名新工作区不会继承。宿主通知会话已删除时禁用转存、关联和引用，笔记正文仍独立保存。另一台电脑找不到会话不自动清理关系。

保存及直接导出共用选材组件：用户上传文件按消息、AI 正式交付按轮次归属，不扫描正文中提到的任意路径。服务端冻结范围并核验归属，读取文件当前版本，前后版本变化明确失败。保存后文件副本、原始选材及历史共同参与引用/删除检查，不因正文修改丢失原始材料。未选材料显示未包含，不留下看似可用的本机路径。

侧栏阅读态的「引用」位于编辑左侧，三个侧栏列表同时支持图标、右键与跨笔记本多选引用。临时选择可查看、移除、清空，退出多选或更换会话时清空，不设常驻购物车。确认时全文及正文实际引用的图片、文件必须包含；仅未被正文使用的补充附件可选，默认全选。代码示例、未使用的链接定义不算正文资源；不自动递归引用其他笔记或带入原始素材。

准备为 DSH 管理的副本后，通过公开输入接口一次加入读取说明。保持原输入/附件、支持原生撤销、不自动发送；允许连续追加、单篇与多篇混用。重复检查仅针对当前未发送输入中的同版引用，发送或手动移除后可以再次引用。准备可取消，失败不插入半成品；会话/输入/修订变化时停止插入。笔记变化后可重新检查，更新确认窗中的材料。副本不存工作区，不与日后笔记编辑联动，不由插件清理。没有明确会话上下文的完整窗口不猜当前会话，用户回侧栏引用。此功能不同于原生附件栏登记。完整规则及验证见[会话引用专项](plans/2026-11-12-conversation-reference.zh.md)。

Markdown 有材料时导出相对链接 ZIP；PDF/图片与普通附件一起打包，页面仅显示附件名，不播放音视频。图片选择、来源是否包含及正文元数据选项彼此独立；导出不修改笔记。

会话导出弹窗独立定义主题背景，不依赖笔记主页面是否打开；标题和取消/下载固定，正文及长附件列表滚动。笔记本选择框及选项跟随宿主深浅主题。

### 正文小工具

阅读与编辑底部显示字数统计和已有快捷键说明。统计正文的中文逐字、英文按词，排除 Markdown 标记、图片地址和链接目标，代码文本计入；不计标题、摘要和标签。Markdown 解析在 Web Worker 中执行，编辑停顿约 350 ms 后更新，不在输入线程重算。说明只列出已有局部快捷键，不新增全局拦截。

阅读代码块及编辑态代码预览提供复制按钮，只复制代码本体，保留缩进、空行与换行；点击不把编辑预览切回源码，不把按钮文字写入正文或导出。具体范围及验证见 [E 验收修正规划](plans/2026-11-11-stage-e-review.zh.md)。

## 正文材料与补充附件（E 开发版）

编辑器工具栏的「插入图片」在光标处显示图片，「插入文件」在光标处插入带图标的下载链接。正文后另设「补充附件」，独立添加和移除，不再把所有文件自动拼成正文末尾的列表。补充区文件可「插入正文」：成功后移出补充区，图片通过原有内嵌校验后显示，否则按下载链接插入；失败保留原补充项。移入操作支持一次撤销/重做，随后删除正文引用不会让附件重新出现。

两区均支持文件粘贴与拖放，包括 Windows 资源管理器复制文件和截图位图。正文混合输入按顺序内嵌支持的图片、插入其他文件链接；补充区全部作为文件保存。常规输入直接添加，超出内嵌范围的图片按普通文件处理，大文件沿用确认/拒绝规则。批次串行后台上传，映射原插入位置以保留期间输入，正文整批一次撤销；在对应区域显示进度与取消。大文件确认框不承担后台上传，确认后关闭，用户可继续编辑。详见[粘贴与拖放规划](plans/2026-11-12-paste-and-drop.zh.md)。

2026-11-13 按[文件添加优化方案](plans/2026-11-13-file-add-performance.zh.md)，编辑中的单个文件不超过 1 MiB 时，通过 Worker 编码后使用一次传输请求；附带已持久化草稿的编辑 ID，服务端在同一次仓库队列操作中校验草稿、笔记状态、路径和编辑资格，登记引用后原子发布文件。取消或完成的草稿、过期编辑资格和换库后的迟到请求不能写入。大文件、批量导入继续分块；文件限制、存储格式与正式保存时机不变。后台旧任务发现仅扫描 `jobs/`，逐个任务的完整性与状态校验保留，不因查任务遍历笔记正文和全部修订。

会话转存保留消息内图片的位置；能与已选择的真实材料唯一对应的 Markdown 文件/图片链接，改用归档副本。文件上传卡片和正式交付卡片放入补充附件；同一份文件已经在正文使用时，不再重复列出。仅提及名称不当作引用，不搜索任意路径；外部图片链接不偷偷下载，保留为链接。原始素材仍保持转存时原样，阅读它与编辑当前正文是两套视图。

修订与本机草稿用 `supplements` 显式记录补充材料归属，文件注册清单可保留历史/撤销所需资源。当前导出、引用及阅读只使用正文实际材料和补充材料，移除项不会跟随导出。首次编辑旧修订时初始化归属，不自动改写旧正文或历史；笔记模块版本为 4，旧实例遇到新格式停止写入。单篇与整库 Markdown 导出在正文后生成「补充附件」链接区，原件一并打包；PDF/图片仅列出补充文件名，不预览或播放。

标签输入旁为固定尺寸加号，支持悬停说明和回车添加；建议标签另行换行，不把操作文字竖排撑高编辑区。实施范围与验收见[正文材料与补充附件规划](plans/2026-11-12-body-and-supplements.zh.md)。

## 容量、后台处理与取消（E 开发版）

- 单文件超过 50 MiB 提醒，超过 100 MiB 拒绝；内嵌图片最多 20 MiB、3200 万像素，超出作为普通文件保存原图。每篇最多 128 张图片及 128 个普通附件。
- 单次导入最多 10,000 个条目、5,000 篇；整库最多 5,000 个笔记 ID、100,000 个修订；正文 10 MiB、来源 20 MiB。数量与文本校验保留，不承诺上限规模均流畅。
- 取消图片/文件单篇累计、200 MiB 批次及 512 MiB 整库封顶。设置显示当前资料和独立 Git 缓存占用，约 1 GiB 温和提醒、5 GiB 强提醒；提醒不阻止保存。
- ZIP 解压/扫描、Markdown 解析和编码在真正的 Web Worker 中执行，临时内容分块保存在浏览器中；UI 只协调进度和有界请求。Host 异步读写文件，每次上传最多 1 MiB，一次最多持有一个单文件内容；同步二进制按需读取、整库 ZIP 按块输出并等待下游接收，不把全库堆入内存。
- 同库只允许一项导入/转存/引用准备任务，服务端按窗口和仓库校验。普通阅读、其他笔记编辑和会话输入可继续。收起面板保留进度，取消终止后续工作；已进入正式提交的单篇等回执后准确计数，已完成笔记保留。退出运行窗口不提供跨重启续传；临时目录仅按任务归属清理。
- PDF/图片转换另有保护：单次图片输入总量 128 MiB 或累计 1.28 亿像素；超过时改选材料或用 Markdown ZIP。它限制渲染的内存开销，不限制原件保存。已有页面尺寸/转换预算继续保留。
