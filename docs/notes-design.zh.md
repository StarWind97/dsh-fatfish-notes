# DSH笔记产品与存储设计

本文记录版本 `0.5.0` 的有效设计，功能与 `0.5.0-rc.12` 一致。日常操作见[使用说明](user-guide.zh.md)，首次发布工作按[分步规划](plans/2026-11-04-first-release.zh.md)推进。

## 产品范围

产品名称为 **DSH Notebook**，当前副标题为 **私人笔记管理**，中文简称保留 **DSH笔记**。首发以现有笔记能力介绍产品；长期探索利用宿主 AI 进行知识组织与内容输出，具体功能另行规划。代码仓库和安装包标识继续使用 `dsh-github-notebook`，默认私有笔记库名仍为 `dsh-notes`。

将 DSH 会话原样保存为个人笔记，手动编辑 Markdown 图文，通过同一个 GitHub 私有仓库在自己的设备之间继续使用。笔记和会话均可导出为本机文件。

正文由用户手动修改。标题、标签和摘要也可手动修改，会话转存时可显式选择模型建议这三个字段。原始选材和已归档图片作为来源资料保存，日常正文编辑独立于原始素材。

## 首次接入与同步

首次使用需要 Git、GitHub CLI、GitHub 个人账号及一个专用私有笔记仓库，并在完成首次同步后进入笔记操作。缺少工具时提供安装链接与重新检测，账号认证使用 GitHub 浏览器授权。

首次引导面向没有 Git 知识的用户，按「准备同步工具 → 登录并选择云端笔记库 → 确认保存位置并同步」展示。解释资料保存在本机及用户自己的 GitHub 私有库，默认不公开，不存放在插件作者的服务器。Git 用于同步文件，GitHub CLI 用于账号授权，用户无需学习命令。分别标明工具已安装、账号已登录、首次同步完成，安装或登录成功不等同于上传下载成功。首次使用默认选择新建，换设备可连接已有库；推荐名称仍为 `dsh-notes`。本轮只调整引导、帮助与状态呈现，沿用现有身份校验、首次同步和存储机制。

初始化分为选择模式、检查、只读确认和已绑定四个状态。用户单选接入已有库或新建私有库。新建建议名称为 `dsh-notes`，可修改；本机建议目录末级随仓库名变化，用户明确填写的路径优先。确认页展示账号、仓库、完整本机位置及同步范围，绑定后设置页提供当前状态和位置管理。

已有库通过 `notebook.json` 核对格式、所有者及仓库稳定身份，同时校验笔记清单。首次连接与每次上传均核对私有状态。

已绑定后，本机保存可在临时断网时完成，界面显示尚未同步。恢复网络后宿主自动重试，打开笔记库也会检查更新。保存修订、原始选材、附件和笔记本随私有仓库同步，回收站内容包含在同步范围内。

异常退出遗留的同步锁，在确认所属进程已退出后恢复。正在使用的锁、无法识别的锁和无法确定进程状态的锁不会自动清除；锁的存续时间本身不作为回收依据。

并发修改同一篇笔记时保留带冲突版本后缀的独立文档，供用户改名、编辑或删除。重复同步保持已有冲突结果。

## 本机位置与仓库切换

默认控制目录由 `DSH_HOME/github-notebook` 确定；未指定 `DSH_HOME` 时使用用户主目录下的 `.dsh/github-notebook`。新绑定的资料夹默认为控制目录下的 `libraries/<仓库名>`。活动绑定、各库最后使用的位置及本机身份保存在当前设备。

更换本机位置会暂缓写入和同步，复制并核验笔记、附件、本机任务和 Git 缓存，再切换位置并清理已迁移的插件文件。失败继续使用原位置，断网期间也可搬迁。

日常跨设备使用同一个私库。需要换用另一套资料时，通过重置入口从 A 切到 B。目标库先在独立资料夹完成同步，离开 A 前再次取回 A 的远端更新，并在暂停本机写入时确认本机与远端一致。两边成功后才切换，取消或失败继续使用 A。

从 B 切回 A 时，按 GitHub 账号 ID、仓库 ID 和本机资料标识验证记住的 A 位置。验证通过后由用户确认复用；原位置失效时提供选择原资料夹位置或新建本机资料夹两个入口。新资料夹从远程 A 同步。成功搬迁或切换后更新本机位置记录。

## 阅读与编辑

笔记库跟随宿主的浅色、深色和跟随系统设置。左栏顶部可选择笔记本或全部内容，列表显示正文摘要，默认最近修改在前，可切换为最早修改在前。列表宽度随窗口适应并允许在约束范围内拖动，阅读和编辑区域支持标准宽度与全宽。

阅读页展示标题、最后修改时间、标签、摘要和正文。时间采用 `2026-11-03 18:21` 格式；标签在同栏靠右，窄窗换行。摘要以引用式样呈现，在标签下方与正文之间用分隔线区分。点标签筛选时，左栏显示可清除的筛选标记，清除后保留搜索、笔记本和排序条件。

点击编辑或双击段落后，在原阅读位置打开 Markdown 编辑器。标题、笔记本、标签、摘要和正文组成一份草稿，摘要使用独立输入框。保存一次提交整份草稿，取消恢复已保存内容。新稿取消后笔记列表保持原状；切换有未保存修改的笔记时先处理保存或取消。

编辑器支持各级标题、粗体、斜体、删除线、有序和无序列表、任务列表、引用、行内代码、代码块、链接、图片、表格、分隔线、缩进、查找与撤销重做。编辑区按光标位置显示语法和预览，工具栏使用图标并随宽度收纳次要功能。

图片可通过剪贴板、文件选择器、拖放或公网 HTTPS 图片地址导入。图片以附件归档并在编辑区预览。剪贴板只有文件路径文字时提示使用文件选择器。

正文与只读原始素材可便捷切换并恢复阅读位置。顶栏在空间允许时展示操作，窄窗使用锚定菜单。回收站常驻左栏，支持移入后立即撤销和日后恢复。

## 会话转存

已完成回答下方并列展示保存到笔记与导出。默认图标和文字，也可在本机外观设置中选择仅图标。

点击保存到笔记后，留在会话并默认勾选当前问答。其他已完成回答下方可勾选轮次，输入区上方显示数量和操作。按消息细选可单独取舍问题与回答、选择目标笔记本及 AI 建议。整个会话、轮次选择与细选之间往返会保留手选项。

点击保存才创建笔记，内容来自固定截止点的选中消息，保留角色、顺序和可归档图片。原始选材另存为只读来源。可选模型建议调用宿主会话模型，只生成标题、摘要和标签，失败时仍可使用已经保存的原文。

选材使用宿主提供的回答操作、轮次末尾和输入区扩展位置，按记录序号关联已完成回答。首次接入规则适用于会话入口。

## 文件导出

笔记从阅读页打开导出弹窗，支持取消、关闭和 Esc。导出使用已保存修订，可分别选择包含标签、包含摘要，以及是否附上原始素材。内容顺序为标题、修改时间、标签、摘要、正文；Markdown 的文件头与可见字段使用同一选择。

会话导出默认当前问答，也可选择整个会话或自选消息。范围以固定截止点的可见记录为准，按原顺序区分用户与 AI，在内存中直接生成下载文件。

纯文本 Markdown 为单文件，带归档图片时提供包含同名 Markdown 和相对路径附件的 ZIP。另支持 PDF、单张长图和分页图片。过长内容可使用分页图片。历史不完整、图片缺失或网页图片仅保留链接时，在下载前提示用户选择。

## 存储与运行边界

资料夹中的 `notes/` 保存笔记文档、不可变修订、原始选材、归档图片和笔记本，Git 缓存位于 `backup/repositories/`。同步按笔记对象合并并校验结果。

采集与模型任务日志、本机位置及界面偏好保存在本机，模型凭据由 DSH 管理。HTTP 接口执行 loopback、Origin 和 sec-fetch-site 校验，文件操作校验路径与仓库身份。字体及必要许可证随安装包分发。

## 后续备忘

本地 Markdown 文件导入在首次发布后优先安排。阅读区右侧操作面板及 AI 选项留待后续规划。笔记直接附加到会话需要宿主提供合适接口。
