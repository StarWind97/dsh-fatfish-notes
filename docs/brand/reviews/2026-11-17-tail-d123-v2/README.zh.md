# 饱满尾瓣第二轮：D1 / D2 / D3

2026-11-17，按[正式规划及途中反馈](../../../plans/2026-11-17-clean-arc-tail-variants.zh.md)制作。当前状态：**预览完成，待用户评审；未接入插件、未发布。**

## 设计依据

用户要求基于 C 去掉背景鱼尾，只留上方弧线；前景鱼尾保留原有感觉与轮廓，三档逐渐增大，下尾可适度肥大和加粗。首轮细长稿被否定后，本轮直接使用 C 原有的曲线控制点序列作局部扩张，固定鱼身连接端点，保留上下不对称和圆润端部，增加实色面积。

背景左端收口缩短并略上移，与前景保持真实透明间隔。单色仍分开，双色沿用浅绿 `#B7C9B3` 弧线、提亮绿 `#3F5A4E` 或米白 `#F7F4EB` 前景。三稿的鱼身主体、眼孔和视框保持原样；字形未修改。

| 稿件 | 尾部面积（D1=100） | 24 px 方块内尾部宽 × 高 |
| --- | --- | --- |
| D1 · 圆润 | 100 | 5.57 × 10.70 px |
| D2 · 丰盈 | 127 | 6.02 × 11.89 px |
| D3 · 充盈 | 156 | 6.47 × 12.99 px |
| A（大小参照） | 不参与面积递增比较 | 5.56 × 10.54 px |

面积以尾部轮廓在两个身体连接点之间闭合后计算，四舍五入；尺寸为同一标称方块内的投影。它们辅助确认逐档增大，不能替代观感。仅角点端点位置不代表实际边界，尺寸采用浏览器路径边界测量。
