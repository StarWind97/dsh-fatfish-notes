# 肥鱼笔记图标方案：界面变化审查

2026-11-16。审查基线：`main` / `60253c8`。审查开始时工作区干净。本轮只更新会话内的方案与预览，不实施 Logo 接入。

## 结论

需要局部调整，主要是设置页位置清单、接入边界、主题跟随与验证范围。已确定的鱼形和中英文字形无需重做；「小入口纯图形、较大介绍场景品牌组合」的分工保持。

原方案将「首次接入／设置标题」合并处理，已不够准确。现在必须区分：

1. 首次接入，以及 DSH 自身设置中未分组的肥鱼插件表单：原 44 px 图标容器仍可见，替换为约 28 px 鱼形。
2. 肥鱼主界面／独立窗口 → 设置 → 同步与存储：`grouped` 表单中 `.setup-icon` 和品牌小字被明确隐藏，保持隐藏。
3. 分类设置页的外层：替换顶栏的 20 px 品牌图形；「设置」标题、分类导航、帮助卡片均保持功能表达。用户随后指定帮助页底部展示完整品牌，第三版已将其纳入方案，其他分类不增加大图。

## 仍适用的位置

- DSH 展开侧栏入口仍为 16 px，插件仍单独输出书本路径；宿主小图标槽规则不变。
- 会话顶部入口和会话笔记标题仍是 17 px，主界面／独立窗口品牌仍为 20 px。
- 欢迎区原 32 px 书本仍可按方案改为 48—64 px 双色鱼形。
- 插件包图标、市场图片、favicon、README 和介绍封面的分工未被此次界面调整改变。

上述判断来自当前源码和提交差异；本轮未安装新图标，不能称为接入后的验收。

## 用户补充：帮助页底部完整品牌

场景 11 使用用户提供的 1556 × 1223 截图，去掉位置红框，以原矢量轮廓合成 480 px 组合；没有修改应用或替换日常安装。透明底仅去除原 SVG 整张底色，品牌路径不变。其余设置分类、分组图标隐藏、帮助书本、侧栏齿轮规则保持。
