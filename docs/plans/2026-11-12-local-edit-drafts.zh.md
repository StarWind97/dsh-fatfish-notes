# 编辑期间保存本机草稿，结束编辑后统一提交

状态：2026-11-12 已按用户批准完成实施和开发验证，待集中体验。[交付与实测](2026-11-12-local-edit-drafts-results.zh.md)。属于 E 阶段验收修正，替代[上一轮方案](2026-11-12-stage-e-refinement.zh.md)第 5 项的取消逻辑；不启动 F，不发布版本。

## 已确认行为

- 编辑中的标题、摘要、标签、正文和附件持续保存到本机草稿，覆盖同一草稿，不生成正式笔记修订，不提交或上传到 GitHub。
- 完成编辑、切换笔记、离开笔记页面时，统一保存为正式版本，返回阅读态，后台提交和双向同步。没有实际内容变化时不产生新修订。Git 可合并短时间内多篇笔记的更新。
- 点击取消：有修改先确认，放弃本次草稿，原笔记不变；新建草稿直接丢弃，不进入回收站。已上传到本机的草稿专属图片/附件安全清理，共用文件保留。
- 临时切到其他应用、文件选择框等仅落盘草稿，不结束编辑。
- 正常关闭尽力完成本机保存；崩溃、强制退出时不依赖关闭回调。下次启动自动恢复并完成本机草稿，进入阅读态，再同步。已完成的同一草稿重试不能重复生成修订；断网不阻止本机完成。
- 草稿独立于同步内容。保留窗口编辑占用、版本校验和冲突保留副本的规则，不覆盖其他窗口或设备的新内容。

## 实现与边界

保留现有正式笔记格式和 Git 同步协议；新增本机草稿存储及保存/完成/丢弃接口，接入编辑控制器、启动恢复、离开事件及附件保留检查。浏览器保存尚未送达宿主的末次输入，宿主原子写入持久草稿，二者用编辑标识核对完成/取消，避免重放。草稿文件不参与云端同步或库导出。

不改为每次按键提交，不增加手工恢复流程，不修改日常 DSH 资料，不增加依赖。关闭时不能保证网络完成，允许下次继续同步；电脑突然断电时只能恢复已经落盘的输入。

## 验证和性能

按第三档运行类型检查、构建、全量回归。专项覆盖连续草稿保存不增加修订、一次完成、无变化完成、取消已有/新建、丢失响应重试、重启恢复、附件共享及丢弃、双窗口编辑、离线完成与恢复联网同步。真实验证仅使用项目内隔离 DSH 和指定私有测试仓库。

同一测试资料测量 5 次自动保存与完成接口的中位数/最大值，并统计连续编辑的正式修订数量；本机保存不等待网络。截图/体验入口及实际覆盖范围记录在交付文档中。

中等规模存储与控制器调整。失败保留草稿供重试；回滚代码前先完成或导出本机草稿，不能删除未完成草稿。完成后更新入口、设计及用户说明，提交同步 main，打开隔离体验窗口供验收。
