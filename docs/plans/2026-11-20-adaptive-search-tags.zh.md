# 共用筛选面板的常用标签排版

2026-11-20 用户确认按宽窄对照原型实施。选中项用主题底色、文字颜色和边框标记，尺寸和文字结构一致。起点为 main 的 717a389。

- 标签用名称和篇数的内容宽度紧凑排列。数量由标签实际宽度和面板空间决定，布局最多三行，较矮的笔记区用两行。
- 常用标签沿用全库篇数排序。「查看全部」按名称浏览，名称查找覆盖整个目录，目录区可独立滚动。主界面、独立窗口和会话侧栏共用该组件和主题样式。长标签缩略显示，完整名称可悬停查看。选择、替换和取消操作沿用当前筛选。
- 改动落在 `SearchFilterPanel.tsx` 和纸面布局样式，以及构建产物。复用当前目录、缓存、笔记读取与现有浏览器能力。风险集中在拖动宽度后少露一项或露出半行、选中后边框改变尺寸、短窗结果可用空间和大目录处理的耗时。
- 按第二档运行类型检查、构建、相关测试。在隔离桌面、独立窗口和 Web 以实际标签检查换行、选中几何、目录和矮窗。用同一资料与尺寸量开面板及选标签，包含一次首次与后续五次。交付可重开的隔离入口；回退可重装[上一候选](2026-11-20-unified-search-ui.zh.md#体验与回退)。
