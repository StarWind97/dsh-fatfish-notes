## 性能与边界

在同一 Desktop、1460×980 内容尺寸、同一篇「从会话继续 · 文件与笔记」上，计时从点击到标题可见并完成两帧绘制；每组 5 次，包含 UI 操作等待，不是纯接口耗时。

| 操作 | 修改前中位 / 最大 | 修改后中位 / 最大 |
| --- | --- | --- |
| 侧栏打开同一篇笔记 | 289 / 375 ms | 386 / 574 ms |
| 侧栏切换到工作区笔记本列表 | 原版没有对应浏览入口 | 277 / 452 ms |

本轮没有把速度提升作为交付结论：正文显示中位数增加约 97 ms，当前这组最大值仍低于 0.6 秒。基线为 104 个笔记 ID、327 个修订；验收中增加一篇图文笔记，后测为 105 个 ID、341 个修订，两组都约 541 MiB 当前文件。目标正文和宿主尺寸相同，资料规模有上述小幅变化。未测冷启动，不把这组数据作为所有设备的性能保证。

另对 162,000 字节的重复 Markdown 在真实宿主统计线程单次测量：约 250 ms 返回 33,000 字/词；主线程 10 ms 心跳持续 24 次，最大间隔约 11 ms。这只验证统计线程不会持续阻塞界面，不代表同等长文的渲染和同步也只需该时间。

## 集中体验

通过 [Open-Fatfish-Notes.cmd](../../scripts/Open-Fatfish-Notes.cmd) 打开隔离资料：

1. 打开「E0 普通附件与生成文件」，点顶部「会话笔记」。比较来源、关联、工作区笔记本、查找四个页；搜索只在最后一页出现。
2. 在「查找并关联」选「B—D 体验」或「E 阶段 · 会话资料」，打开笔记后返回，试关联、解除与撤销；拖窄侧栏检查本列表折叠。
3. 用回答下的保存/导出入口检查深浅色、笔记本选择、附件列表和底部按钮；取消不会保存或导出。
4. 主笔记库中打开「侧栏验收 · 临时工作区」笔记本里的「侧栏体验 · 代码与资料」，试代码复制、字数、快捷键说明及阅读/编辑切换。这个笔记本作为测试资料保留，与已移除的临时工作区无依赖。
