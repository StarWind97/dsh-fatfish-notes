## 最终用法

| 位置／逻辑显示尺寸 | 图形 |
| --- | --- |
| DSH 入口 16 px、会话入口和侧栏标题 17 px | D2；宿主入口单色，侧栏标题双色 |
| 主／独立窗口内部标题 20 px，以及通用 24 px | D1 |
| 接入表单 44 px 容器中的 28 px | C0 |
| 更大尺寸，包括插件列表约 36 px、欢迎区 64 px | 原版 |
| 独立窗口原生标题栏、任务栏及浏览器 favicon | 固定 D1 提亮绿圆角方块，所有位图分辨率保持同一鱼形 |
| 帮助、介绍、完整品牌组合 | 原版图形与原中英文字路径 |

组件与通用 PNG 共用尺寸规则：≤17 px D2，>17 且 <28 px D1，28 px C0，>28 px 原版；按逻辑尺寸而非屏幕倍率切换。独立窗口因多个系统位置共用 favicon，采用固定 D1 的已确认例外。

15 份 D2/D1/C0 SVG 与获选评审快照逐一相同。原版、字形、提亮绿 #3F5A4E、米白 #F7F4EB 与页片绿 #B7C9B3 保持。A/B/C/D3、历史图册及用户反馈均保留；旧 A 资源不再被当前组件与生成器引用。

## 任务栏缓存问题与修正

初次包内文件及页面已匹配 D1，但两次正常重开后的原生图标仍更接近旧 A。失败记录和截图保留，不能用资源替换成功代替任务栏验收。

在既有 favicon 管道内，为 ICO、PNG、SVG 四个地址加入由源 SVG 内容生成的版本标识。摘要生成前统一换行，避免 Windows／Linux checkout 差异产生无意义版本。当前版本为 `b41c1aab9b1ad046`；路径白名单与来源栅栏保持，没有清空浏览器资料、引入轮询或改造原生窗口。

修正后 16 px 原生图标与 D1 的平均像素差约 0.68，与旧 A 约 14.13；32 px 分别约 8.23 和 17.17。Windows 缩放导致结果并非逐字节相同，因此同时检查了原生图标提取和真实任务栏／标题栏截图。最终两者均显示彩色 D1。
