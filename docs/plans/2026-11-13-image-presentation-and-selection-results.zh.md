# 图片展示切换与笔记多选：验证与交付

日期：2026-11-13。依据[已批准规划](2026-11-13-image-presentation-and-selection.zh.md)实施。属于 E 体验修正，保持原存储格式与依赖，未发布、未启动 F。

## 交付行为

- 截图、单张图片、纯图片批次粘贴或拖入正文，默认展示图片；图片与其他文件混合时，整批按顺序显示下载链接。显式「插入图片 / 插入文件」优先，补充区保持独立。不能内嵌但可安全保存的图片保留原件链接并解释原因。
- 图片及受支持图片文件链接可从省略号、右键或编辑器选中项切换展示方式。修改当前出现位置，可撤销 / 重做；共享引用定义和其他出现位置保持。阅读态先进入编辑，完成 / 取消沿用原规则。展示图片时仍可下载原件。
- 已登记图片切换只改 Markdown。旧普通附件首次转换从本机原件校验并登记图片，不重新上传；原附件继续供历史、其他引用和撤销使用。持久草稿支持未保存文件，异步结果必须重新核对编辑资格、资料根和目标文字。
- 主列表、独立窗口、侧栏三个列表进入多选后，标题、摘要、时间、留白及复选框都只改变选择；双击只切换一次，Enter / Space 行为一致。单篇菜单及引用、关联按钮暂时隐藏。主列表改变筛选清空选择，侧栏跨笔记本选择仍保留。

## 响应测量

测量时未并行运行构建、安装或全量测试。同一隔离 Desktop、1660×1100、相同体验资料与「复制粘贴与拖放 · 体验」正文，Windows 原生 480×160 位图，每组 5 次，粘贴后等正文变更、进度结束及图片加载，再撤销。

最初基线（新增本轮体验笔记前）中位 / 最大为 276 / 346 ms。完成较长的功能验收后，最终候选首组为 273 / 466 ms；这一组与重启后的旧候选有状态差异，不据此计算版本增减。

为核对差异，在相同资料上先后安装旧、最终候选，各自重启后按同一流程测量。两组期间没有新增或修改正式笔记，导航显示 113 篇；均经历启动自动同步，结束采样时同步仍在进行。结果如下，不代表所有网络繁忙场景：

| 操作 | 样本 | 中位 | 最大 |
| --- | --- | --- | --- |
| 旧候选原生粘贴至图片加载 | 248 / 165 / 132 / 250 / 149 ms | 165 ms | 250 ms |
| 本轮候选原生粘贴至图片加载（宽度收尾前） | 259 / 159 / 134 / 130 / 120 ms | 134 ms | 259 ms |
| 最终候选图片改为链接 | 5 次 | 29.3 ms | 35.4 ms |

后两项从真实点击事件到两帧后的界面状态计时，不含展开菜单、自动化等待或宿主启动。图片切换期间文件接收 / 导入请求为 **0**；两项达到规划中位 ≤100 ms、最大 ≤200 ms。上述同资料重启对照中，原生粘贴中位未出现超过 20% 的回退，最大值仍有波动。每组仅 5 次，不能据此宣称普遍提速或消除全部长尾；全量功能测试期间的自动化点击耗时不计入本表。

最终截图复核曾发现图片已加载但布局为零，稳定重开时可显示，含重渲染时机因素；现为容器增加明确内容宽度，验收改为同步刷新后检查实际尺寸。最终包五次切换均为 480×160，380 px 窄窗口中为 308×103，已查看截图。该收尾仅改变两个客户端构建文件中的一条宽度样式，Host / 传输 / 保存逻辑完全一致，包对比见 `layout-package-diff.json`。

布局收尾后的最终包再次完成五次原生粘贴抽查：640 / 359 / 269 / 283 / 280 ms，中位 283、最大 640 ms。这是后续长会话热态，资料包含新增的测试恢复 / 回收站记录，与上表重启对照条件不同，不据此计算版本回退或加速；本轮仍有时序与长尾波动。
