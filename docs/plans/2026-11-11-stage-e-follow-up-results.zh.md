# E 后续修正交付

## 本轮行为

- 侧栏提供新建笔记：第一次有效保存即关联当前会话，优先使用工作区默认本，可手动换本；空白退出不创建笔记。「从本会话保存」成为「关联的笔记」内的筛选，「查找笔记」保留按本浏览和搜索。
- 笔记本列可拖动、键盘调整并记住宽度，默认 220 px、偏好范围 160–340 px，实际宽度受侧栏可用空间约束。关联操作放在条目右侧，就地更新并保留原列表位置与已加载页。
- 侧栏笔记本列底部可新建普通本，工作区绑定默认不勾选。没有工作区默认本时，「关联的笔记」内提供轻量设置入口；已有默认本时显示实际名称，可改名、更换或解除绑定。条目菜单明确区分全局默认和当前工作区默认。
- 转存条改为「下一步」，已选数量与空白区域也能打开保存选项。纯文字与含附件使用同样流程，最终确认才保存。转存面板只选已有本，创建和工作区设置统一在侧栏或笔记本管理页。
- 保存选项采用宿主页面内居中弹窗：宽窗口两栏，窄窗口单栏，标题和底部操作固定。Esc、关闭和返回会话保留选材；转存条「取消」才结束本次选择。
- AI 元数据改用宿主公共辅助模型服务，不向当前会话发送提示词、不创建隐藏聊天、不调用 Agent 工具。摘要通常 50–120 字、上限 200 个可读字符且为单段；标题上限 60 个字符、标签最多 5 个。格式不合格最多补试一次，失败保留原文。已有旧通道任务终止而不继续污染会话。
- 普通保存成功提示约 5 秒收起；关联解除、移入回收站的撤销提示约 8 秒收起，悬停/聚焦暂停，切换上下文清理。失败状态不按成功计时隐藏，后台任务不会因收起提示而取消。
- 主界面、独立窗口及侧栏使用相同的条目「…」和右键菜单；复用既有修订/编辑保护与危险操作确认。主界面列表顶部固定，只有条目滚动；正文所属本另行标明，不为高亮而改变全部笔记或搜索范围。
- 修复侧栏新建的字段顺序与保存结果不同而反复自动保存的问题。规范化比较后，保存稳定完成，重启读回保留正文、笔记本和会话关联。

本轮不改变正文/附件格式，不加入 AI 整理正文，不自动修改历史长摘要。原有已生成的长摘要可手动编辑；新限制只约束新生成建议。

## 性能结果与未掩盖的边界

同一 Desktop、1460×980 内容区、同一组原有笔记。计时从自动点击到目标可见并完成两帧绘制，包含 UI 自动化等待，不是纯接口耗时；修改前后各 5 次。原资料 106 篇、353 个修订，修正后测量 110 篇、446 个修订（增加验收笔记和修订），附件约 541 MiB。此次未测完整宿主冷启动，不用热切换结果代表冷启动。

| 操作 | 修改前中位 / 最大 | 修改后中位 / 最大 |
| --- | --- | --- |
| 侧栏打开「参考资料 · 装备清单」 | 196 / 286 ms | 416 / 618 ms |
| 切换到「E 阶段 · 会话资料」并显示目标条目 | 259 / 272 ms | 357 / 654 ms |

新增交互各测 5 次（没有相同旧交互的基线）：菜单展开中位 94 / 最大 103 ms；保存选项中位 291 / 最大 2718 ms（首次较慢，后续四次 234–441 ms）；连续写入关联中位 3446 / 最大 4522 ms。关联请求提交后显示处理中、其他浏览仍可继续，不能把该等待说成已消除。

从实现看，关联会创建笔记修订；本地写入使校验缓存失效，后续读取重新检查修订，且与其他本地仓库操作共用队列。连续关联测量因此比纯阅读慢；本轮不通过省略完整性检查来换速度。后续应单独测量写后校验和队列等待，评估安全的增量校验，优先解决连续写入后的短时延迟。尚未完成细分计时，不能将全部耗时都归因于单一环节，也不是 GitHub 网络往返的耗时。

本轮热阅读中位数增加约 0.1–0.2 秒，最大未超过 0.7 秒；功能增加和修订数量变化均可能影响结果，不宣称性能提升。此前的大文件、同步、会话生命周期边界继续见 [E 验收修正](2026-11-11-stage-e-review-results.zh.md)。macOS、宿主永久删除会话接口仍未真实覆盖。

## 集中体验

入口：[Open-Fatfish-Notes.cmd](../../scripts/Open-Fatfish-Notes.cmd)。这是项目隔离资料，可安全操作已有测试笔记。

1. 打开「E0 普通附件与生成文件」的会话笔记侧栏，试新建、查找、调整笔记本列宽，以及条目右侧关联与菜单。
2. 在会话回答下点「保存到笔记」，选材后点空白或「下一步」；切换本、勾选附件、Esc 返回继续选，再确认保存。
3. 如勾选 AI 建议，原文先保存，后台完成短标题/摘要/标签；当前聊天不会增加新问答。已有长摘要不自动重写。
4. 在肥鱼笔记主界面滚动列表，检查顶部控制区；打开跨本笔记，检查左侧所属本提示；尝试「…」和右键菜单。
5. 点独立窗口入口，继续阅读或编辑；撤销提示等待约 8 秒或切换页签后应收起，回收站和重新关联入口仍可用。

验收后先处理实际问题，再回顾主规划 F 的候选清单及下一版发布范围；不自动开展未选定的候选功能。
