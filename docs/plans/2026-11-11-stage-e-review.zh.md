## 已确认范围

1. 会话保存的笔记本下拉框适配深浅主题。会话导出弹窗不透明，标题与按钮固定，内容独立滚动，侧栏样式不影响弹窗。
2. 来源笔记自动算作与本会话关联；「关联的笔记」列出来源和手动关联并去重。「从本会话保存」仍作来源筛选。来源显示已关联，其他笔记可关联/解除并撤销。一篇可以关联多个会话，解除一处不影响其他关系、笔记归属及原始素材；关联不自动发送给 AI。
3. 搜索只位于「查找并关联」内。浏览时为笔记本列与笔记列，窄侧栏折叠笔记本列；进入正文后只显示阅读/编辑区，返回恢复浏览位置。空搜索不默认加载全库；选本后搜索该本，允许切换全部笔记。
4. 按本机私人库及工作区记住上次有效笔记本，否则选择工作区默认本，否则展示笔记本列表。已映射时在「关联的笔记」与「查找并关联」之间显示「工作区笔记本」。未映射时醒目提供新建/选择已有入口。新建建议名用工作区名称，允许修改；改名不解绑、不强制同步名称。
5. 归档/恢复保留关系；会话删除保留笔记及原始素材，停止对失效会话的转存与引用；工作区移除保留笔记本与笔记，失效默认不继续使用。同名新工作区不继承旧映射，其他设备缺少会话不清理同步的关联。打开中的页面及时刷新/提示；不做全库自动清理。
6. 补齐正文统计、已有快捷键说明及代码块复制。统计不计 Markdown 标记、图片地址等，中文逐字、英文按词，提供口径说明；编辑延迟更新。复制只取代码本体，保留缩进和换行，反馈成功/失败，覆盖阅读与编辑预览。不新增全局快捷键或自定义系统。

## 方案、影响与回退

沿用现有笔记本、搜索、自动保存及同篇编辑保护。不复制出另一份笔记，不要求重复关联来源，不凭名称猜关联。浏览组件独立于阅读组件，局部状态按仓库/工作区隔离。列表响应增加当前会话关系标记，来源/关联存储继续使用 manifest v3，不迁移正文和附件。生命周期读取使用宿主公共接口。

主要影响 `ConversationNotes`、会话保存/导出样式、查询契约和 repository 关联筛选、宿主会话上下文、Markdown 渲染/编辑及 locale。复用现有依赖；统计重计算放后台线程，避免新增长文输入阻塞。风险是样式串扰、快速切换后的旧响应、失效宿主状态、关联重复、复制/统计把语法或按钮文字混入内容；按下列场景验证。正常回退本轮代码与本机浏览偏好即可，不重写历史或更改资料结构。

## 顺序和验收

先测同一资料的侧栏读取基线，再修弹窗 → 浏览与关系 → 生命周期 → 常用功能 → 集中验证。工作量中等，交付代码、中文操作说明、真实截图、结果与可重启体验入口。

- 因涉及关联写入，按第三档类型检查、构建、全量测试；局部开发期间只跑相关测试。
- 深浅主题；打开/关闭侧栏前后导出；窄/矮窗口、长附件列表、底部按钮、Esc/取消；下拉框展开检查。
- 多本、无映射、默认映射、浏览记忆、书名变化、失效回退、搜索范围和返回滚动；一次关联多会话、来源自动关联、解除/撤销、复制与换本。
- 指定隔离 DSH 临时会话/工作区的归档、恢复、删除和移除；不改日常资料。退出或移除时仍保留笔记编辑和图片附件；真实私库仅使用指定测试仓库。
- 中英混排、Markdown 标记、链接/代码、长文；统计延迟更新、代码复制保真；实际快捷键及宿主输入框无冲突。
- 同一资料、宿主和尺寸测侧栏读取各 5 次，中位/最大值；新增笔记本浏览另测 5 次，区分接口与实际显示；读取不等待网络。检查长文输入不增加持续阻塞。
