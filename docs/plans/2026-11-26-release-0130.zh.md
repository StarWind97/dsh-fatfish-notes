## 二、已批准实施清单（阶段一）

1. **流程沉淀**：新增 [docs/release-sop.zh.md](../release-sop.zh.md) 并从 [docs/README.md](../README.md) 链接，固化发版前核对、图文同步、升级与性能抽查及发布后复核全流程。
2. **代码防错加固、`QuickSwitcher` A+B 与测试补全**：
   - `src/client/styles/inject.ts`：当同一 key 存在活跃引用（`entry.count > 0`）却传入不同 CSS 字符串时抛出错误，杜绝静默覆盖；在 `test/quick-switcher.test.ts` 补单测校验冲突抛错及全库 `src/client/` 样式注册 `(layer, id) → css` 唯一性。
   - `src/client/QuickSwitcher.tsx`：
     - **A**：结果按钮增加 `onFocus={() => setActiveIndex(idx)}`，保持键盘 `Tab` 焦点与视觉高亮一致；
     - **B**：打开时使用 SSR 安全的 `useLayoutEffect` 直接同步调用 `inputRef.current?.focus()`，消除原先 1 帧（~15 ms）的 `requestAnimationFrame` 延迟。
   - 回归补强：`test/browser/check-switcher-sidebar.mjs` 补 24 项显示上限断言与 `Tab` 焦点同步高亮断言；`test/shared-appearance.test.ts` 补「升级后调用 `.set({ size: 20 })` 追加操作」与「待写队列含未知/原型非法值被拒绝」断言。
3. **随包用户手册升级至内容版本 `v6`（中英文）**：
   - 保留 `assets/handbook/v4/`、`v5/`、`en/v5/` 不可变；新增 `assets/handbook/v6/` 与 `assets/handbook/en/v6/`；

   - 内容对齐：`+ 新建`、编辑态「编辑属性」抽屉、`Alt+K` / `⌥K` 快速切换、「全部 / 收藏 / 最近」分段、保存选项缩略图与底部「取消」、空目录自动收起、「设置 → 帮助」反馈入口。
