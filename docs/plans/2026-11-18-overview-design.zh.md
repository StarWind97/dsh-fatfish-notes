# 概览品牌排版与标签浏览

2026-11-18 用户确认独立评审页内最后一版主案并批准实施。基线为 `5ce6427` 和[阅读区概览与标签页交付](2026-11-18-reading-overview.zh.md)。

## 目标与取舍

- 概览去掉标语与简介，居中组合原版彩色鱼形与原版矢量中文标准字。新建笔记、在线使用说明在品牌下居中同高，主按钮用品牌色。沿用宿主深浅效果，浅色使用暖纸色、深色跟随产品主题。将分隔线留在组边界，用行距和标题层次呈现笔记。
- 以桌面为主，按实际阅读区宽度选择双列或单列。小屏品牌整体收缩，操作空间不足时纵向排列。沿用现有最近打开／最近修改的独立排序与每组 5／10／15 篇上限。选中笔记、启动恢复及标签页行为沿用上一轮。
- 真实标签区紧接两组记录。存在标签即同页可滚动到达，不按宽高藏起；无标签不占区域。按使用次数展示前十个计数，排除回收站。点标签进入全库对应结果，可打开笔记、继续分页并返回概览。小屏仍保留可见的返回入口。离开标签浏览时恢复进入前的列表筛选。

## 数据与验证

- 从配套品牌生成器引入原稿字标，保留字形和颜色。标签计数复用既有本机列表读取与标签目录的口径，按同一批笔记视图计算，避免启动另发请求、二次读盘或正文解析。标签结果沿用本机只读列表接口、分页和既有打开笔记入口。影响客户端、只读列表响应及中英文文案，笔记格式、写入流程和同步协议沿用现有规则。
- 按第二档运行类型检查、构建、相关测试及实际隔离宿主。比较 790 px 左右阅读区和小屏显示，检查 320 px 窄窗无横向溢出、较矮窗口能滚到标签、实际数据计数、标签跳转/打开/返回、深色字标及新建和手册入口。沿用原隔离资料及上轮响应基线，核对概览请求数、首屏和实际操作耗时。
- 交付同一个隔离候选、桌面和小屏截图、可重开的体验入口及验证记录。需要回退时重装上一轮候选或撤销对应提交。

## 验证与体验

- 最终版本通过类型检查、构建和 81 项专项测试，其中 2 项覆盖真实本机 HTTP 路径。Windows rc.3 Desktop 和 rc.4 Web 均安装同一个候选包，各核对 254 个文件，SHA-256 为 `8bba0cb5f5f49084368518219853501d33796c7c8187ec13e916546badf3064c`。Web 匿名请求返回 401。
- 实际隔离笔记库中，标签和计数与标签目录一致。桌面用键盘进入标签、打开笔记、关闭后回到标签结果，再返回原标签及键盘焦点。Web 也走通这条路径。桌面新建进入编辑器，空白退出。在线说明核对了链接目标。
- 实际独立窗口 790 px 阅读区两栏各 10 篇，两个入口同为 45 px，浅色主按钮实测为 `#6C305E`。深色字标为 `#FFF7EE`。320 × 650 px 窄窗每组 5 篇、纵向排列，概览无横向溢出，滚动后触控模拟可进入标签并返回。小屏截图为窗口模拟。
- 桌面使用同一测试库、1260 × 880 px 插件区域和相同两篇笔记。上轮 176 篇，列表和概览一次样本分别为 1378／1430 ms，10 次切换中位和最大为 157／424 ms。本轮 179 篇，分别为 1518／1526 ms，切换为 164／364 ms。两轮首屏各一次，背景可能在同步。Desktop 和 Web 启动均未额外请求标签目录，也未自动读取正文。
