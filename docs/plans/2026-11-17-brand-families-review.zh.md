# 六套品牌场景组合评审

2026-11-17。用户已明确批准。在上一轮网页反馈中，12「紫莓薄荷」为首选，07「薄荷纸」同样喜欢，02「鲜翠」保留参考但有微信配色联想；结构未选定。基于此收拢为两条主线、每条三套场景组合。

## 目标与边界

- 六套：紫莓薄荷、偏蓝亮紫、偏红莓紫；薄荷纸、青绿与金黄、鲜绿与橙金。
- 每套展示完整中英文 Logo、透明鱼形、应用方块、主界面／侧栏位置、任务栏和宣传封面，允许不同场景调节颜色分工、留白和图文排列。
- 大尺寸沿用原版，小入口沿用 D2／D1／C0 的已确认分工；任务栏先用 D1，避免新配色与未选择的结构混在一起。另提供适度结构对照入口，不把此前未填写的结构选择当成批准。
- 单个图标全部纯色；不同候选之间改变冷暖、亮度等。字标保留现有矢量路径；不重绘字体、不加入圆形徽标。
- 本轮仅新增评审素材和辅助脚本，正式图标、产品 UI、主题规则、版本、公开宣传及发布不变。完整组合是候选，不宣称已经接入。

## 实施与取舍

1. 从现有原版、小尺寸鱼形、中文和英文字形派生，记录来源哈希。完整组合提供竖式与横式；浅深环境分别选择鱼身、叠页、文字的颜色。
2. 六套在同样的场景并排；品牌色变化只作用于品牌图形和宣传示意，插件界面保留宿主中性功能区，避免误将品牌探索扩为界面重构。
3. 网页概览、最多三套同场景比较、单套全景、实际尺寸及每个场景的偏好／说明。旧反馈只读展示，新意见独立自动保存。
4. 六个应用图标用上一轮已验证的临时原生清晰图像方式实拍选中／未选中任务栏，记录 PID、DPI、像素和裁片来源；不在产品里接入该临时方法。
5. 校验 SVG 字形／轮廓保留、色彩与透明度、页面与反馈保存、真实截图，持续回写本规划和结果。完成后提交推送并保留评审服务。

## 风险、回退与成本

- 场景变体过多可能削弱关联：用每套固定的主色、辅助色与同一鱼形、字标建立联系，页面允许直接比较是否仍像同一品牌。
- 浅色图形在浅底上易消失：这轮为透明 Logo 专门提供浅深版本，而非只去掉任务栏底色；页面展示实际用色。
- 不改系统主题／DPI，不声称高分屏或 Mac 已验。真实 Windows 任务栏和界面示意明确分开。
- 影响仅 `docs/brand/reviews/2026-11-17-brand-families/`、本规划、开发入口及启动脚本；正式资源只读，旧评审保留，可回看。关闭测试窗口撤销临时设置。
- 一轮六套完整预览，复用源稿与渲染、反馈和任务栏流程；无产品依赖新增，不写大型品牌规范。

## 验证与交付

- 核对原版和 D2／D1／C0 路径、中文／英文字形未重绘；PNG 对应显示槽位与倍率，不错误地把字号或几何随 DPI 改变。
- 查看完整组合、横竖排、明暗、透明鱼形、应用图标、界面和封面；模拟界面不充当实际产品截图。
- 检查对比、场景选择、下载、逐项反馈和总体意见、自动保存／刷新／新浏览器读回、失败保留与重试，以及窄屏。
- 只运行素材与评审脚本专项，不跑无关产品全量回归。交付新网页、可重开入口、证据与简短建议，等待选定后再规划接入。
