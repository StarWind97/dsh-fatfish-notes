# 分类管理与标签工作区

2026-11-20 确认实施。基线 b30c97f。采用用户评审过的桌面三栏原型。顶栏「分类管理」容纳现有笔记本管理列表和标签页，笔记筛选面板可直达当前标签。日常标签筛选只刷新笔记列表，保留原阅读页与位置。

1. 标签目录按名称、篇数查看，支持近似写法、仅用一次。中栏展示篇数、笔记本分布、最近更新时间，复用本机查找、排序、分页。右侧按需读完整正文，点击标签联动，单篇增删标签走既有修订与同步。
2. 改名、移除、两名合并在中栏确认。选合并目标时左栏搜索已有标签，支持逐一阅读、交换保留名、核对重叠与最终篇数。按钮只描述标签操作，另列全库影响。移除发起批量撤销的入口与接口；旧版未结束的任务仍能收尾。
3. 在隔离资料测量目录打开、筛选及阅读全文，常用操作重复五次。目标为目录输入本地响应、每次只加载选中的正文。覆盖上百标签、稀有标签、空结果、筛选中编辑、切换候选、写入占用或中断、恢复旧资料，执行类型检查、构建、全量回归及 rc.5 桌面和 Web 验收。

本次使用既有本机搜索、Markdown 渲染与普通笔记修订。增补本机目录统计，沿用现有笔记格式、主题和宿主版本。风险集中在两套阅读状态混用、预览期间并发写入以及展示范围与实际影响不一致。交付本机安装包与隔离体验入口。回退可重装前一候选，已写入笔记保有普通修订历史。预计单人 4–7 个开发日，公开发布另行安排。

## 实施记录

旧版基线使用 rc.5 的两份隔离资料，各有 157 篇笔记、81 个标签。相同 1360 × 920 窗口，从筛选面板点击管理到出现标签，Web 首次 208 ms，后五次中位 200 ms、最大 229 ms；桌面首次 166 ms，后五次中位 220 ms、最大 239 ms。

管理清单仅查当前版本，普通搜索沿用既有匹配规则。目录一次读取各标签的使用次数、笔记本分布、最近更新时间，正文随选择读取。合并预览在同一次读取中统计目标已有篇数，重叠只计一次。

隔离体验发现两处差异并据此调整。筛选面板打开管理页时，在导航前指定当前标签，避免恢复上次目录的第一项。后台同步刷新时继续显示同一份笔记清单、正文和影响说明，确认按钮等最新核对完成后可用。返回笔记时读取原文的最新标签。

## 验收

- Windows 桌面和 Web 均从日常笔记进入，选中一个原文未带的标签后，笔记列表切到其他笔记，当前正文及滚动位置仍保留。由筛选面板进入管理页时，打开的是已选标签。切回笔记本页仍显示原有列表。
- 桌面使用 119 个标签、Web 使用 120 个标签的隔离样本。检查了查找仅用一次的标签、近似名称、目录翻页、键盘选定与取消、输入新搜索后清除旧目标、交换保留名、查看两边笔记、阅读长文末尾。
- 两篇源笔记横跨两本笔记本，目标原有两篇，其中一篇重叠。将中栏缩小为一本笔记本、一篇笔记时，全库仍影响两篇。合并后目标的三篇笔记、源标签消失和正文保留均已读回。改名和移除也核对实际修订。单篇添加和移除标签后，原文仍可在右侧读完。
- 类型检查、构建和全量 424 项回归通过，未跳过。常规 Windows 临时目录复验通过；较深的项目临时目录曾导致测试用 Git 仓库同步失败。40 项集中回归通过，覆盖 103 篇结果的分页边界、仅冲突版本带标签的笔记、目标重叠、保存占用、写入中断和旧版未完成的整理记录。两份隔离安装分别按包内全部 259 个文件逐一校验。测试样本只写入项目专用资料。

Web 写入的标签改名经指定私库同步到桌面，两端持有同一个笔记 ID 和修订号；桌面清理样本后，Web 亦已核实移除。桌面直连 GitHub 一度无法核对账号，改用项目体验入口配置的本机代理完成。最终调整限于中英文影响文案，两端从同一包重新安装、核对文件，实际复查了「全库影响」与「确认合并标签」。
