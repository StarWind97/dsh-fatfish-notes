# 阅读区标签、概览与拖动排序

2026-11-19 用户确认实施。基线为 `main` 的 `44f21df` 和正式版 0.9.3。沿用[阅读区概览与笔记标签](2026-11-18-reading-overview.zh.md)的本机阅读和保存规则。

## 已批准交互

- 相邻的未选中标签之间加短竖线，当前标签与阅读区相接。原型比较了短竖线和独立底色，用户选择短竖线。
- 正常进入笔记主界面或独立窗口时，标签栏显示一张选中的「阅读区概览」。关闭最后一篇笔记或从右键菜单关闭所有笔记标签后，回到同一状态。仅剩概览时保留它。指定笔记入口直接选中目标笔记。
- 「+」贴着最后一个可见标签。点击后在末尾打开概览，已有概览时切回它。由选中的概览打开一篇笔记时，新笔记接替概览原来的位置。再次打开已在标签栏里的笔记时，切回原标签并收起这张概览。直接点击别的标签时保留打开的概览。
- 可拖动笔记或概览标签。拖到某张标签的左半边或右半边决定落点，拖到「+」处放到全部标签末尾。溢出菜单里的标签也可调整，右键菜单提供逐项向左或向右移动。重排保留当前阅读页和阅读位置，顺序跟随本窗口的标签会话。
- 会话侧栏采用共同的分隔、排序和溢出行为，关闭最后一篇回到侧栏列表。标签栏遵循原「显示本次打开的笔记标签」设置。窄窗需要在当前可见的概览或阅读入口继续访问标签及「+」。
