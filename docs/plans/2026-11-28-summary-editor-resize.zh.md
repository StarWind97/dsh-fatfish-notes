# 2026-11-28 编辑态摘要输入框高度

## 范围与选择

用户已确认编辑属性中的摘要框采用四项行为。展开后从两行起，随实际换行伸缩，自动最多八行。实际高度受笔记编辑区剩余可见空间限制。保留原生拖拽，手动可以超过八行并在本次展开内优先。内容超出当前高度时可在框内滚动，正文浏览沿用外层滚动。

变更范围为笔记编辑页的摘要输入框、现有属性抽屉及对应说明。采用浏览器内容自适应和原生垂直拖拽，组件测量编辑区边界。另一方案是用脚本反复测量文本高度并覆盖输入框尺寸，需额外处理换行和原生拖拽之间的冲突。优先采用前者，核对桌面和 Chrome 的实际表现。

## 验收与回退

- 普通高度窗口验证空白两行、自然换行增高和清空后缩回，宽度变化时行高随实际排版调整。
- 矮窗口和标签换行时测量编辑区底边与摘要框边缘，验证空间不足时展开或聚焦带入视野，主动滚向正文时页面可继续滚动。
- 粘贴超长摘要，核对自动八行上限、框内滚动和完整文本。实际拖动右下角验证增高、缩矮、超过自动上限、窗口缩小后的边界与重新展开复位。
- 执行类型检查、构建和相关回归。相同候选包串行安装到 release12-desktop 和 release12-web，核对包与实装逐文件一致并从宿主入口验收。摘要排版与拖拽验收使用隔离资料中的本机草稿。
- 风险集中在窄矮布局、焦点与原生拖拽叠加时的尺寸变化。以可见底边、焦点与编辑内容为验收依据。回退使用对应提交的回退记录和前一候选包。

## 最终验收

- 同一候选在 DSH 0.2.2-rc.5 隔离桌面和 Chrome Web 的笔记编辑入口通过。桌面与 Web 分别使用 release12-desktop 和 release12-web。普通摘要按自然换行增高，清空后回到两行。
