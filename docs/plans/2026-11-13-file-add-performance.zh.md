## 目标与依据

约 50 KB 照片加文本的既有前台五次添加中位 6049 ms、最大 9792 ms，图片显示只比正文插入晚 7–14 ms。两文件目前需要六次串行传输请求，每次先经过仓库公共队列。当前资料为 119 篇笔记、493 个笔记修订、39 个笔记本修订、749 个文件、567204348 B。

实施前独立进程只读测量：热读取五次 124/127/129/120/121 ms；仅清空内存整库校验缓存后的读取 412/413/418/409/404 ms。后台旧任务发现每两秒扫描整库，五次 108/122/121/119/118 ms；限定任务目录并核验路径的小测为 3.12/1.60/1.38/2.02/1.68 ms。后两组只说明扫描范围成本，不等于宿主添加耗时。首次校验单样本 2705 ms，不据此承诺冷启动性能。

## 已批准范围

1. 在隔离宿主补充分段计时：草稿就绪、请求、仓库排队、校验、落盘、正文插入及预览；不记录凭据或正文。若主要瓶颈超出本范围，记录证据并重新讨论。
2. 正文及补充区单文件不超过 1 MiB 时，以单次请求接收。服务端在一次仓库操作中验证当前编辑资格、持久草稿、文件与仓库状态，登记草稿引用并落盘。保留所有身份、路径、字节、图片和并发校验；较大文件、批量导入继续现有分块流程。
3. 旧任务发现只检查任务目录，保留任务校验、恢复、取消与调度周期。

不重构公共队列、不放宽校验缓存、不修改存储格式、依赖、用户操作、文件上限或同步策略。另一候选为全局队列/缓存重构，影响面较大，本轮不采用。
