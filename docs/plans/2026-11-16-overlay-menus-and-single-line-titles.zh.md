# 内容菜单不占位与笔记标题单行

状态：2026-11-16 已按用户批准完成规划、试验、开发与验证。见[验证与隔离体验](2026-11-16-overlay-menus-and-single-line-titles-results.zh.md)，未发布。

## 目标与取舍

1. 内容旁的「…」脱离正常布局：隐藏时不占宽度、不拦截鼠标；显示时覆盖内容末端，不挤压文本、不引起行高或宽度变化。不再以预留边距模拟覆盖。
2. 保留条目悬停、键盘焦点、当前条目选中、菜单已展开时显示的规则；触摸设备保留可发现的入口。菜单有匹配背景，避免图标与被覆盖文字混杂；控制覆盖面积。
3. 主界面、独立页面、会话侧栏及目录树的笔记列表标题统一单行省略，悬停可看完整标题。摘要保留现有行数；普通/多选一致。标题应兼容中文、西文长串、收藏与置顶图标。

选择绝对定位覆盖，放弃 display:none 导致键盘不可达、以及透明但仍保留 flex 宽度的做法。核对全部「…」入口；本轮统一内容附属菜单（笔记本、笔记、目录树、标签溢出、图片、文件链接）。正文/编辑工具栏中常驻的更多操作保留操作栏语义，不将一个操作按钮覆盖到另一个操作按钮之上。

## 影响面与边界

预计修改 RowMenu、NoteSelectionRow、共享列表样式、ConversationNotes、NotebookTree 的标题提示，以及 ImageActions/NoteMarkdown 的文件链接菜单与静态导出占位。按核对结果去掉主题样式中的冲突规则。存储、同步、默认排序、导出形式、依赖及宿主接口不变；旧评审网页和反馈不变。

列表、正文只改布局，不新增请求、笔记解析或扫描，不重挂编辑器。以既有示例库和长标题验证：比较隐藏/显示时文本可用宽度及行高，目标是完全一致；标题一行且不横向撑开容器。无需重复此前大规模读取性能测试。

## 实施步骤

1. 记录当前占位来源和真实页面基线，清点所有相关规则。
2. 统一内容菜单覆盖定位，移除菜单预留；统一标题截断与全文提示，检查选中和展开状态。
3. 类型检查、构建和相关测试；隔离安装，验证宽窄主界面、侧栏、目录树、明暗、多选、键盘/触摸模拟、长文件链接。对导出静态布局做针对性核对。
4. 更新设计/使用说明与验证记录，交付原隔离启动入口；保留前版候选以便回退，结束本轮验证进程。

预计为一轮小范围界面修改。主要风险是浮层覆盖过大、隐藏按钮拦截点击、嵌套 flex 导致省略失效，以及不同主题的规则优先级；均以实际几何和交互检查确认。回退本轮提交或重装前版隔离包即可，无数据迁移。

## 过程与证据

- 基线代码：main bb3022c，工作区干净。RowMenu 按钮为 flex 子项，隐藏仅 opacity:0；笔记本占 25 px，普通行占 28 px。主笔记标题另留 25 px，侧栏标题另留 28 px；标题继承允许折行。文件链接菜单仍为行内按钮，静态导出另有 26 px 空白占位。
- 基线实测（DSH 1720 × 960）：179 px 的笔记本行内，内容按钮 154 px、菜单 25 px；测试长标题高 67.17 px，行高 22.4 px，另有 25 px 标题右边距。测试标题仅临时替换页面文本，不改笔记。
- 第一轮：统一共享菜单 absolute 覆盖、不可见时禁用指针命中；清除标题/文件链接占位，标题单行并保留全文提示。侧栏的引用/关联按钮仍常驻，仅其所在标题行保留必要空间；摘要使用完整行宽。多选行无菜单预留。
- 第一轮检查：类型检查、构建和 19 项相关测试通过；主界面/实际会话侧栏的菜单显示前后几何一致，隐藏不拦点击，焦点/选中/展开可见，主界面多选不会打开正文。笔记本按钮宽度恢复为 179 px。
- 主题试验：32 组合矩阵进行到边签档案时，发现原主题 min-height:44px 套到了菜单按钮；在共享控件中限定最小高度为 0，保持实际按钮 26 px，不改变条目行高。随后重新构建并安装，最终矩阵不注入试验样式，32 组合全部通过。
- 最终验证：实际 DSH 主界面、359 px 会话侧栏、明暗切换、普通/多选、标签溢出及键盘操作通过；安装后的独立页面完成八布局宽窄明暗矩阵、图片/文件链接、触摸模拟与 PNG 导出。文件链接场景只替换页面读取的测试响应，不保存或修改示例笔记。菜单悬停 5 次未增加笔记/引用读取请求。
- 已完成：清点与实测基线、共享实现、主题冲突修正、相关测试、实际隔离安装与验收、设计和使用说明。候选包、验证边界、原体验入口与回退路径统一记录在交付文档。
