## 性能：实测口径与结果

Windows / Node 24.21.0 / DSH 0.2.2-rc.1，项目隔离 Desktop，内容区 1460 × 980，沿用同一会话、目标笔记、两本笔记本和测量脚本。结束点为点击后实际结果显示，再等待两次绘制；并记录关联接口返回。没有提前显示已关联。全量测试结束后才执行优化后测量，避免回归任务争用磁盘。

基线为改动前 `e65b313` 的重新测量。前后每项 5 次，关联接口包含同一组中的解除与关联共 10 次。资料约 541 MiB，笔记从 110 增至 112 篇，修订统计 470 → 474；新增是本轮两篇转存验收笔记。属于同一测试库连续操作比较，不能称为完全相同的冻结快照。没有把模型生成、云端同步、DSH 启动或首次冷启动算进热操作结果。

| 操作 | 优化前中位 / 最大 | 优化后中位 / 最大 |
| --- | --- | --- |
| 点击关联至实际状态显示 | 918 / 1357 ms | **297 / 371 ms** |
| 关联或解除接口返回（10 次） | 708 / 930 ms | 185 / 254 ms |
| 从侧栏打开正文 | 235 / 917 ms | 153 / 250 ms |
| 切换笔记本并显示列表 | 255 / 322 ms | 173 / 260 ms |

关联中位约减少 68%，本轮达到中位 ≤500 ms、最大 ≤1000 ms 的目标。这是此机器和此规模的结果，不保证所有资料与设备相同。

上轮曾记录关联中位 3446 / 最大 4522 ms；本轮修改前重新测得 918 / 1357 ms，说明缓存、后台同步和磁盘活动会影响等待。不能把上轮最差数据直接当作本轮每次必现的基线。只读诊断中，失效后整体重读中位 2819 ms，有效缓存读取 185 ms；一次重建有 678 次文件读取和 279 次附件引用验证，是此次逐文件复用针对的主要成本。
