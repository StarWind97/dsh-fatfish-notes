采用 0.9.1 修订版本，保留 DSH 0.2.2-rc.3 / Windows 验证边界。没有新存储格式、新功能或宿主机会探索。选择从已验收 main 直接准备，避免另建长期发布分支；不升级依赖、不改测试库名或日常环境。公开下载链接在确认发布前仍指向 0.9.0，候选状态明确标注。

## 影响、风险与回退

本轮主要修改 package.json、package-lock.json、README 中候选说明、开发入口、发布文档与生成的 lib。业务代码预期与 8a11dff 一致；若发现新的功能缺陷，先判断是否在本次修复范围内，扩大范围需重新讨论。

访问检查可能影响登录续期或资源加载，须用实际 Web/桌面入口确认；独立窗口继续使用自身本机来源栅栏，不声称全部本机接口均采用 DSH 登录。品牌检查包含任务栏原生图源与截图，不把网页模拟当物理高 DPI 实测。

无格式迁移；不覆盖旧正式包/标签。保留上轮已验收内部包及本轮安装前副本；必要时重新安装此前候选或新增回退提交。候选版本已写为 0.9.1 也不代表已公开。市场对 0.9.0 的提醒继续保留，待新版真正公开并验证下载后再申请更正。
