# 目录边距与独立滚动调整

2026-11-05 用户确认实施。

## 范围

- 目录靠近插件右边缘，宽窗右栏保留约 12px 外侧间距；窄窗浮层同样紧凑，并避开正文滚动条。
- 正文和目录分别滚动。宽窗依次为正文、正文滚动条、章节目录、目录滚动条，去除最外侧的正文滚动条。
- 正文、目录和笔记列表采用统一的原生滚动条：固定预留 14px 操作宽度，平时滑块较细，悬停或拖动时加粗、加深；轨道悬停时显现。宽度固定，悬停不改变正文换行。
- 保留标准/全宽、主题适配、窄窗浮层、目录跳转及阅读/编辑位置恢复。不增加按钮或依赖，不修改保存、同步或导出协议，不发布新版本。

## 实现与验证

调整 PaperColumns、NoteEditor 的滚动容器及目录宽度测量，更新相关样式和说明。目录展开、收起、窗口缩放不重建编辑器。

主要风险是滚动容器变化后影响吸顶、章节跳转和位置恢复。按第二档运行类型检查、构建和相关测试，在隔离 Desktop 实测两个滚动区互不干扰、原生滑块拖动、悬停不挤动布局、深浅色与宽窄窗口，以及阅读/编辑和原始素材切换。交付截图与可重开的体验入口，提交同步到 main。预计一个小规模调整轮次；需要撤回时单独回退本次提交。

## 实施结果

- 宽窗目录右边缘与正文侧的间距均为 12px；正文与目录各自滚动，外层不再产生正文滚动条。窄窗浮层与正文滚动条也保留 12px 间距。
- 三处原生滚动条固定占用 14px，滑块从平时约 6px 加粗到悬停时约 10px，正文不重排。实际鼠标从滑块透明边缘拖动成功。
- 验收发现完成编辑时会返回旧的进入位置：保存操作先发布阅读态，旧代码随后才记录当前位置。本轮调整记录时序，并根据实际工具栏边缘选择锚点；复验停留在刚刚跳转的章节。未改变保存内容和同步协议。
- 类型检查、构建及 5 项目录/编辑专项用例通过；隔离 Desktop 安装的 126 个文件与构建一致。实际窗口覆盖深浅色、宽窄布局、章节跳转、编辑器不重建、阅读/编辑及原始素材往返。
