# 列表底栏与条目菜单

2026-11-18，已在 rc.3 Windows 隔离桌面完成体验验收。开发基线为正式版 0.9.2 对应的运行代码及 `main` 的 `6101810`。正式发布待用户确认。

## 目标与范围

- 精简笔记列表底栏。外观样式为列表加了 16 px 下内边距，底栏还有 8 px 下内边距。收紧两层边距，把空间还给滚动列表，保留按钮点击范围、边线与原有操作。
- 普通笔记本条目显示既有笔记数量。对鼠标用户，悬停或菜单展开时显示 `…` 并隐去计数。移开鼠标且菜单收起后，计数恢复。仅选中或展开笔记本仍显示计数。
- 笔记条目同样按实际交互显示 `…`，选中高亮继续保留。键盘可聚焦并展开，菜单关闭后焦点可恢复。无悬停设备保留可点入口。

选择给复用的行菜单增加按交互显示的模式，应用于笔记条目及主导航、目录树、会话侧栏的笔记本条目。范围限于这几种列表的底栏、计数和菜单显示，其他菜单调用点沿用原规则。沿用现有计数、菜单动作与 DOM 布局，显隐不增加查询。原本仅显示图形的收窄导航使用当前显示规则。

## 验证与交付

根据第二档运行类型检查、构建和布局、外观相关测试。从项目隔离入口核对实际界面，比较修改前后底栏空白与按钮大小。核对宽窄布局、选中后移开鼠标、数量与菜单切换、菜单展开后移开、关闭、键盘聚焦及无悬停设备，检查宽度行高稳定与多选。用现有 0.9.2 正式包作为可重装的回退包，代码用普通回退提交撤销。本轮预计一次局部修改和一轮实际验证，交付隔离入口及证据。

## 执行记录

- 核对了底栏间距及共享 `RowMenu` 当前显示条件。原规则含 `aria-current` 和 `:focus-within`，点击选择后移开鼠标仍可满足显示条件。
- 收紧底栏 20 px，列表与按钮的其他尺寸沿用当前规则。边签档案原先隐藏所有计数，补上该布局当前笔记本的计数显示，以覆盖所有有名称的已选条目。
- 按第二档完成类型检查、构建及 13 项布局与外观相关测试。隔离候选安装的 254 个文件均与候选包一一匹配。正式版 0.9.2 包保留作回退。
- 同一隔离桌面以 1540×920 核对正式版与候选。导入／导出按钮下沿距面板底边从 24 px 缩至 4 px，按钮仍约 85×32 px，点击后可开启、关闭导入导出。独立窗口在 1540×920 和 690×710 均保留 4 px 间距及原按钮高度。
- 主页面通过鼠标选中、移开、悬停、展开后移开、点击外部关闭、键盘 Tab / Enter / Esc 及焦点恢复验证。计数恢复、所选笔记菜单隐藏和行高、内容宽度稳定。多选切换通过。
- 独立窗口、边签档案、目录树展开条目及会话侧栏实测通过。用无悬停触屏模拟实际点开菜单，物理触屏待覆盖。恢复了隔离资料的原布局，验收窗口已关闭。
