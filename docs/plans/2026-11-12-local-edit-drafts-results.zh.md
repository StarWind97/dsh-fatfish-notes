# 本机草稿与结束编辑统一保存：交付记录

2026-11-12，按[已批准方案](2026-11-12-local-edit-drafts.zh.md)完成。属于 E 集中验收修正，正式版仍为 0.8.0，未发布新版本、未启动 F。

## 当前行为

- 编辑标题、摘要、标签、正文及附件时，持续覆盖本机草稿，不生成正式修订或上传草稿。
- 完成编辑、切换笔记、离开笔记页面/侧栏后，统一保存为正式版本，由后台合并 Git 提交并双向同步。无内容变化不增加修订；Git 提交不与每次点击一一对应。
- 取消经确认丢弃本次草稿，原笔记和历史不变；新建草稿直接丢弃，不进回收站。
- 切换其他应用、文件选择框等临时失焦仅保存草稿，返回仍可继续编辑。
- 刷新、正常关闭尽力完成保存；强制退出后，下次启动自动完成已落盘草稿。浏览器补充尚未送达宿主的末次输入；回执避免重复完成和复活已取消草稿。
- 草稿单独保存在本机资料夹的 `local-drafts/`，不纳入笔记库导出或 Git 同步。共用图片/附件保留，丢弃时清理草稿专属文件。跨窗口编辑资格和冲突保留副本继续有效。

## 性能实测

Windows / Node 24.21.0 / DSH 0.2.2-rc.1。沿用同一隔离 Desktop、测试笔记及接口辅助脚本，在全量回归结束后测量。测试库 113 篇笔记、约 541 MiB；前后连续操作期间历史修订有变化，非完全相同的静态快照。

计时从调用开始到实际接口成功返回，包含辅助脚本的窗口身份登记，不包括防抖等待、页面绘制、宿主启动或云端网络耗时。

| 操作 | 样本数 | 中位 | 最大 |
| --- | --- | --- | --- |
| 改动前：每次自动保存为正式版本 | 5 | 457 ms | 809 ms |
| 改动后：编辑期间写入本机草稿 | 5 | 18 ms | 24 ms |
| 改动后：结束编辑保存正式版本 | 5 | 353 ms | 419 ms |

草稿保存中位耗时减少约 96%。样本分别为 `[438,457,605,354,809]`、`[24,17,18,15,18]`、`[174,188,419,399,353]` 毫秒。这是本机此规模的热操作结果，不承诺所有电脑相同。

更关键的数量变化：改动前连续 5 次保存增加 5 个正式修订；改动后连续 5 次草稿保存，历史数量保持 11，完成编辑后才从 11 增为 12。结束编辑仍承担正式校验和写入成本，网络同步继续在后台进行。

## 集中体验

使用项目入口 `D:\DSH-Workspace\dsh-github-notebook\scripts\Open-Fatfish-Notes.cmd`。本轮交付打开隔离窗口并停在「草稿保存机制 · 对照测试」阅读态。

1. 编辑正文，等「草稿已保存到本机」，点击取消并确认，检查原文未变。
2. 再编辑，点击完成编辑，检查正文更新；也可以直接切换到会话再返回。
3. 编辑后切到其他应用再回来，应仍能继续本次编辑。
4. 编辑后关闭体验窗口，再用入口打开，检查最新内容已恢复为阅读态。
5. 在会话侧栏新建笔记后取消，检查没有额外回收站条目。

需要回退候选代码前，先完成或导出本机草稿，保留 `local-drafts/`，不能通过删除草稿目录回退。
