# 首次初始化：选择父目录并保持库名一致

2026-11-06 用户确认实施。

## 范围与取舍

- 首次初始化「更改位置」打开目录选择弹窗，选择父目录后自动追加云端库名；页面展示最终完整路径，不单独编辑本地子目录名。
- 默认位置保持 `DSH_HOME/github-notebook/libraries/<仓库名>`。自选位置为 `<父目录>/<仓库名>`。
- 取消选择保留点击前的位置；已选自定义位置可恢复默认位置。
- 新建云端库遇到本地重名占用，可返回第二步修改云端库名（本地名称同步更新），也可更换父目录；连接已有云端库只能更换父目录。
- 首次接入只接受不存在或空的最终目录，不接管其他已有本地资料；本次初始化中断允许继续重试。不清空、覆盖或重命名旧目录。
- 第二步不创建云端库；本地检查通过并最终确认后才创建。保留已有云端库接入、已绑定恢复及此前确认的切库记忆行为。
- 优先复用当前宿主的目录选择接口；不改变宿主配置、工作区目录或笔记存储格式。本轮不扩展旧本地资料导入。

## 实施与验证

修改初始化界面、目录选择适配、路径与初始目录检查、相关测试和使用文档。确认当前 DSH 0.2.1-rc.5 的接口后接入，不以新版接口代替已验证能力。

主要风险是路径选择歧义或错误接管旧数据。由服务端校验最终目录及身份，确认前不创建云端库；取消、失败均保留旧资料。代码可用回退提交撤销。
