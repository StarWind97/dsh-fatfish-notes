## 三轮实施

1. **品牌资源与界面**：核对现有生成链和全部颜色入口，更新生产 SVG 与生成器，分别生成鱼形／字标色；更新 PNG／ICO、客户端常量、图标内容版本及当前图册。根 README 引用的公开宣传资源保持原样，若共享路径导致公开变化则拆出冻结的展示文件。
2. **独立窗口图标**：先验证原生图标在辅助进程退出、页面刷新、重开后的生命周期。复用已有 PID／启动时间／专用资料目录校验，只操作属于本插件的顶层窗口。优先在打开／复用时有限次设置正确尺寸图像；不运行常驻维护进程。失败回退现有 favicon，不影响打开与聚焦。若实验需要扩大到新的窗口架构或后台常驻，再向用户说明，不自行扩大。
3. **安装与验收**：类型检查、构建、相关回归，打包内部候选、核对包内容并安装项目隔离 DSH；实际主页面／侧栏／独立窗口／帮助／插件列表明暗检查，真实任务栏选中／未选中、刷新、关闭重开与宿主重启检查，最终图册与重开入口交付。

## 影响面与取舍

- `assets/brand/`、根 `icon.svg`、`assets/icon-180.png`、品牌生成／渲染脚本、`Brand.tsx`／生成常量、`paper/appearance.tsx` 和首次接入颜色调用处；图册 `docs/brand/current*` 与品牌／设计／验证文档。
- `standalone-window.ts`、已有 `focus-window.ps1` 或紧邻的原生辅助模块，保留现有 loopback／Origin／路径栅栏。新增原生逻辑必须有窗口归属检查及失败降级，不以窗口标题单独判断归属。
- 单纯修改 favicon 声明此前未消除柔化，故不重复无效路线；保留 favicon 作为跨入口资源和失败回退。直接设置原生图标的准确尺寸与资源生命周期先试验后确定。
- 不改存储格式，不需要真实 GitHub 写入验证。此轮按第二档验证，不因品牌变化运行笔记业务全量回归。

## 性能、风险与回退

- 阅读、查找和保存路径不新增请求；图标设置仅打开／复用窗口触发，无定期扫描。测量已有窗口复用 5 次基线和接入后 5 次，中位／最大值与实际环境一起记录；初开另外记录，不把进程启动耗时等同于阅读性能。
- 风险：Chrome 后续覆盖原生图标、跨进程图像句柄生命周期、原生调用阻塞、DPI 与缓存。设置使用有限超时，核验图源与屏幕效果；不得以换色成功冒充清晰度修复。
- 保留接入前安装文件与包摘要，回退采用上一候选包或正常回退提交，不清空资料、不重写 Git 历史。新资源源稿可从基线恢复，评审与反馈不受影响。

## 验证与交付物

- 色值／字形／轮廓／尺寸与获选稿对应，SVG 纯色，PNG 透明与倍率、ICO 帧一致；共享界面颜色分别跟随视图明暗，DSH 单色不染品牌色。
- 单测覆盖品牌角色、生成输出、独立页资产与窗口图标失败回退；实际隔离入口覆盖打开／复用／刷新／重开，错误身份拒绝设置图标。
- 真实任务栏采用连续屏幕裁片并记录 DPI、状态与原生图像对比。物理高分屏／Mac 未覆盖时明确说明；浏览器模拟不能替代真实系统缩放。
- 一轮资源接入、一轮窗口修正、一轮验收；交付候选包、验证结果、当前品牌图册和隔离体验入口。规划随试验修正，已批准范围内持续推进。

## 过程记录

- 已读取现行代码与前序试验。当前鱼身与字标共用单一 `--fatfish-brand-ink`，上弧固定；独立窗口的真实架构是 Chrome／Edge `--app`，已有严格进程归属与焦点辅助脚本。开始第一轮资源核对和原生生命周期试验。
- 第一轮已分离鱼身、上弧、字标颜色，生产矢量及位图改为选定色；README 所引品牌组合已冻结到独立路径，视觉保持原样。
- 生命周期试验推翻了直接套用旧截图方法的方案：`WM_SETICON` 使用短进程创建的 HICON，在进程退出后读取即失效（`ToBitmap` 报无效参数）。不接入此实现，也不新增常驻进程。
- 改为试验 Windows 窗口属性：只设置 `RelaunchIconResource` 无改善；一起提供应用标识、重开命令、显示名与 ICO 路径后，任务栏改用清晰文件资源，辅助进程退出及刷新后仍有效。拟接入已批准的窗口辅助流程；标题栏仍使用浏览器 favicon，不声称其缩放已改变。官方依据：[窗口图标资源](https://learn.microsoft.com/en-us/windows/win32/properties/props-system-appusermodel-relaunchiconresource)。
- 核对发现现有脚本仅在回退查找时检查资料路径，已有 PID 分支没有核对实际命令行。本轮原生操作前补齐路径精确匹配、进程启动时间和窗口归属；CIM 查询本机耗时数十秒，改用有界的原生只读进程命令行读取，避免打开窗口等待系统管理服务。所有调用仍在短进程中完成。
- 2026-11-18：三轮完成。类型检查、构建、25 项相关测试、252 文件安装核对、14 项实际界面及真实任务栏刷新／重开／宿主重启验收通过。图册已更新，旧评审和公开展示保持。实际性能、失败重试、未覆盖边界与回退见[最终结果](2026-11-18-berry-brand-results.zh.md)。没有发布。
