# 主界面与会话侧栏共用搜索和筛选

2026-11-20 用户确认按并排交互原型实施「A · 列表内展开」。从主目录 main 的 ef3c552 开发。

## 范围与取舍

- 会话侧栏的「关联的笔记」和「工作区笔记本」直接显示各自的列表，按最近修改排列。会话转存来源在条目上说明。引用、关联、笔记本设置和现有行操作继续可用。
- 「查找笔记」从全库最近修改的首批笔记开始，可直接搜索、直接筛选或先选范围。宽栏按需展开笔记本列，保留拖动及操作。读完返回恢复条件、已加载页和滚动。切到其他分组后返回，恢复之前的范围和位置。不同会话各自保存当前查找状态。
- 主界面、独立窗口与侧栏使用同一搜索行、已用条件、展开面板、命中信息和排序选项。展开先显示时间及附件，再查全库标签，按篇数列常用、按名称浏览全部。标签目录单独滚动，为结果留位置。内容区沿用当前主题和密度。
- 清除条件保留关键词、笔记本范围和视图。改搜全部保留其他条件。主界面改查找条件时保留右侧正文或当前编辑。主动打开搜索结果才定位命中。主界面保留「管理标签…」及正文标签筛选。
- 复用现有本地搜索、目录、打开笔记与编辑接口，影响客户端、样式、中英文文案及浏览测试。沿用笔记存储、宿主协议、同步和依赖。

常用操作在同一资料下对照首开及其后五次，核对浏览可见时间及接口数。主要风险为后台请求覆盖新筛选、窄栏展开挤压结果、返回时列表移位，以及改变查询意外结束编辑。按第二档验证类型、构建、受影响的回归与隔离桌面和 Web。桌面检查 399 与 611 px 会话栏及独立窗口。交付隔离候选包、启动入口和实际验收记录。可重装[上轮候选](2026-11-20-classification-layout.zh.md#体验与回退)恢复原有界面。
