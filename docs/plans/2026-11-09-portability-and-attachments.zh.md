# 笔记迁入迁出、普通附件与回收站完善

状态：2026-11-09 用户确认实施；功能、238 项全量回归与隔离 DSH 验收已完成。同日补验 Obsidian 1.10.6 真实窗口通过；1.15.0 独立程序启动失败，未覆盖该版本。正式发布另行确认。

## 范围与取舍

保持一本归属、多标签和稳定笔记身份。导出时将笔记本映射为目录，不与 Obsidian 或其他软件共同编辑内部资料目录。以通用 Markdown、图片、附件及基础属性实现迁入迁出；不转换专有数据库、白板、动态查询、块嵌入或插件配置。不新增 AI 正文整理。

1. 普通附件：PDF、音频、视频及其他文件可添加、保存、同步、下载、另存和随 Markdown 包导出；不预览、播放、执行或解析。超过 10 MiB 需确认，超过 50 MiB 拒绝。批量导入显示总量、列出超限项并允许跳过。图片沿用图文能力。PDF/图片导出只显示普通附件名称。
2. 多选与清理：全部笔记、单本和回收站可进入选择模式，全选当前筛选结果、显示数量和退出。本次多选仅用于删除。普通删除移入回收站并可撤销；回收站支持单篇、多篇彻底删除及清空，危险动作明确确认。删除笔记的正文、修订、独有来源和附件；其他笔记（含回收站和保留修订）仍引用的文件保留。最小删除记录参与同步，避免旧设备复活内容。不重写 Git 历史，不承诺安全擦除或立即缩减仓库历史体积。
3. 文章互链：编辑时搜索并插入另一篇笔记，阅读时跳转和返回；内部使用稳定笔记标识。改名/换本不破坏链接，已删除或回收站目标明确提示，引用不导致连带删除。迁入迁出转换文件路径。
4. 整库/单本导出：Markdown ZIP，标题作文件名，笔记本作目录，图片及普通附件随包携带，相对路径；保存标题、标签、摘要和时间等属性。处理重名和不合法文件名，默认排除回收站、历史修订及原始素材。沿用单篇各格式导出。
5. 导入：单个/多个 Markdown、文件夹或 ZIP；先扫描预览再确认，选择指定本或按一级目录建本，记录来源路径。默认新增、不覆盖现有笔记，不修改来源文件。转存本地图片/附件，可选下载网络图片；失败保留引用并提示。转换常见 Obsidian 图片与笔记链接；不支持或歧义项明确列出。

## 实施与影响

依次完善附件基础、多选与彻底删除、笔记互链、整库迁移。工作量中等偏大。影响 contracts、notes 存储/校验/同步/导出、Host 接口及客户端编辑/管理/导入界面。按需要引入成熟 YAML 解析器，不自行实现通用 YAML。旧数据可读取，包含新字段的数据由新版实例同步，不建立跨软件共享目录兼容层。

## 风险与回滚

重点防止共享附件误删、删除被旧副本复活、路径转换错误及导入中断。写入采用已有修订机制，导入结果逐项报告。隔离资料升级前备份；代码回退采用回退提交，涉及新格式时配套恢复备份。不修改日常 DSH 资料，不执行 Git 历史重写。

## 验证与交付

第三档：类型检查、构建、全量回归；覆盖大小边界、下载而非内嵌执行、共享引用、清空/多选、双副本删除同步、改名/移动后的互链、中文/空格/重名及 Markdown/Obsidian 迁移。使用项目内 `.dsh-home/pure-001/` 和 `StarWind97/dsh-community-private-test` 验证实际安装和同步。导出包在 Obsidian 实际打开；如环境不可用，记录未验证项，不用模拟代替实际结果。交付截图、体验入口、使用指引与提交，正式发布另行确认。

## 实施结果与已知边界

- 附件、多选清理、稳定身份互链和 Markdown 迁入迁出已实现。YAML 使用锁定的 2.9.1 解析器，ISC 许可证随包提供。
- 新数据启用 notes manifest v2，保留旧 v1 读取；新增 `attachments`、`originPath` 与最小删除记录。参与同一私库的实例需要一起升级，回退须配套恢复升级前备份。
- 导入映射标题、标签、摘要和正文，记录来源路径；不迁移全部第三方属性，章节定位转换为整篇笔记链接并提示。当前只支持 UTF-8 Markdown，文件夹/ZIP 一批上限 200 MiB。
- 真实 DSH 已验证 ZIP 导入、图片显示、附件下载、文章链接与改名换本、批量移入/撤销、单篇/多篇彻底删除、清空确认取消、整库/单本导出、深浅主题与窄窗。指定 GitHub 测试私库收到附件与删除记录。
- 首次使用官方 Obsidian 1.15.0，安装包签名验证通过，仅解包到项目隔离目录；程序启动即以 `0x80000003` 退出，未改动系统安装和日常资料。当时仅核对实际导出 ZIP 的相对文件引用及往返导入，未计为 Obsidian 实际窗口验收。
- 随后用户指出本机安装版可用；核对为 1.10.6，并使用它配合独立 `user-data-dir` 完成真实验收。正文、标题/标签/摘要属性、1280×730 图片、笔记链接实际跳转及返回通过；5 个导出文件与 ZIP 字节一致。1.15.0 使用新空资料、去除调试端口及输出重定向仍立即退出；失败定位在程序启动阶段，具体底层原因未确定。用户原来的 Obsidian 窗口和资料未改动。
- 图册：`output/playwright/portability/index.html`；操作指引见[使用说明](../user-guide.zh.md#导入整库导出与附件061-开发版)，完整验证及包摘要见[候选记录](../releases/0.6.1/review.zh.md)。
