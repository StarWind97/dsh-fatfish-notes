# B—D 连续实施

状态：2026-11-10，B—D 已完成并经用户体验认可，连同 A 与性能优化统一随 0.8.0 正式发布。本文件保留用户授权连续实施时的范围与取舍；后续 E、候选清单回顾与 F 的安排以[主规划](2026-11-09-product-iteration-roadmap.zh.md)为准。

实施结果：B—D 已完成开发、第三档检查、真实宿主组合验证和隔离升级，图册及验证边界见[交付记录](2026-11-10-bcd-results.zh.md)；最终公开包安装与同步核验见[0.8.0 发布记录](../releases/0.8.0/review.zh.md)。

## 范围与取舍

- B：收藏、按本机访问顺序显示最近阅读、多关键词搜索（标题优先、上下文、高亮及正文定位）、已有标签建议和数量。收藏随库同步，访问记录按仓库保存在当前浏览器，不触发 Git。暂不添加复杂筛选语言和所有高级条件。
- C：历史列表与预览、恢复为新修订或副本；多选移动笔记本、添加/移除标签；复制笔记。恢复前版本和原始素材保留。暂不做逐字合并、标签管理体系。
- D：从有效 Markdown 内链计算反向链接、点击预览后打开目标；从笔记保存模板、编辑模板、从模板新建，支持 `{{日期}}`、`{{标题}}`（及英文 `{{date}}`、`{{title}}`）。无脚本、关系图谱、会话侧栏或 AI 输出。

## 实现与影响

沿用不可变修订、附件引用和阶段 A 的单篇编辑保护。收藏与模板标记采用可选修订字段 `favorite` / `isTemplate`，模板是独立副本，列表单独筛选，保留图片及附件。相比另建配置文件及模板存储，这样直接复用同步、历史、删除和附件回收，维护面更小。普通导出以笔记为单位；模板可单篇导出，不混入普通整库导出。

新增受保护的整理接口及只读历史、目录统计、反向链接接口；搜索扩展查询契约。批量写入先整体校验所选版本、编辑占用和目标本，再执行。磁盘故障仍可能部分完成，报错后刷新核对；不引入全库事务系统。恢复、复制和从模板新建继续检查版本，不绕过双窗口保护。

界面沿用现有纸张布局：列表增加轻量视图选择，收藏为图标；低频历史、复制、存模板放入真正的「更多」菜单。历史和模板选择用可关闭对话框，标签建议贴近输入，反向链接在正文末尾按需展开。搜索高亮仅属于界面，不修改或导出到正文。

影响 `src/contracts/notes.ts`、笔记校验/检索/仓库、Host 路由、客户端控制器/页面及中英文文案；`lib/` 仅由构建生成。无需新增依赖。预计是三组中等功能改动加一轮组合验收。

## 风险、回退与验证

新版可读取现有 0.7.0 数据；旧包不了解新字段，**不能直接降级后继续写新版资料**。实际安装前备份隔离资料；需回退时关闭隔离宿主，恢复匹配备份和旧包。公开版本和日常资料不动。

专项测试覆盖多关键词排序/分页、中文命中、访问隔离、收藏同步、批量预检与标签保留、历史及附件恢复、副本/模板独立性、有效链接/代码伪引用、模板变量和双窗口占用。最终按第三档运行类型检查、构建、全量回归，打包并实际安装；用隔离 DSH、独立窗口及指定私库验证组合流程，提供截图图册和统一体验入口。性能记录采用实际测试库及合成检索样本，未测规模不宣称已通过。
