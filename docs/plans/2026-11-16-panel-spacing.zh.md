# 设置页与主界面面板间距一致性

2026-11-16，用户已批准此范围：先落盘规划，再开发和验证；明暗规则保持现状，不发布。

## 目标与边界

修复设置页左侧笔记本栏与右侧内容面板的间距过宽，使同一布局、同一密度下的可见面板间距与笔记主界面一致。一起覆盖笔记本管理页、左栏展开/收起和窄窗口。保留八种布局各自的视觉特征，不统一成一种布局。

不调整设置表单内部卡片、正文排版、明暗规则、跨窗口共享机制、数据存储、依赖或发布流程；不发布。沿用现有隔离体验资料，不改日常 DSH。

## 原因与方案

现有五个固定位置用于保留编辑器实例：笔记本、分隔条、列表、分隔条、正文。设置页把中间列宽置零，但 CSS 的四段 column-gap 仍保留。因此柔和分区紧凑时相邻面板原本 10 px，设置页累计成 20 px；收起左栏时也可能残留空隙。

候选一：逐页减半 column-gap，再针对收起状态覆盖。改动少，但继续依赖隐藏列数，容易再次遗漏。

采用候选二：保留五个位置和组件生命周期，将间距明确交给分隔列；每对可见面板只保留一段间距，隐藏面板同时消除对应间距。主题继续提供既有数值，密度选择按既有规则生效。试验时核对分隔条位置，避免拖动命中区偏移。

## 影响与风险

- 主要改动：`src/client/paper/layout-themes.ts`；必要时配套调整分隔条定位样式，`lib/` 只经构建更新。
- 不改协议、配置 schema 或笔记文件。开发入口、产品设计和本规划同步记录最终行为。
- 风险：隐藏左栏、横向导航、目录树和小窗口有特殊布局，可能出现额外空白或分隔条偏移。逐一检查，保持 DOM 不变。
- 回退：恢复本轮样式并重新构建；隔离安装保留上一候选 `fatfish-shared-appearance-6f939ff42b48.tgz`。不需要数据迁移。
