将已完成的默认笔记本、笔记本管理、Markdown 迁入迁出、普通附件、文章互链、多选清理及依赖修正合并为 0.7.0。原 0.6.1 仅作为开发过程记录，不另行发布。相较补丁版本，这些用户功能及数据格式变化适合一次次版本更新。

按第三档执行类型检查、构建和全量回归；用 0.6.0 实际包创建空数据，再由 0.7.0 读取和初始化默认本。隔离 DSH 安装最终候选包，核对当前笔记、附件和导入导出入口，再验证指定 GitHub 私库同步。历史 Obsidian 实测沿用相同运行代码的 1.10.6 结果，不重复整轮迁入迁出实验。

数据格式已在本批开发中升级到 notes manifest v2，升级说明只保留必要提示：同库实例一并升级，旧包不能继续写新格式；若确需回退，使用相配套备份。用户空库无需搬迁内容。代码可回退提交，隔离验收保留前一安装包和资料副本；不删除日常资料或远端历史。
