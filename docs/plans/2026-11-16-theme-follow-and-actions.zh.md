# 明暗跟随、会话引用与图片菜单

状态：2026-11-16 用户已批准；规划先落盘，实施与验证已完成。见[验证与隔离体验](2026-11-16-theme-follow-and-actions-results.zh.md)，未发布。

## 目标与取舍

- 主界面和独立窗口默认跟随 DSH。手动明暗只临时影响当前视图；DSH 实际明暗改变后恢复跟随，重新打开也恢复跟随。布局、配色、字体等偏好继续保存。
- 会话侧栏始终跟随 DSH，不提供独立明暗按钮；侧栏外观设置明确说明此规则。弹窗和菜单继承发起视图，避免侧栏与主界面临时明暗互相干扰。
- 会话引用采用气泡加号图标，保留「引用」文案；同时调整列表、正文、多选和确认入口。正文 Markdown 引用块的图标保持其原语义。
- 图片右上角菜单默认隐藏；整图悬停、键盘焦点进入、菜单已打开时显示。触摸设备保持可发现；阅读和编辑预览一致。

不开发独立侧栏明暗偏好，不修改笔记存储、同步协议、导出形式，不增依赖，不发布。旧评审网页保留。

采用「持久外观偏好 + 每个视图的临时明暗状态」，不继续用全局持久 mode，也不引入每个入口一套持久配置。旧 mode 值不再作为永久覆盖，其他偏好保留。仅实际宿主明暗变化重置临时值，普通样式变化不重置。

## 影响面与风险

预期修改 appearance 状态/组件、主页面和侧栏边界、主题桥接必要部分、引用图标、ImageActions 与编辑图片控件，以及相关测试和使用文档。弹窗/portal 通过 React 上下文继承视图主题。既有四角色独立窗口桥接保留，不扩展 HTTP schema。

主要风险是跨入口状态串扰、宿主通知遗漏、编辑图片菜单关闭后的焦点与状态残留。使用实际 DSH 三入口检查。可回退本轮提交及隔离候选包；不会迁移远端数据。

## 验证与性能

- 默认跟随；主视图临时切换不影响侧栏；侧栏设置没有明暗选择；各来源弹层正确着色。
- DSH 切换实际明暗后，主界面/独立窗口的临时覆盖清除；窗口重新打开默认跟随；配色/字体不丢失。
- 独立窗口沿既有 2 秒轮询接收宿主状态，明确测量而不承诺瞬时；主题变化不读取笔记/扫描仓库、不重建编辑器。
- 阅读/编辑图片：非悬停隐藏、整图悬停显示、焦点可达、菜单打开不消失、关闭后恢复、无悬停可用；导出内容不带控件。
- 引用入口语义和实际操作保持，Markdown 引用块不受影响。
- 本轮不改笔记读取路径，不做与改动无关的资料规模基准；局部交互按实际页面检查，必要时补充定向测试。

## DSH 全局明暗快捷切换

用户已批准内嵌主界面始终跟随 DSH，并从顶栏按钮切换宿主的浅色和深色。会话侧栏继续跟随宿主。独立窗口保留临时明暗，重开或收到宿主实际明暗变化后恢复跟随。

用户补充外观设置提示。在主界面的「配色与层次」说明明暗始终跟随 DSH，以及顶栏太阳或月亮按钮可以切换整个 DSH。独立窗口继续显示当前窗口的明暗选项和说明。

通过客户端 `theme` 服务读取已解析的颜色模式，取相反值交给 `setTheme`。这沿用原生外观设置的保存流程。「跟随系统」下点击会选定一个固定模式，可在 DSH 外观设置中切回。主界面复用已有跟随边界，设置页随之隐藏视图级明暗选项。涉及客户端注册、按钮提示、宿主依赖声明和产品设计。回退提交或重装前一候选可恢复原来的按钮行为，DSH 外观选择可在宿主设置中调整。[官方客户端接口](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.2-rc.5/packages/extensions/cordis-client-runner/src/client/api-catalog.ts#L262-L275)

按第二档执行类型检查、构建、外观与宿主契约相关测试，以及隔离 Windows 桌面和 Web 验收。检查主界面、会话侧栏和独立窗口的明暗、宿主偏好保存与重启，复核当前 0.10.0 的公开图文，记录随新版发布的更新项。交付隔离候选和体验入口。
