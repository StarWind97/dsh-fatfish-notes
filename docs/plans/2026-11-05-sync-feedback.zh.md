# 同步提示与回收站轻量确认

状态：用户确认方案并指示开始实施。

- 顶栏区分正在保存、本机已保存等待上传、实际同步和已同步；仅实际同步旋转。悬停或点击展开提示，移出触发按钮及面板、点击外部或按 Esc 收起，不直接跳转设置。异常时提供重试，必要时再进入设置。
- 设置页与顶栏订阅同一状态，持续更新正在同步、成功或失败。首次同步完成仅在初始化结束时短暂提示。
- 文章工具栏只显示垃圾桶图标，悬停提示「移到回收站」。点击向下展开非模态确认，不挤动正文，不重复标题；取消、确认移入，并保留移入后的撤销。
- 排查实际启动入口的账号提示，区分账号认证与连接失败；本机只保留最近失败的时间及错误分类，不保存凭据或正文。
- 同步减负采用批量读取 Git 对象，减少逐文件进程开销；保持身份、私有性、字节上限、哈希和笔记结构校验，不更改远端存储格式或引入依赖。

影响客户端状态、设置页、文章操作、账号检查、Git 读取和本机同步诊断。工作量中等。沿用自动保存与五分钟双向检查，不调整产品范围，不发布 npm 或 GitHub Release。

验证按第三档执行类型、构建、全量回归；隔离 Web/Desktop 从实际入口验证状态、浮层、取消与撤销、同步成功及失败提示，并在现有私库验证双向传递与耗时。截图及包放忽略目录，中文提交并同步 main。异常可通过回退提交还原，保留笔记数据。
