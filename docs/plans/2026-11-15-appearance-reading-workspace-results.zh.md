## 隔离体验与回退

双击 [Open-Fatfish-Notes.cmd](../../scripts/Open-Fatfish-Notes.cmd)。进入肥鱼笔记后：

1. 「同步与设置 → 外观与阅读」选择主题、配色、代码与资料布局；默认组合已保留。
2. 打开「侧栏体验 · 代码与资料」或「阅读与导出 · 统一验收」，体验全宽、代码、资料把手和导出。
3. 打开不同笔记本的几篇笔记，从标签回切；试试「目录树工作室」及「浮岛桌面」的管理/设置页。
4. 会话「E0 普通附件与生成文件 → 会话笔记 → 全部关联」可体验侧栏；顶部齿轮也能调整外观。

最终候选：`dist/fatfish-appearance-f27667ca7f8a.tgz`。SHA-256：`f27667ca7f8a5871c574ebd20cb6f0003e1381bc9d036faecd2a20d3fdc14797`。沿用项目内 `release12-desktop` / `release12-shell`，日常 DSH 资料不变。

回退包：`dist/fatfish-export-completion-d2edaa83d47c.tgz`。本轮没有数据格式迁移；如需回退，关闭隔离 DSH 和独立窗口后，用同一隔离 DSH_HOME / desktop profile 安装这个旧包再启动。安装前的插件及配置副本保留在证据目录 `installed-before/`。恢复默认外观也不删除笔记或草稿。

最终核对无编辑/文件任务后，自建隔离宿主与临时浏览器已关闭；双击上方入口可重新启动。验收脚本退出时遇到 Node Inspector HTTP 客户端断言，随后独立检查确认宿主已退出；该断言不是插件页面异常。

旧设计评审页继续保留：[V6 评审页](http://127.0.0.1:8804/#preview)，本轮核对 HTTP 200，没有重启或关闭该服务，V1–V6 及原反馈不变。新版产品体验使用上述隔离 DSH 入口。

## 已知边界

- 真实验收范围为当前 Windows / DSH 0.2.2-rc.1；未覆盖 macOS、其他宿主版本和两台物理设备。
- 独立窗口沿用原来的四角色主题桥接，其他原生角色使用当前 DSH 基线回退；不能承诺未来任意宿主主题逐色自动对应。宿主与独立浏览器的自定义偏好各自保留，暂不跨设备同步。
- 本次只对常见语言提供精细高亮，超大代码完整纯文本显示。没有加入自动代码格式化、缩略图、分页图片、网页导出或会话 AI 编辑笔记。
- PDF 保留既有文档排版，不与阅读 PNG 逐像素一致。原型主题评价是设计反馈，本次实际结果仍待用户体验取舍。
