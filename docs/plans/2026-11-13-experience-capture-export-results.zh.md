## 试验中发现的问题及修正

1. 旧 PNG 使用独立排版器，不能实现同宽截图。改为已冻结且校验通过修订的临时阅读投影，共用只读组件；不修改用户修订或原始来源。
2. 截图库取整字号会改变换行，恢复真实 CSS 字号。初版 SVG 绘制曾有背景或内嵌图片不全，增加加载、解码与下一绘制帧等待；最终用五次独立浏览器像素核验确认。
3. 阅读区图片使用延迟加载，初次对比误把未加载图片高度计入差异；验收先等待实际图片解码，再比较双方排版。
4. 测试环境起初限制原子写入所需硬链接；测试改在项目内临时目录和允许该操作的环境执行，没有放宽产品路径或身份校验。
5. 指定私库同步曾出现网络/仓库核对失败；通过原有同步入口重试成功。最后状态 idle、pending=false，成功时间 2026-11-14 00:37:47（北京时间）。保留失败证据，没有修改网络、账户或校验规则。
