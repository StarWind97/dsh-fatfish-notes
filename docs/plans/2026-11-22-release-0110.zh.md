# 肥鱼笔记 0.11.0 发版准备

2026-11-22 按用户要求评估并开始准备本地候选。以上一公开版 [`v0.10.0`](https://github.com/StarWind97/dsh-fatfish-notes/releases/tag/v0.10.0) 的 `8abee27` 为对照，候选基线为 `main` 的 `f948170`。本轮先复核回归、制作本地包并确定需要更新的用户说明。正式候选的图文范围、新宿主验收和对外发布分别按项目约定确认。

## 版本与范围

建议目标版本为 **0.11.0**。会话转存有新的选材流程、标题预填和纯文字 AI 建议，主界面新增切换 DSH 明暗的入口，两项变化都有独立的用户价值。

- `ad60946` 的[会话转存](2026-11-21-capture-layout-and-text-suggestions.zh.md)在宽窗并排显示选中消息、图片与文件、笔记信息，窄窗可展开或收起。切换时保留选材和手填内容。已有会话标题预填；AI 建议根据选中消息的文字生成标题、摘要和标签，归档仍按选择保存图文和文件。
- `2df56f7` 的[明暗切换](2026-11-16-theme-follow-and-actions.zh.md#dsh-全局明暗快捷切换)让笔记主界面顶栏直接切换并保存 DSH 明暗，笔记主界面和会话侧栏同步跟随。独立窗口的明暗选择仍是临时的。
- 运行差异集中在转存客户端、宿主会话与模型调用、可选 `sessionTitle` 响应字段和主题宿主依赖。两项功能的既有隔离证据均来自 DSH 0.2.2-rc.5 桌面与 Web。库中已有笔记继续使用原格式，当前候选宿主声明为 `>=0.2.2-rc.3 <0.2.3-0`。

### 发布说明草稿

- **更容易核对要保存的会话内容。** 宽窗并排查看消息、图片与文件及笔记信息，窄窗可手动展开。布局切换会保留所选内容和已填信息。
- **转存时可以直接沿用会话标题。** 可手动修改；需要时点「AI 建议」，让模型根据所选消息的文字生成标题、摘要和标签。
- **从笔记主界面切换 DSH 明暗。** 点顶栏太阳或月亮切换并保存宿主设置；独立窗口仍可临时调整当前窗口的明暗。

### English draft

- Review the messages, images and files, and note details side by side when there is room. Expand the compact view when needed. Switching layouts keeps your selection and edits.
- Start with the conversation title or edit it yourself. Optional AI suggestions use the selected messages’ text to propose a title, summary, and tags.
- Change and save the DSH light or dark theme from the notes toolbar. The separate window can still use a temporary appearance.
