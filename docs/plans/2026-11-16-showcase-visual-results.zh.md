## 内容与效果

七篇笔记已加入隔离资料的“开发手册”，统一标签 `AI使用`：

1. 配图提示词：把「好看」说具体。
2. 读长资料，先想清楚要找什么。
3. 零散想法，怎样整理成文章。
4. 一封邮件，怎样礼貌又不绕弯。
5. 排查问题前，准备这四项信息。
6. 长对话结束后，给下次留个起点。
7. 常用提问：留下真正会再用的。

主图使用第一篇：已保存的配图、明确的画面要求、可复用提示词，以及下一轮可如何调整。它是实用方法示例，不伪造模型多轮试验结果。配图沿用项目已有 GPT 生成的 2172×724 桌面照片；完整原提示词可下载。另有图片 CSV 检查清单和文字 Markdown 检查清单，均为实际文件。没有新建笔记本、覆盖用户手册或清空旧测试资料。

| 方向 | 正式版设置 | 视觉判断 |
| --- | --- | --- |
| A 清晰而温暖 | 柔和分区／松青／浅色／现代清晰／微软雅黑与 Segoe UI | 建议主图候选；功能区分明，配图和文字层次均衡 |
| B 安静的阅读感 | 墨线书房／暖砂／浅色／书页排版／宋体与 Georgia | 阅读气质更突出，缩小后文字更纤细 |

统一 1440×1000 视口、17 px 正文、1.8 行高、标准阅读宽度、紧凑密度、同一七篇列表和正文起点。每组包含首屏和下方正文细节，共六张 2880×2000 PNG。用正常设置和实际安装界面拍摄，没有注入美化 CSS、替换界面文字或制作 UI 假图。人工查看原图和 820 px 缩小图后，推荐 A 优先评审；最终选择由用户决定。
