### 验证与交付

- 基线以 Node 24.21.0、DSH 0.2.2-rc.5 完成类型检查、构建、440/440 测试、弹窗与侧栏浏览器回归。隔离 Web/Desktop 各 194 个构建与词表文件与基线相同。桌面快捷键到获焦五次中位 25 ms、最大 49 ms。项目指定私库完成一次无待传变更的同步；双设备有变更往返由本地 Git 克隆回归覆盖。
- 本机原始证据位于 `output/playwright/codex-audit-20261125/`，包括 `review.zh.md`、`components.json`、`table-15.png`、`suite-host.log`、`web.json`、`desktop.json` 与 `english.json`。该目录由 Git 忽略；复核所需输入、预期和关键结果均写在本文件及提交的回归中。
- 每批维护此文、构建并运行相关测试。最后做类型检查、全量回归、窗口尺寸与交互检查，以同一候选在指定隔离 Web 和 Windows 桌面验证。快捷面板沿用缓存优先、120 ms 防抖与 24 项上限，比较同资料键盘呼出样本；变更不引入额外查询。预计半天至一天。
- 审查 PNG 在不可容纳时提示加宽的取舍、离线队列的幂等与非法字段拒绝、旧查询迟到、样式注册生命周期及路径别名是复核重点。存储格式、同步协议、依赖、市场发布和日常 DSH 资料均在范围外。每批可通过独立回退提交撤回；构建产物随对应源码提交，候选包保留在忽略目录。

### 快捷面板耗时与结论

在同一 DSH 隔离桌面、1440×950 窗口，从按下 Alt+K 计时到输入框实际获焦。每组新启动一次宿主，进入设置帮助页，连续呼出五次，每次按 Esc 关闭。当前资料共 161 篇活动笔记。此指标包含自动化、宿主与渲染开销，计时在输入查询前结束。

| 观测 | 五次耗时（ms，按先后） | 中位 / 最大（ms） |
| --- | --- | --- |
| 最初审查的基线 | 49、26、25、25、25 | 25 / 49 |
| 修复包，全量回归同时运行 | 71、41、35、35、33 | 35 / 71 |
| 修复包，全量回归结束后单独运行 | 56、35、34、34、36 | 35 / 56 |
| 相邻对照，重新安装基线 | 56、32、31、34、30 | 32 / 56 |
| 相邻对照，重新安装修复包 | 52、33、30、38、37 | 37 / 52 |

相邻对照中，修复包的中位数增加 5 ms，最大值减少 4 ms。五次样本包含首次呼出，无法据此确定持续的性能退化或提升。基线渲染包与 `2514e4c:lib/client.js` 核对一致；测试结束时桌面已恢复修复包，并再次核验 273 个文件。复核记录为 `desktop-timing-baseline.json` 和 `desktop-timing-final.json`。
