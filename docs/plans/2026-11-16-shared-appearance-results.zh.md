# 跨窗口外观设置同步：验证与隔离体验

2026-11-16，按[正式规划](2026-11-16-shared-appearance.zh.md)完成实现、实际窗口验收及全量回归补验；未发布。

## 行为

- 同一 DSH 资料内，主界面、会话侧栏和独立窗口共享布局、配色、对比度、字体、代码、资料面板等持久偏好。在任何入口修改，其他入口及时更新。
- 第一次合并采用主界面的现有设置，等待主界面提供旧值后才初始化；独立窗口先连接不会将默认值写成权威设置。两端旧值保留在本机设置文件及各自浏览器备份中。
- 仅按实际修改的字段提交；同时修改不同字段不会相互覆盖。保存失败显示提示并自动重试，未确认的补丁在刷新后保留；近期操作回执避免响应丢失后的重复回写。
- 手动明暗仍仅影响当前视图本次使用；侧栏始终跟随 DSH，宿主切换明暗后临时覆盖失效。窗口大小、阅读位置和打开标签保持各自独立，不上传外观设置到 GitHub。

设置单独保存在 DSH 资料的 `fatfish-notes/appearance.json`，不改笔记格式。通知复用现有 JSON HTTP 转发：最多等待 20 秒，有变化立即返回，超时续接。宿主明暗由观察事件主动上报。没有新增高频轮询；原有 2 秒编辑协调心跳继续保留，不再反复采样外观。

## 实际窗口与性能

Windows / Node 24.21.0 / DSH 0.2.2-rc.1，使用项目原隔离 DSH 与原独立 Chrome 应用窗口，均为可见窗口，不以静态网页替代。沿用同一份 143 篇笔记、25 个笔记本的测试资料和启动方式。收尾实测主页面视口 1280 × 820、独立页面 1344 × 881。

| 操作 | 样本（ms） | 中位 / 最大 |
| --- | --- | --- |
| 修改前：DSH 明暗到独立窗口 | 3678、3987、4004、4014、4007 | 4004 / 4014 |
| 修改后：DSH 明暗到独立窗口 | 669、686、609、618、592 | 618 / 686 |
| 主界面配色到独立窗口 | 110、112、102、79、84 | 102 / 112 |
| 独立窗口配色到主界面 | 82、81、64、71、76 | 76 / 82 |

以上均以对端页面状态实际更新为完成信号。明暗计时包含打开、操作和关闭 DSH 设置的 UI 时间，不是纯网络传输；修改前布局/配色没有跨窗口同步，因此没有可比较的旧版延迟。当前前台样本满足规划中的常用设置小于 300 ms 目标，不据此承诺后台休眠/浏览器节流时也即时显示。

22 秒双窗口空闲观察：仅 2 次外观等待续接，0 次外观更新、0 次笔记/引用读取；共享设置文件字节未变。原窗口协调心跳仍运行，这个统计不声称整个插件没有请求。

已确认：

- 首次迁移的主界面 soft/lilac 覆盖独立窗口的 outline/native；服务端保留的两份原始 JSON 与改动前快照逐字一致。
- 同时从两端修改字号和代码字重，两个修改均保留；双向布局切换正常。
- 独立窗口更新请求模拟失败，显示重试提示；刷新后仍保留未确认选择，恢复请求后双方一致。
- 侧栏外观弹窗与独立窗口双向同步，侧栏没有独立明暗选项；独立窗口临时深色不改变浅色侧栏，DSH 真正切换明暗后恢复跟随。
- 编辑正文时从另一窗口调整字号，编辑器 DOM 实例、内容均保持；完成编辑后整份笔记及修订与进入编辑前一致。
- 关闭并重新启动宿主与独立窗口后偏好恢复；无既有浏览器缓存的 Chrome 页面读取相同设置，单次样本 405 ms（含页面加载，n=1，不作普遍启动性能结论）。此项是无头新环境，前述双向操作使用原可见独立窗口。
- 页面错误列表为空。验收脚本曾误用显式 role 选择器定位原生 dialog、未先关闭模态框就点击宿主设置，以及连接到退出中的测试宿主；修正脚本后补验通过，未将这些脚本问题当作产品失败修复。
