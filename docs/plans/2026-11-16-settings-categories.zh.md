## 目标与非目标

将笔记设置整理成外观、阅读与代码、工作区、同步与存储、帮助五类。主界面与独立窗口共用完整分类，侧栏外观弹窗复用前三类。顶部总入口简化为「设置」，同步提示入口直接定位同步与存储。

整块右侧内容区域承接滚轮，包括内容两侧留白；内部内容按适宜宽度排版。常见宽窗口争取每类一屏，内容未溢出时没有滚动条；窄窗、矮窗、放大字体或展开详情时允许必要的单一纵向滚动。分类导航常驻可见，极窄时使用分类选择器。

不改已有设置值、明暗规则、外观共享协议、仓库格式、保存与同步算法、初始化流程；不引入依赖，不发布。设置分类选择只属于当前视图，不与其他窗口同步。

## 原因与方案

当前 `.paper-other` 同时使用 `maxWidth:960`、自动外边距和 `overflow:auto`，两侧空白不属于可滚动容器；外观组件后又接入完整同步设置，成为长页面。

目录锚点仍保留长页，折叠分区也会随展开累积长度。本轮采用顶部分类标签：当前类别单独显示，类别内继续短分组。滚动边界与内容宽度分离，使用原生滚动，不添加全局 wheel 转发。标签按 WAI-ARIA Tabs 模式支持焦点、方向键与 Home/End；窄空间切换为有标签的原生选择器。

| 类别 | 内容 |
| --- | --- |
| 外观 | 界面主题、配色、明暗、对比度、面板密度 |
| 阅读与代码 | 字体、字号、行距、代码显示、阅读预览 |
| 工作区 | 资料区位置/排列/固定、笔记标签、会话转存按钮样式 |
| 同步与存储 | 仓库/账号/同步、本地目录、容量、移动资料和切换仓库 |
| 帮助 | 用户手册、问题与建议 |

恢复默认保持原有恢复全部外观偏好的含义，入口明确标注，避免拆分类别后误认为仅恢复当前一类。同步异常入口优先打开对应分类。首次初始化与 DSH 自带设置入口保持原有业务流程兼容。

## 影响、风险与回退

预计新增通用分类导航/设置工作区组件，拆分 `paper/appearance.tsx` 展示分组，调整 `NotesPage.tsx`、`ConversationNotes.tsx`、`SettingsPage.tsx` 的组合与相关样式/文案；维护开发入口、产品设计和用户说明。`lib/` 由构建生成，不手改。

主要风险是切分类卸载表单导致未提交输入、错误提示或进行中操作丢失，以及子容器继续形成嵌套滚动。分类面板首次访问后保持挂载，隐藏类别不占布局，不重复启动读取；同步业务控制器和确认动作不改，切换类别不触发连接、移动、重置或保存。必要时在进行中操作结束后把提示带回相应类别。

回退使用上一隔离候选 `fatfish-panel-spacing-58e8a22cb639.tgz`，源码新增回退提交；不需回退笔记或外观设置。所有试验在项目内指定隔离资料进行，旧评审网页保留。

## 分轮与验证

1. 基线：用现有资料记录内容中心/两侧滚轮响应与滚动容器，盘点设置项和同步入口，确认分类完整性。
2. 第一轮：分类组件、可复用字段、布局与整面板滚动；保留分类输入和操作状态，确认不因切换反复请求。
3. 第二轮：类型检查、构建、相关客户端/设置测试；实际 DSH 主界面、独立窗口、会话侧栏验收。检查常见宽窗无不必要滚动、两侧空白真实滚轮、矮/窄窗口和标签键盘、八布局、明暗不变、恢复默认含义、同步提示定位及首次设置兼容。
4. 更新隔离候选，核对安装文件；恢复测试偏好，记录真实/模拟/未覆盖范围，交付原启动入口。

按第二档局部交互验证。若试验要求改动存储、同步或身份校验，先暂停并重新确认范围。只做设置组织，不重复全量 Git 同步回归。切换分类以本地显示为先，不等待网络；常用分类切换测量五次显示时间并检查重复请求，目标常见前台操作中位低于 100 ms、最大低于 300 ms，报告实测边界。

## 过程记录

- 规划落盘，已核对当前设置包含外观字段、手册、同步绑定/目录/容量、转存按钮样式。同步页的初始化和移动/重置表单需保留，不能仅用条件渲染切掉组件。
- 实际基线：1760 × 1000 的隔离宿主，旧设置内容高 2693 px、可见高 886 px；同样滚轮 400 px，中心实际滚动 400 px，两侧留白均 0。此为滚动命中区测量，不是性能承诺。
- 第一轮实现：五类设置复用同一分类组件，侧栏使用前三类；首次访问后保留面板挂载，分类导航与全宽滚动区域分离。同步类仅改变展示组合，首次设置/移动/重置的业务状态与确认动作保持原实现。类型检查已通过，继续构建及受影响测试。
- 首轮实际页面：类型检查、构建、20 项相关测试通过；1760 × 1000 宿主下五类均无纵向溢出。截图发现主题卡片形成 5＋3 的不均衡排列，工作区中转存按钮仍沿用旧的「外观」标题和嵌套边框；下一步调整为宽窗 4＋4、窄窗两列，明确转存按钮分组，同时稳定分类标题栏高度。属于已批准的布局整理范围。
