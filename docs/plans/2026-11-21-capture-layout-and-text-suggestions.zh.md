# 会话转存布局与纯文字 AI 建议

2026-11-21 用户批准将可变布局、会话标题预填和纯文字 AI 建议接入肥鱼笔记。交付到隔离 DSH 体验阶段。实现在主目录 `main`，以 [0.10.0 发布记录](../releases/0.10.0/review.zh.md)和已确认的两份原型为对照。

## 交付范围

- 根据 DSH 页面内容区的 CSS 尺寸切换。自动模式采用原型的 1180 × 720 px 门槛，宽窗并排显示轮次、图片与文件、笔记信息。窄窗采用已认可的紧凑布局，范围和附件摘要依次放在同一位置。每次打开支持手动展开、收起及恢复自动。尺寸与布局切换保留选材和表单。
- 会话内勾选是主入口。紧凑模式的轮次和文件均在同一个保存弹窗内展开核对，确定应用，取消恢复打开前的选择。在「整个会话」下可以全选后减去任意轮次或消息，确认后显示实际范围。宽窗在清单中直接勾选。沿用现有大文件确认、可用性限制和最终保存流程。
- 默认用已有会话标题，可手改。缺标题时沿用提问开头。AI 建议只从当前所选消息取文字，独立限制输入，长文取有覆盖的原文片段。常规一次辅助模型调用，沿用已有的格式纠正、停止及替换手填前确认。没有文字时提示手填。
- 交付边界为肥鱼笔记的会话转存和隔离候选。会话导出、旧笔记及同步按照既有契约工作，发布与正式版用户图文按各自审批阶段推进。

## 接入与风险

紧凑原型已经完成交互评审。宽窗采用已选定的三栏原型，保持消息与文件清单各自滚动，两种布局使用同一份状态及笔记表单。宿主从原有会话读取路径取得标题，通过转存选择响应提供可选值。纯文字建议复用冻结选区、宿主配置的模型和建议格式校验，直接读取会话文字，避免额外的文件状态或字节访问。改动集中在转存客户端、Host 会话和建议路径及对应测试。

主要风险是切换模式导致选材、文件限额确认或手填信息丢失，核对窗取消时错误应用临时选择，以及文字裁剪影响概括质量。布局和 AI 请求各自验证，保留上一已验收的隔离候选供回装。工作量为两处局部功能接入与一轮联合验收，交付可重新打开的隔离候选、实拍和本记录。

## 隔离体验

在已安装候选的隔离环境中，运行 `.dsh-home/pure-001/capture-20261121/Open-Capture-Candidate.cmd`，打开「肥鱼转存核对」工作区的合成会话，从任一回答点「保存到笔记」再点「下一步」。自动布局在宽度和高度均满足门槛时使用三栏。窄窗点展开后，轮次、图片与文件、笔记信息从上到下排成一列。切换时保留表单和已选项。手动状态在本次保存选项打开期间生效。

## 小窗口退出检查

用户要求避免手动展开后回切、关闭按钮被窗口遮挡。隔离桌面最小窗口实测为 520 × 600，放大至 300% 后内容区为 173 × 200 CSS px，原候选的按钮仍可点，正文滚动区被挤到 0 高度。隔离 Web 的 200 × 110 和 160 × 100 CSS px 可复现两个按钮同时被裁切，Esc 能返回会话。

将转存标题栏限制在一行。极窄时布局按钮用带名称的图标，标题可截断。高度特别小时正文与保存按钮一起滚动，标题栏仍固定。改动局限于转存弹窗展示，回装本节之前的候选可回退。用同一隔离样本验证按原尺寸展开、展开后再缩小、滚动后鼠标回切和关闭，检查手填标题和选材。
