# 界面体验、会话转存与导出简化实施规划

状态：**已完成实施与隔离验收，待用户体验；未发布**。2026-11-13 用户确认将此前界面、快捷键、转存与导出讨论统一落盘，包含会话侧栏，分轮试验、实施与验证；持续修正规划，交付验证结果及隔离体验入口，**不发布**。本轮沿用 main，开始代码基线为 `77a0f80`。已有 docs/README.md 中新版 DSH 附件接口检查约定保留。

## 目标、范围与取舍

1. 阅读主界面、独立窗口、会话侧栏使用一致的视觉和操作规则。移除正文底部重复编辑；附件、反向引用与正文有明确层级；修正独立窗口外观设置和历史弹窗的已知样式缺陷，检查相关设置、菜单、弹窗、空态、深浅主题和窄宽布局。
2. 引用数不依赖点击展开才可知。确定为 0 时隐藏，有引用时默认展开并显示精确总数，先展示有限条目，可展开更多；加载与失败不能冒充零。避免每次打开正文重新解析全库链接。
3. 阅读支持 Home、End、Page Up、Page Down；按焦点区分列表、阅读、输入框、编辑器、菜单和弹窗，不抢中文输入或选区按键。核对已有编辑组合与快捷键说明，低频功能不新增专属组合键。本轮不另引入 Ctrl+S 保存语义或全局快捷键系统。
4. 会话上传文件在所属消息原位置成为文件链接；多个文件保留顺序。AI 原有文件链接保留，无正文位置的材料才进入补充区，正文已有文件不重复列出。对应关系来自消息和材料身份，不能全局替换文件名或猜测同名文件。未选/缺失材料不生成假链接。
5. 移除会话回答下独立“导出”入口，保留保存到笔记。笔记图片导出以阅读内容截图为目标，当前宽度保持换行，可选标准宽度；提高像素密度不改变排版。复用现有阅读组件和样式优先于继续扩展独立图片布局器。
6. 笔记 PDF 保留为次要导出格式，不进行全新 PDF 排版引擎重构。PNG/PDF 默认直接输出相应文件，不附送附件原件；分页图片 ZIP 只含图片。Markdown 带走可编辑正文及选定资源，必要时 ZIP 打包。正文内嵌图片正常显示与额外打包原件分别处理。

不做：AI 创建/修改笔记、原生输入框附件改造、DSH 升级、新渲染依赖、库迁移、同步协议调整、发布。会话 ZIP 标题来源问题已确认，但相应入口移除后不再为其单独扩展实现；笔记导出继续使用笔记标题。PDF 包内附件超链接不纳入本轮。

## 分轮工作与交付

### 第一轮：阅读、键盘与界面一致性

- 先核对本机数据快照与变化代际，测量常用打开/切换及反向引用基线。实现可重建的引用关系派生数据，按实际资料变化更新；使用精确总数与有限列表，兼容现有调用。
- 调整阅读焦点与滚动，不让菜单 Home/End 或编辑键盘操作误滚正文；保留必要的操作入口，核对双击编辑与文本选择是否冲突。
- 建立少量语义色和附属面板样式；强调色用于选中、主要动作、链接，状态色用于警告/危险，普通图标不逐个随意着色。修复历史弹窗宽度覆盖、独立窗口外观设置缺样式；主界面与侧栏复用。
- 影响：NoteEditor、NoteTools、NoteAttachments、菜单/快捷键、paper 样式、CaptureAppearance、standalone、仓库查询与相关契约。缓存失效、响应字段与性能证据在实施前补充到本页。

### 第二轮：转存文件位置与来源兼容

- 先检查原始来源数据与消息投影的身份信息，选择能明确关联上传块、兼容既有来源的最小方案，再实现正文链接与选材分组。
- 覆盖单轮、全会话、自选消息，多文件、同名不同内容、重复文件、未选/缺失文件，以及旧来源阅读/导出。保存、历史与来源的内容校验不可绕过。
- 影响：host/note-conversation、capture-materials、capture、来源验证、选材 UI、原始素材显示与导出。若需要超出本规划的库格式迁移或改变旧笔记正文，先重新确认；默认仅影响新的转存，旧来源保持可读。

### 第三轮：导出入口简化与阅读截图

- 移除会话独立导出入口及其面向用户的配置/说明，核对会话保存和多轮选择仍可用。
- 先用同一篇内容做阅读组件截图试验，验证字体/图片加载、正文链接、表格、代码、长文、主题和宽度；当前输出采用另一套 ExportModel/layout 的事实已确认。
- 用同一只读渲染入口生成笔记 PNG，明确截图范围为标题、用户选定的标签/摘要、正文及补充材料，不含操作工具栏、编辑控件、输入框、引用回链管理。兼容原始素材附加选项；不混入未保存草稿。
- PNG/PDF 不附送文件原件；Markdown 资源包保留完整性。图片宽度允许当前阅读宽度与预设，单张超限时明确提示分页；取消和失败清理临时节点。
- 影响：NoteExport、note-export、独立截图模块、共享阅读组件/样式、export service、会话 action 注册、相关说明与测试。保留 PDF 的现有排版，不重做它的分页设计。

### 第四轮：整合验收与交付

- 第三档检查：类型检查、构建、全量回归；专项覆盖来源兼容、引用失效、导出资源完整、编辑保存与两窗口刷新。
- 实际入口覆盖主界面、独立窗口、**会话侧栏的列表/阅读/编辑/菜单/键盘**；深浅色、窄宽布局、上传文件转存、PNG/PDF/Markdown 实际下载与文件核验。侧栏必须实测，不以共用组件或代码审查替代。
- 比较相同资料、窗口和完成标准下的打开/切换性能，常用操作至少五次，记录中位数、最大值和资料规模；首次样本不足五次如实注明。正确性包括其他笔记修改引用、同步/导入、回收站/恢复与换库的失效。
- 打包仅用于隔离安装，在 `.dsh-home/pure-001/` 及指定私库验收；不接触日常资料。检查未保存编辑后更新隔离候选，完成后关闭自建进程并提供 `scripts/Open-Fatfish-Notes.cmd` 可重启入口。
- 更新开发入口、产品设计、用户指引和独立验证记录；正常提交/推送并核对远端，**不创建 Release、不上传市场、不发布 npm**。

## 风险、验证与回退

- 引用缓存：不能仅根据当前笔记修订失效，其他笔记也会改变反向关系；换库/外部写入/同步必须触发更新，失败后可重建。大库不承诺没有首次构建成本，正文不等待引用。
- 焦点：真实 iframe/侧栏和独立窗口分别验收，不夺取输入和弹窗焦点。
- 来源：新旧记录兼容，同名上传按身份匹配；旧记录信息不足时明确保留旧行为，不猜测改写。
- 截图：字体、图片异步加载与长画布限制需有完成信号和明确失败；性能目标为不阻塞编辑、单次资源准备、不重复扫描全库。默认当前宽度的输出与受测阅读内容对照。
- 用有意义的行为测试覆盖查询失效、上传身份与导出文件内容；纯样式不写复刻实现的测试。最终验收前不因小调整反复全量跑。
- 每轮可用独立提交回退；不撤销既有用户笔记，不重写历史。必要的临时脚本、截图、安装包保留于忽略目录。

工作量：跨读取、来源与截图渲染的中等偏大修改，按以上四轮推进；以试验结果调整具体步骤，不以固定工期替代完成标准。
