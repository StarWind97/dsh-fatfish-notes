## 目标与边界

让真实的 0.9.0 界面呈现有内容、有层次、值得使用的工作空间。颜值与功能同为交付条件；功能验证通过不自动代表展示合格。用同一组 AI 使用笔记、同一窗口尺寸比较三种方向，不改产品默认外观，不用额外 CSS 或生成 UI 假图美化截图。

本轮只整理隔离测试资料与本地评审素材，保留开发手册、用户手册两册分工。既有回归资料及用户手册不清空、不覆盖。插件源码、依赖、存储格式、已发布安装包、标签、README 展示图片及 screenshots.json 不变；公开资源和市场更新不属于本轮授权。

## 内容与候选

最终选题为用户明确确认的“我的 AI 使用笔记”。围绕值得保存、反复查找和再次引用的方法组织七篇内容：配图提示词与下一轮修改方向、长资料阅读、文章整理、邮件语气、排查问题、长对话收尾、常用提问方式。主图展示同一篇图文创作笔记和自然的多条列表；配图、附件与内链服务内容，不机械塞入每项功能。

场景内容为可复用的 AI 使用方法与场景记录；示意清单与对话明确记录来源，不编造真实客户、模型评测或不存在的修改过程。配图复用已有可追溯的生成素材，必要时生成新图；生成与人工整理的边界在素材清单中标明。附件是可打开的提示词和编辑检查清单，不开发其他应用。

## 视觉验收

- 列表显示约五至八条自然内容，目标条目明显而不过度强调，标题、摘要、标签相符。
- 首屏有清晰的标题和实质内容，图文比例自然；不让空面板、加载遗漏、无关目录制造大面积空白。
- 字体清晰、代码缩进和高亮正确，选择菜单和悬停状态不遮挡主要内容；截图时同步已完成。
- 三方向使用同一内容、同一窗口与列表，差异来自真实设置；主题可不同，内容不能为了某一方案占优势而改变。
- 原尺寸与 README 缩小宽度都人工实看；只清晰但缺少吸引力，也需要调整。
- 用户评审前素材均保存在忽略目录，不能因为提交推送而提前进入公开展示。
