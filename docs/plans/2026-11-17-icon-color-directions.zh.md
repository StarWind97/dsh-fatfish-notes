# 图标纯色配色与结构对照

2026-11-17。用户以「做」批准本轮制作。基于已评审的鲜明绿，扩展色相、色温、亮度、饱和度和鱼身／叠页／背景的搭配。用户明确：逐档变化发生在不同候选之间，单个图标不使用颜色渐变。

## 目标与非目标

- 鲜明绿常驻基准，新增 12 个纯色候选，分为绿色力度、冷暖色相、彩色主体、双色搭配四组。
- 结构单独比较：现有 D1、适度放大主体、加强独立叠页；保持饱满不对称尾瓣、上弧独立以及现有文字。
- 同时查看透明鱼形、圆角方块，16／24／32／48 px 与浅深背景；不增加圆形徽标。
- 本轮仅制作评审素材，不接入正式图标、不修复产品图标传递、不改宿主与系统设置、不发布。旧评审和反馈保持。

## 实施步骤与取舍

1. 从正式 D1 SVG 快照派生，配色组保持几何完全相同。绿色力度组仅改变底色，冷暖组保留主体／叠页色；其余组明确改变颜色分工。
2. 结构变体不穷举全部颜色组合，先用同一鲜明绿比较。页面可在候选配色间复核结构效果，单独记录结构偏好。
3. 复用既有浏览器渲染和原生临时取图实验。以清晰源图比较设计；真实任务栏裁片标为「临时窗口清晰图像实验」，不宣称已修复插件。正式链路模糊问题仍见上一轮结果。
4. 制作新评审页，可筛选、并排比较、查看实际尺寸／位置、下载 SVG、记录单稿意见与最终偏好。新意见独立自动保存，旧意见只作只读背景。
5. 核验素材和真实任务栏，再检查页面交互、保存恢复／失败重试、窄屏和高密度素材。更新本规划与结果，正常提交推送。

## 影响面、风险与回退

- 仅新增 `docs/brand/reviews/2026-11-17-color-directions/`、本规划和启动脚本，并更新开发入口。
- 生成源和预览素材均位于评审目录；`assets/brand/`、产品代码、发布资源不改。关闭实验窗口即可撤销原生临时图标设置。
- 鲜亮不必然清楚：以小尺寸轮廓、眼孔、叠页分离和明暗背景共同判断，不仅看放大图。不以饱和度或对比数值排序替用户决定。
- 不改系统主题／缩放，不将浏览器倍率等同于真实高 DPI 验收。Windows 实屏、网页模拟及未覆盖平台分别标明。
