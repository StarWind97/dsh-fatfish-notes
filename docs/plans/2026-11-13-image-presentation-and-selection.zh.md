## 目标与范围

1. 明确截图、纯图片批次、混合文件批次、显式插入与补充区的默认呈现规则。
2. 正文中的受支持图片可在图片展示和下载链接之间切换；选择写入正文，随正常保存、同步和导出保持，不只是当前窗口的临时折叠。
3. 有多选模式的笔记列表，条目整行左击只切换选择，不打开正文或执行单篇操作。
4. 不重做上传、索引或同步架构，不引入依赖、图片格式转换、图库、批量相册、全局偏好设置或新的存储版本；不自动修改历史笔记、会话原始素材或发布候选。

## 竞品对照与产品判断

2026-11-13 查阅下列官方帮助，未安装或操作竞品来复现全部组合，也未据文档推断未说明的混合批次行为。

| 产品 | 官方资料能确认的行为 | 对本项目的启发 / 证据边界 |
| --- | --- | --- |
| [Obsidian](https://obsidian.md/help/embeds) | 支持的文件拖入正文可自动嵌入；在内部链接前加 `!` 表示嵌入，普通链接与内嵌表达可区分 | 显示方式可以和文件本体分离；同一资源不应因反复切换而重复归档。文档未证明混合批次一律为链接 |
| [Notion](https://www.notion.com/help/images-files-and-media) | 有独立 Image / File 入口，图片可拖入页面；图片可下载原件，过大不能展示时可作为文件上传 | 明确插入意图应优先；展示图片和允许下载并不互斥。未证明其有本项目所需的全部双向转换或混合批次规则 |
| [Evernote](https://help.evernote.com/hc/en-us/articles/360022954093-Note-editor-and-editing-toolbar-overview) | 官方“Personalize attachment views”说明图片、附件、链接可选择文本链接、标题预览或完整预览，并可设默认视图 | 默认方式加后续可改，比一次不可逆的插入更合理；不据此照搬全局设置 |
| [Joplin](https://joplinapp.org/help/apps/attachments/) | 支持附件拖放及直接粘贴图片；Alt 拖放是建立本机文件链接 | 要区分“下载已归档原件”和“链接电脑上的原路径”。本项目始终归档，不采用可能跨设备失效的本机路径链接 |

[Evernote 多选说明](https://help.evernote.com/hc/en-us/articles/209004857-Merge-multiple-notes-into-a-single-note)采用 Ctrl/Cmd 点击选择后执行批量操作。这说明批量动作基于选中集合，但不能证明其他软件一律采用本项目的显式多选模式。本项目已经有明确模式切换，进入后让整行用于选择是直接一致的规则，无须增加修饰键。

候选方案：

- **A：始终逐项按类型。** 图片展示、其他文件链接，和当前行为一致、单个文件更可预测；混合收集资料时会展开多张图，占用正文空间。
- **B：按批次推断默认意图，并允许逐项切换（推荐）。** 截图与纯图片批次倾向表达内容，混合文件倾向作为资料清单，符合用户提出的整理方式。代价是同一图片随同批内容不同而默认不同，因此必须有便捷、可撤销的修正入口。
- **C：每次询问或增加全局偏好。** 控制最强，但频繁打断粘贴和拖放；本轮不采用。已有“插入图片 / 插入文件 / 补充附件”足以提供显式意图。

结论：用户三条规则合理，推荐采用 B；这是针对肥鱼笔记资料整理场景的产品选择，不宣称是所有竞品共同标准。补齐单张本地图片规则，并让显式操作优先。

## 拟采用的行为规则

| 场景 | 默认结果 |
| --- | --- |
| 截图位图粘贴 | 显示图片 |
| 一张本地图片粘贴或拖入 | 显示图片 |
| 多张图片粘贴或拖入 | 按输入顺序显示各张图片 |
| 图片和非图片文件一次粘贴或拖入 | 所有项目均显示下载链接，保持顺序 |
| 明确点击「插入图片」 | 显示可内嵌图片 |
| 明确点击「插入文件」 | 全部作为下载链接 |
| 补充区接收任意文件 | 保持补充附件；主动插入正文时，支持的图片默认展示 |
| 不支持内嵌、超出图片限制或校验不通过的图片文件 | 能安全保存原件时保留下载链接，并说明不能展开；不假装支持展示 |

优先顺序：安全和容量约束 → 目标区域 / 显式按钮意图 → 批次默认规则。原有 20 MiB / 3200 万像素内嵌限制、PNG/JPEG/GIF/WebP 支持范围、50 MiB 提醒 / 100 MiB 拒绝及数量检查保持。

“混合”仅针对同一次文件接收批次中的图片与非图片文件，不能因为截图剪贴板同时带 HTML/文本格式就判为混合，也不改变手写 Markdown、复制的文章正文或会话转存原有排版。批次选择在已有大文件确认完成后、开始接收前冻结；上传失败/取消不反过来改变已接收项的展示方式。纯图片批次里某张不支持内嵌时，仅该张退回链接。

远程图片地址及 HTML 图片按现有明确导入流程处理；失败保留原链接，不在阅读或切换时偷偷请求任意外站。现有历史正文不自动重排。

### 单项切换与资源身份

- 在正文图片和图片文件链接的就地菜单中提供「显示为下载链接」或「显示为图片」；选中源码中的对应项也可调用同一命令。图片展示仍提供下载原件操作，不强迫用户为下载先切成链接。
- 这是正文编辑。编辑态一次切换对应一次可撤销操作；阅读态的入口先取得编辑资格并进入编辑，再修改该处，不绕过双窗口占用，也不私自产生即时正式版本。历史/原始素材/回收站只读视图不显示修改入口。
- 同一图片在文中出现多次时仅修改当前这一处；保留标签、原文件名提示和其他引用。链接定义被多处引用时，只改当前引用为等价内联写法，不改共享定义。跳过代码示例，避免用全篇字符串替换。
- 对已归档的 `assets` 图片，`![说明](路径)` 与 `[说明](路径)` 共用同一文件；切换只修改正文，不上传、复制二进制或重新扫描全库。新粘贴的受支持图片即使默认显示链接，也先按图片资源归档，再选择正文标记。
- 旧笔记、显式“插入文件”和补充区可能已有 `attachments` 图片。首次改为展示需要实际校验类型、像素和大小，并登记为可展示图片资源；随后复用该资源。保留原附件以支持旧修订、其他引用及撤销，不宣称首次转换完全没有派生文件；不主动清理历史原件。
- 该首次转换拟作为现有 `/notes/transfer` 的本机附件转换动作（如 `promote-image`），以当前笔记、有效编辑 ID 和已登记附件 ID 为输入，直接读取本机已有原件。服务端检查草稿/笔记归属、编辑资格、根目录与取消状态，登记草稿引用后发布图片；不接受任意路径，不经浏览器下载后再次上传。按哈希复用已存在、校验通过的目标。
- 未保存附件和草稿恢复也须可转换，不能仅依赖本次窗口的 `File` 内存缓存或已经存在的正式修订。异步转换结束时重新核对当前编辑与目标文字；目标已修改、换篇、取消或换库则不写回。失败保留原链接。

### 多选模式

- 标题、摘要、时间、复选框及条目内留白的左击均切换该条目的选中状态；一次点击只切换一次，不产生打开正文请求，不重置列表滚动。
- 多选期间隐藏条目的省略号及单篇引用/关联等按钮，操作集中到现有批量工具条；关闭进入模式前已打开的单篇菜单。右键不再暴露打开、改名、收藏等单篇动作，本轮不增加新的批量右键菜单。
- Enter / Space 在聚焦条目时与点击一致；复选框保留正确选中语义、焦点和可访问名称。双击不打开正文，抑制同一双击序列的第二次翻转，避免刚选中又取消。
- 退出多选恢复普通打开与单篇菜单；正文已打开时保持原阅读内容，不为了选中另一条目改变正文。窄侧栏不得因选择跳转至详情。
- 主页面、独立窗口共用的列表和侧栏三个选项卡统一执行以上规则；不改变笔记本导航、日期分组标题、加载更多等非笔记条目的用途。

## 验证与响应目标

保存、草稿资源登记及正文资源引用受影响，整轮按第三档：类型检查、构建、相关专项与 `npm test` 全量回归；安装候选并核对隔离实际包。

- 输入矩阵：截图、单图、多图、图加 PDF/TXT、纯文件；粘贴/拖放/两个工具栏入口/补充区；MIME 为空或错误、不支持图片、超限、取消、部分失败与连续输入。原生截图和资源管理器输入必须在隔离 DSH 实测，不能仅用构造事件代替。
- 切换：图片资源与附件图片；新建未保存、已有笔记、草稿恢复；同图多处、引用式 Markdown、代码块；撤销重做、取消编辑、保存、重启、历史、下载原字节/哈希、会话引用、Markdown ZIP 和 PDF/图片导出。非图片/损坏/超限图片始终不能绕过内嵌校验。
- 并发：转换中继续输入/删除目标/换篇/取消/换库；另一窗口占用；转换资源被其他笔记/旧修订引用时不误删。保存沿用单次正式版本，转换不提前产生正式笔记。
- 多选：主列表各过滤结果、侧栏三个选项卡、宽窄窗口；每类条目测试标题/摘要/时间/边缘/复选框、键盘和双击。检查选择数量、正文与滚动不变，以及点击没有调用打开正文接口。退出后恢复正常打开；批量确认、跨本选择、分页和会话切换按现有语义回归。
- 真实联网仅用 `.dsh-home/pure-001/` 和 `StarWind97/dsh-community-private-test`，验证展示选择保存同步及重启读回，不使用日常资料。测试结束关闭自建进程，保留原可重启体验入口。
- 性能基线在实施前以当时实际资料为准；上一轮 121 个笔记 ID 的测量只是历史参照，不能忽略后续新增的验收笔记。使用同一批次、资料、窗口尺寸和完成标准，常用场景至少各 5 次，报告中位与最大值。
- 已归档图片切换与多选反馈目标中位 ≤100 ms、最大 ≤200 ms；不得为选择打开正文、为纯展示切换重传二进制或增加全库扫描。文件接收与展示分开计时；混合链接不加载图片像素，不能把少渲染直接宣称为上传加速。图片上传路径与批准前同图展示基线比较；超过 20% 的中位回退须定位并修正或明确记录，不把不同呈现形式硬作等价比较。

## 风险与回退

- 混合输入默认链接可能不符合个别图文写作场景：用逐项切换和显式插图覆盖，不增加每次确认。
- 异步转换和正文位置变化可能改错引用：使用编辑器位置映射、原片段与编辑身份复核；失败不动原文。
- 附件首次转换可能影响引用、历史和清理：严格复用草稿登记与内容哈希，不改旧修订，不立即删除原附件；专项覆盖通知缺失 / 共享资源及取消。
- 多选事件冒泡可能双重切换或残留菜单：采用单一交互入口，真实点击和键盘用例验证，不以源码字符串断言代替。
- 回退采用新增回退提交与重新构建，隔离安装可退回上一候选 `fatfish-local-data-70132789531f.tgz`。正文仍是旧版本可理解的图片/链接和已有资源类型，没有格式迁移；已保存的用户排版不自动逆转。
