# 阅读空间、列表组织与操作精简：验证与隔离体验

2026-11-16 完成；接续[正式规划](2026-11-15-reading-organization-refinement.zh.md)。本轮已实施、安装和验证，未发布、未更新市场、未升级 DSH，未改日常资料。真实宿主为 DSH 0.2.2-rc.1，测试目录为项目内 `.dsh-home/pure-001/`。

## 本轮交付

- 资料入口与字词统计合并在一条底栏，附件与反向引用分别显示图标和数量；右侧模式只有右上入口。固定按钮仅在展开后显示。自动面板向上展开，固定面板按内容占高，最多约正文区域三分之一。旧缺陷确为浮层仍占用收缩的 Grid 行，导致高度塌到 1 px；已解除这项布局依赖。
- 打开的笔记标签按可用空间收纳到尾部下拉菜单，当前页保持可见。标签和溢出列表可右键关闭当前或其他标签；保存失败保留标签。侧栏鼠标、键盘切换都同步笔记本定位。
- 列表简介使用整行，不再为笔记本归属单独占一行。条目菜单在悬停、键盘焦点、当前项及触摸环境可见。收藏入口紧接“全部笔记”；默认笔记本与收藏使用不同语义图标。
- 星标表示收藏，置顶独立控制排序。主列表与侧栏可按修改时间、创建时间、标题升降序查看；笔记本支持拖动、上移/下移和名称/创建时间查看。手工顺序优先，新本追加；默认本不强制排首位。
- 移除模板入口和实例化；旧模板按普通笔记读取、编辑、计数、导出和引用，保留原 ID、文件与修订历史。保留创建副本。
- 增加中文、西文字体选择、预览和缺失提示；段落、列表、表格与强调内容共同遵循阅读字体。默认跟随宿主；代码仍随包提供 Cascadia Code，Regular 默认。PDF 使用随包字体，PNG 沿用阅读排版。
- 用户手册精简为三篇、1409 汉字，复用已有配图和附件演示。新种子使用版本 2 身份；普通用户旧副本不自动覆盖。移除阅读、编辑和对应输出中的“私人笔记”重复标记。

## 快捷键与兼容边界

- Ctrl+Tab / Ctrl+Shift+Tab 已经 DSH Electron 宿主输入路径验证，作用域限笔记区域；侧栏跨笔记本定位另作定向验证。系统 SendKeys 在当前自动化会话未送达，不能据此宣称每种系统键盘环境已实测。普通浏览器可保留组合键给自身标签，使用笔记标签及下拉菜单仍可完成操作。
- 不接管 Ctrl+W，避免覆盖 DSH 原有页面/窗口关闭。标签上的关闭按钮和右键菜单均可用。
- 正文字体依赖本机可用字体，缺失时回退；代码的拉丁字体随包，中文注释由系统字体补足。PNG 与 PDF 的字体机制不同，不承诺 PDF 与当前页面逐像素一致。
- 整理信息使用独立、带校验的不可变事件，不改变旧正文修订格式。并发手工顺序采用确定性先后规则收敛，并非自动合并两个人的所有排序意图；可重新调整。旧版会保留这些文件，但不会展示置顶和手工顺序功能。
- 本轮未检查新的 DSH 版本，也没有声称宿主已提供直接添加会话输入附件的接口。后续兼容性检查仍必须核对该接口。
