# 同一 DSH 资料的跨窗口外观设置同步

状态：2026-11-16 已按批准范围完成规划、试验、开发和验证。见[验证与隔离体验](2026-11-16-shared-appearance-results.zh.md)，未发布。

## 目标与边界

- 主界面、会话侧栏与独立窗口使用同一份持久外观偏好：布局、配色、对比度、字体、字号、代码与资料区选项等。任一入口修改后，其他入口及时更新；侧栏仍按自己的空间适配。
- 窗口尺寸、阅读位置、打开标签不共享。手动明暗仍仅影响当前视图本次使用；侧栏始终跟随 DSH，宿主实际明暗改变后主视图恢复跟随。
- 首次迁移以主界面现有偏好为准，保留主/独立两边的旧值，防止先启动的独立窗口默认值覆盖主界面。主界面还未提供旧值时，不擅自完成迁移。
- 设置保存在当前 DSH 资料目录，不进入私人笔记 Git 仓库，不改变笔记、同步、编辑租约和回收站协议。不升级 DSH、不加依赖、不发布。

## 方案与取舍

采用宿主本机统一设置存储、客户端缓存及字段级修改。设置更新有版本，按服务端接受顺序合并，避免两窗口修改不同字段互相覆盖；重新打开/恢复连接时核对权威状态。旧浏览器值只用于一次迁移及备份，不在每次连接时重新覆盖服务端。

优先复用现有通信能力进行变更通知。先核对 DSH 转发及独立 HTTP 通道是否支持轻量通知/等待；若可用，设置变更立即唤醒等待的窗口，超时及连接恢复仅做核对。保留既有窗口协调心跳，不因换肤更改租约续期。放弃缩短全局轮询间隔和全量设置定期回写，避免空转与覆盖。

影响文件预计包括共享外观值校验、宿主本机设置服务、HTTP/类型契约、客户端外观存储与生命周期、主题观察及相关测试。接口保留 loopback、Origin、窗口身份和请求大小限制。设置读取只访问内存，落盘只发生于有效变更/首次备份；通知不扫描笔记、不触发正文刷新或重挂编辑器。

## 分轮步骤

1. 核对入口、传输能力及现有行为，记录双窗口设置不同和主题切换基线；据试验选择通知方式。
2. 实现共享存储、迁移保留、字段合并与失败恢复；接入三入口及宿主明暗变更。同步失败应有可理解提示，未确认更新可重试，不假装已保存。
3. 单测验证迁移顺序、并发字段合并、失效/重连、持久化失败与身份边界；类型检查、构建、相关/全量验证按实际影响选档。
4. 隔离安装，实际主界面/独立窗口/侧栏双向修改、关闭重开、DSH 明暗及编辑中切换；记录性能与未覆盖边界，更新设计、使用说明和交付记录。原体验入口更新，保留前版包回退。

## 验收与风险

- 同一资料下三入口的持久偏好最终一致，宿主重启可恢复；原两端偏好可追溯。不同 DSH 资料之间不串用。
- 常用设置变化至少 5 次，区分请求完成与对端实际显示；本机前台目标多数小于 300 ms，单次超过 1 秒需定位。不承诺后台节流情况下即时响应。
- 核对无变化时的请求/写盘频率；不得新增每 2 秒读笔记、扫描仓库或写配置。既有示例库规模和窗口尺寸随记录注明。
- 风险：启动竞态、失败回写、旧响应覆盖新值、通知请求占用写队列、明暗观察回路、迁移丢失。用有序字段补丁、独立通知等待、版本核对和保留旧值控制。
- 初步按第三档验证：本轮涉及宿主持久设置与跨窗口通信，计划运行类型检查、构建、全量回归及隔离实际安装；真实 GitHub 仅核对已有测试库状态，不为外观修改制造笔记修订。
- 预计三轮开发/验证。交付规划、代码、验证记录、隔离候选与原启动入口。回退重装前版 `fatfish-overlay-titles-07c4e8a93cb9.tgz` 或新增回退提交；保留共享设置文件及旧值备份，无笔记数据迁移。
