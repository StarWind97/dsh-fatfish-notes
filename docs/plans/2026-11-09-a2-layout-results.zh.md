## 实际行为

- 按插件可用宽度自动展开「笔记本 → 笔记列表 → 正文」，不依赖是否全屏。首次达到 1140 px 展开，已展开时缩到 1100 px 以下才收起；窄窗改为列表顶部下拉选择。
- 笔记本栏初始 196 px，可调 164–260 px；笔记列表初始 312 px，可调 240–440 px。空间不足时临时收窄列表，优先保留正文空间；不覆盖用户偏好。
- 两条分隔线支持鼠标拖动、键盘方向键、Home/End，双击恢复该列默认宽度。手动收起后不随拉宽自动展开，可通过列表标题旁按钮重新展开。
- 笔记本栏显示全部笔记、各本及数量、默认本标记、管理与回收站入口；与现有下拉、管理选项卡共用同一选择。切换时沿用自动保存。
- 宿主内和未来独立入口分别保存本机布局偏好。布局不进入 GitHub 同步；A2 未开放独立窗口按钮。
- 阅读、原地编辑、标准宽度/全宽、章节目录及宿主深浅主题继续可用。切换栏位不重新挂载编辑器；标题尺寸采用 A1 的 27–38 px 范围。
