## 内容与使用方式

- **开发手册：8 篇**。前序工程说明、设计与协作内容归入同一本，新增维护索引，链接当前源码、开发入口及验证依据。
- **用户手册：11 篇**。新增六章正式手册，另保留五篇前序上手、转存和导出案例。正式新库只提供六章，不带工程回归资料。
- 六章按“开始 → 写作 → 图片与文件 → 留下对话 → 查找复用 → 阅读与交付”组织。首页使用 GPT 生成的 3:1 窗边书桌配图，其他章节用真实 Markdown 排版、有效附件与笔记链接演示功能。
- 配图与手册源在 [assets/handbook](../../assets/handbook/README.md)。一张图片复用，不增加字体、渲染框架或外网图床。会话章节明确为示例，没有虚构实际模型执行结果。
- 旧 12 篇示例的 ID、正文、摘要、来源、图片与附件保留；只归并所属分类，原修订可追溯。旧空分类移除，其他验收资料不变。最终 156 条记录、145 篇在用。

## 初始化与修改保护

首次连接已验证的专用私库后，仅当本机、远端都没有笔记修订/删除历史，且笔记本仍是未改过的默认种子时，自动加入用户手册。默认笔记本仍用于日常收集；首页按初始顺序显示，不在后续启动时强制打开。

已有库升级不自动塞入内容。设置中可“打开用户手册”；找不到有效副本时，再由用户点击“添加用户手册”。识别使用稳定身份，不依赖标题；编辑、改名、移动和删除都保留。整册删除后主动添加使用新一代身份，不复活旧的已删除笔记。

导入采用已有资源验证、修订与同步机制。手动导入有可恢复的本机待完成记录，成功后清除，也纳入离线位置迁移。笔记格式与远端 schema 不变；普通阅读不触发手册扫描或联网检查。手册副本不会随升级静默改写。

## 体积与性能

候选压缩包 17,883,794 字节（约 17.06 MiB）；相比前一候选增加 1,982,347 字节（约 1.89 MiB，12.47%）。解包总量 29,275,387 字节。图片本身 2,070,036 字节，2172×724，独立随包存放，未内联进前端主脚本。两份附件分别为有效 Markdown 596 字节、CSV 239 字节。

接口辅助计时包括窗口注册与读取，原基线 33.6 / 47.5 ms；最终同资料旧候选 47.7 / 64.1 ms、新候选 50.1 / 53.8 ms，各 5 次。中间在新页面刚挂载时测得 100–300 ms 级结果，拆分可见注册与读取均有等待，因此保留 `performance-final.json`、`request-timing.json`，不能把它们当成纯后端执行耗时。
