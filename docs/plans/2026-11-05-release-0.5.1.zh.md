# 0.5.1 发布收尾

状态：候选包已通过用户审核，2026-11-05 用户明确回复「继续」，授权正式发布及市场版本更新。[0.5.1 正式版](https://github.com/StarWind97/dsh-github-notebook/releases/tag/v0.5.1)已发布，公开下载与隔离安装通过；[市场更新 #12283](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin/pull/12283)已提交，等待上游处理。执行结果见[发布清单](../releases/0.5.1/review.zh.md)。

## 本轮范围

- 已绑定笔记库的设置页补齐 GitHub 登录入口，复用已有浏览器授权、验证码和状态查询。明确要求原绑定账号；成功后恢复同步，账号不符时提示使用原账号，不改仓库或本机位置。
- 保留现有自动保存、同步提示、回收站确认及问题反馈等改进，准备 `0.5.1` 候选包，不继续扩充功能、不增加依赖、不改远端格式。
- 更新中英文说明、升级与回退指引、实际截图、安装包和校验文件，整理一页审核材料。正式 GitHub Release、标签及市场更新需用户审核确认后再执行；不发布 npm。

## 取舍和影响

选择复用现有授权流程，不增加账号管理系统或迁移凭据。改动集中于设置页、语言文件、版本、发布说明及验证记录。登录可能需要用户在浏览器操作；测试不退出用户日常账号、不读取或复制凭据。已绑定库身份与私有性校验继续由现有后端负责。

工作量为一轮小功能与发布收尾。保留 0.5.0 安装包；升级前备份笔记资料夹及控制目录，需要回退时正常关闭 DSH 后安装旧包。自动保存改动只影响操作体验，笔记格式不变。

## 验证与交付

- 发布候选按第三档执行类型检查、构建、全量回归、打包内容核对和实际安装。
- 用项目内隔离 Web/Desktop 与现有指定私库验证旧版升级、普通启动的真实账号、自动保存及重启、双向同步、图文导出。
- 登录的等待、失败、原账号成功、账号不符使用受控接口验证界面与请求边界；真实授权沿用用户已完成的普通 Desktop 账号，只有确需人工操作时再发起。
- 记录实际与模拟范围。候选包固定哈希，截图和审阅页放本机忽略目录，中文提交同步 main。先交审核，不代替用户作出正式发布决定。
