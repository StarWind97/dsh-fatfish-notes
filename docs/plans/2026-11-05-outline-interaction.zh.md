# 目录默认状态、居中开关与阅读跟随

2026-11-05 用户确认实施，包含最后补充的居中半透明箭头与章节高亮。

## 已确认范围

- 每次进入插件，宽窗目录默认展开，窄窗默认收起。根据正文及目录的可用宽度判断；本次使用中的切换笔记、阅读/编辑保留手动选择，跨越宽窄布局时采用对应默认状态，不再共用持久化开关。
- 窄窗点击章节只定位，不立即收起。鼠标离开目录、按钮区域约 200ms 后收起；点击外部、键盘主动移出或 Esc 也可收起。程序定位编辑器导致的焦点变化不算主动离开。宽窗目录只由用户主动收起。
- 正文上方操作栏独立于正文/目录分列，目录从操作栏下方开始，开关不因目录伸缩移位。
- 在正文可视区域的垂直中点放半透明箭头：展开时位于目录左边缘、向右收起；收起后位于阅读区右边缘、向左展开。悬停或聚焦更清晰，避开滚动条；保留顶部目录按钮，替换原目录内的关闭叉号。
- 左列表滚动条距分栏边缘缩至 6–8px，保留列表内容内边距和拖动分栏的空间。
- 阅读及编辑滚动跟随当前章节，单项高亮，必要时将目录条目滚入可见范围；覆盖工具栏遮挡、长章节、文末以及收起后再展开。
