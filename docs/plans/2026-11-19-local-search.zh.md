# 本机搜索与统一筛选

2026-11-19 已批准在主目录分两批实施。第一批预计 3–5 个工作日，第二批另约 3–6 个工作日，含验证。交付可在隔离宿主体验的候选。

1. 用搜索框旁一个面板实现单标签直接替换、常用 8 项、按名称看全部、在全部标签中查找、收起与清除。笔记关键词、范围及其他条件各自保留。加入按修改时间、有附件和附件名查找。左栏继续显示笔记本，正文点标签继续原地筛选。
2. 本机按准确标题、文件名和正文段落对搜索结果排序；显示命中的原句或文件名，从列表打开能到对应段落。普通浏览沿用原有排序。范围限于本机已有文字及附件元数据。

只扩展列表读取契约，客户端沿用目录和 Markdown 渲染，保留旧笔记、冲突版本及分页行为。两批可分别回退界面和查询规则，无笔记迁移。额外侧栏入口的价值取决于可否一步打开固定标签，大库索引待真实性能需要再评估。

按第二档做类型检查、构建、相关测试及隔离桌面和 Web 验收。关注条件交集、取消、跨窗口变化、标签目录失败重试、旧响应、阅读位置和窄窗。用原合成库测搜索函数，并在同一隔离资料比较开面板与选标签到结果显示，热测至少五次；记录首次和热测边界。拟以 1000 篇、约 300 标签评估候选查找和结果显示，中位目标分别为 100 和 300 毫秒。
