# DSH 0.2.2-rc.1 适配规划

状态：实施与验证已完成，以 `e6c1218` 为适配前基线，在 `main` 完成。候选版审核后，用户另行确认发布；`0.6.0` 已正式发布，见[发布记录](../releases/0.6.0/review.zh.md)。下方保留本次适配的原定范围和发布边界。

## 目标与取舍

直接以 DSH 0.2.2-rc.1 为宿主基线，对齐插件依赖与兼容声明，修复会话图片读取接口，验证已有笔记功能。不增加旧宿主兼容分支，不在本轮增加新功能或正式发布。

实测旧候选包被新版的版本检查跳过。官方新接口将图片读取请求从附件 ID 改为完整图片引用，因而仅放宽版本声明不成立。会话文本读取、主要 UI 扩展位置及目录选择接口仍保留，集中适配这些边界。

## 影响与风险

- 更新 `package.json`、锁文件中的 DSH、Cordis、Schemastery 依赖。
- 更新 `src/host/note-conversation.ts` 与会话转存、导出之间的图片引用传递及相关测试。保持已归档笔记可读；宿主引用只用于读取原图。
- 按新类型检查结果调整必要的宿主接口调用；保留 HTTP 访问栅栏、私库身份校验、原始素材和图片校验。
- 同步开发入口、使用指引、验证记录及 `0.6.0` 发布审核材料。
- 主要风险是依赖升级和会话事件变化影响加载、图片及会话选材。当前提交和旧候选包作为回退依据；测试仅使用隔离资料及指定私库，日常资料不变。

## 验证与交付

按第三档执行：类型检查、构建、全量回归一次；打包后在新版隔离 Desktop/Web 实际安装，检查初始化、目录选择、会话图文转存、自动保存、章节目录、导出及真实私库双向同步。失败后针对影响范围补验，不无故重复全量。

预计为中等规模集中适配。交付中文提交并同步 `main`、新的 `0.6.0` 候选包与校验值、实际效果和可重新启动的隔离体验入口。未覆盖的模型调用和平台明确记录，正式发布仍需用户确认。

## 完成情况

实际结果：类型检查、构建及 218 项回归通过；新版隔离 Desktop/Web 的加载、保存、图文转存、导出、初始化和真实私库双向同步通过。三套隔离安装各核对 128 个包文件；最终包补验桌面加载。完整边界见[验证记录](../verification-log.zh.md#dsh-022-适配候选版)，包摘要及下一步见[发布审核](../releases/0.6.0/review.zh.md)。
