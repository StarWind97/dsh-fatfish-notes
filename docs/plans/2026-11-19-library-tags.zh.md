# 全库标签整理

用户已批准筛选面板内的「管理标签…」。基线为 4d1ae22。其余候选为分类管理分区、笔记本栏入口、独立顶栏。首版沿用现有全库目录与阅读区筛选，只有整理窗口能发起批量修改。

1. 登记并核对入口、全库目录与笔记修订。预览列出每篇笔记、笔记本及标签变化。新名已存在时明确显示合并，回收站和历史保留原样。
2. 新增本机预览与确认，使用既有笔记修订和同步。确认核对预览、编辑占用与目录变化。中断后只接续尚未完成的笔记；撤销按实际改动还原，防止覆盖后续修改。客户端保留阅读位置和其他筛选条件。
3. 第三档验证，覆盖跨本、重名、去重、失败重试、两个窗口、旧资料、离线、窄窗，构建并运行全量测试，在隔离 Web 和桌面体验。使用既有 156 篇／81 标签隔离测试及上次的筛选时序作参照，热操作各至少五次。目录输入直接在本机缩小候选，普通阅读不增加请求。预计单人 4–7 个工作日。

涉及客户端筛选、对话框、请求契约与宿主写入。无需安装依赖或迁移资料。软件可退回原包，已写入的标签使用撤销或笔记历史恢复。交付隔离体验、验证边界及使用说明；公开发布另行安排。

## 实施与取舍

- 起点实测为 rc.5 Web 的 156 篇／81 标签、rc.5 Desktop 的 157 篇／81 标签。开面板首次分别为 158／126 ms，随后各 5 次的中位为 144／96 ms、最大为 153／163 ms。网页自动化从点击计到标签候选可见。
- 每个资料库只保留最近一次整理的本机记录，操作开始前落盘，包含原修订和预计写入的修订。写入途中退出、漏收回复或宿主重启后均可核对实际历史。整理记录随本机资料夹移动；普通笔记修订照常同步。每批集中更新一次资料库清单。
- 两端初验完成后，调整了完成操作后的目录选中项，让改名／合并停在目标标签、撤销回到原标签。实际 Web 安装采用明确插件名与本地包路径的离线方式；隔离资料中原先使用的公开包地址会触发联网查询。

- 最终候选沿用 0.9.3 版本号，包摘要为 `5683572fabd51448006cb0c935f7974532b1d25b6bef6e724e665854c0e7c9ff`。rc.5 Windows Desktop 与 rc.5 Web 各 259 个安装文件逐一与候选包一致。可从[隔离桌面](../../scripts/Open-Fatfish-Notes.cmd)打开，进入「笔记 → 筛选笔记 → 管理标签…」。待用户体验，公开版仍为原 0.9.3。回退可重装上一轮保留的阅读区标签候选。
- 两端均从阅读区点标签开始，在搜索词和当前笔记不变的情况下，预览跨两本笔记本的合并；两篇受影响，其中一篇已有目标标签。另一窗口占用时确认被拒绝、两篇均保留原标签；解除占用后再确认。验证目录跟随新名和撤销后的旧名、筛选跟随、改名、移除、再次撤销。Web 另外使用 390 × 760 窄窗检查并操作预览。测试笔记按本轮创建的身份逐篇核对后清理。
