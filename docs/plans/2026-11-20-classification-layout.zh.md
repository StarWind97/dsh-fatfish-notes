# 分类管理三栏与标签核对

以已确认的独立原型为依据，在主目录 main 从 cd05c5b 实施。正式入口为「分类管理 → 标签」，笔记本页继续使用现有管理列表。

- 用主题色下划线标出当前页。标签目录、笔记列表与正文按可用宽度分配，两处分隔线支持拖动、键盘和恢复自动宽度。栏宽偏好保存在本机。沿用插件主题、配色、密度及阅读设置。
- 笔记每批 50 篇，点「加载更多」追加。追加保留选中笔记和滚动位置；阅读到批次边界可直接看下一篇。左侧标签目录保留分页。
- 改名、两名合并及移除立即展示全库影响。标签名、影响统计、确认按钮及列表工具按定稿布置。来源和保留页签紧贴笔记列表，右侧展示本文变化。近似候选按已有名字的可解释书写差异优先排列，修改需要明确确认。
- 复用现有目录、搜索、预览与写入接口，不增依赖，不变更数据格式、同步、宿主设置和公开发行。影响面集中于客户端及中英文文案。主要风险是过期的查询结果串入新筛选、混淆全库和当前列表、较窄栏宽下操作不可见。
- 类型检查、构建、相关回归、隔离 DSH 实机验收。用同一资料检查冷热切换、真实长列表及分批边界；核对主题、两种入口、单篇与批量交互。对照旧版隔离记录，桌面 157 篇、81 个标签，1360 × 920 下目录热打开中位 291 ms，切换标签 136 ms、正文 135 ms。独立原型 472 px 中栏、指定示例从中栏顶部到笔记列表为 258 px。
- 交付可重开的隔离体验入口、安装包与验证结果。回退使用[上轮候选](2026-11-20-classification.zh.md#体验与回退)。按客户端变更、聚焦验证和隔离安装三步推进。
