# 肥鱼笔记中英文体验与发布验收规划

2026-11-22 已获批准。本轮交付完整的中英文界面、随包手册、在线图解和实拍，连同持续检查。候选在官方 DSH 的隔离 Windows 桌面和 Web 做同包双语验收。改号与复验见[本轮记录](#改号与新候选复验)，正式发布和市场复核由用户确认后启动。

## 现状与设计

0.11.0 安装包的两份词表各有 801 条。主界面和会话侧栏接入 DSH 语言，独立窗口仍用固定中文翻译器，转存、设置、手册入口等还有直接写入的中文。中英文 README 共用四张中文实拍，英文的用户操作说明仍链接中文图解。现有发布清单检查图文更新，现有转存回归检查中文界面。

- **界面。** 复用 DSH 当前有效语言与现有词表。宿主内入口继续由 DSH 提供翻译，独立窗口读取既有宿主状态中的语言。语言切换后重渲染展示文案，编辑状态和用户笔记正文沿用原始资料。面向用户的按钮、状态、无障碍名称和插件生成的提示在显示处翻译。用户会话按原文转存。
- **手册。** 中英文作为独立、带版本的可编辑手册副本，按界面语言打开或添加。利用现有手册版本和导入协调，保证跨设备的相同语言种子身份稳定，保留旧中文手册的打开方式和用户编辑、移动、删除行为。只在专用隔离资料与指定测试库验证实际装包。
- **图文。** 中英文 README 各用同一场景的对应实拍，另提供英文图解与详细操作参考。截图里的产品文案、图注、演示笔记与会话使用同一语种。市场网页分别收录两份 README；市场目录的共用截图字段按其单列表格式维护。
- **流程。** 在项目约定明确用户可见变更的双语要求，将逐语种图文检查补进现有清单。自动检查进入既有测试入口，覆盖词条和插值、直接写入的可见文案、图文路径及代表性双语界面。后续发布记录写明实测结果和市场双页刷新状态。

## 顺序、影响与回退

1. 审计全部界面、插件生成内容、宿主语言传递和手册导入。先用现有发布验证入口确认基线，再实现语言读取、界面补齐和手册。主要改动在 `locale/`、`src/client/`、手册载入及相关宿主路由。
2. 增加能捕获 0.11.0 已知问题的自动回归，更新开发约定和图文维护清单。完成两份 README、手册及英文图解、参考。用任务演示资料完成同场景实拍与检查表。
3. 类型检查、构建、全量回归通过后，从同一正式候选安装到两个既有隔离资料，核对安装内容及 SHA-256。最终实拍与候选上的界面和演示流程逐项对应。第三方市场两语实页核对安排在获准发布后的收录阶段。

这是一轮中等偏大的界面与文档改动，主要工作是清点文案、测试语言切换和为两种语言准备成对素材。重点防止英文文本挤压窄窗、切换语言导致编辑器重建、跨设备导入产生重复手册以及覆盖用户已编辑的手册。按实现、检查与文档的差异回退，旧种子及用户已保存的笔记按原格式读取。

## 验收与证据

- 自动检查验证词表键与运行时插值一致，实际渲染覆盖转存、设置、独立窗口语言。手册覆盖新库初始化、已有人库、旧版手册与并发添加。
- 隔离桌面、Web 各走简体中文与英文。在 DSH 切换语言并打开主界面、设置、侧栏、宽窄转存、独立窗、手册及导出。核验一次常见失败提示以及实验会话的保存读回。截取证据并检查首次使用、图解和公开四组实拍。若真实私库同步进入验收，使用 `StarWind97/dsh-community-private-test`。
- 交付候选路径、摘要、验收记录及可重新启动的隔离体验入口。发布前按用户确认执行；公开安装包、GitHub 两语 README 与市场两语详情分别核验。
