## 品牌图标

DSH 入口、会话笔记入口和笔记顶栏使用小鱼，原入口名称与操作保持。进入「设置 → 帮助」可看到鱼形、肥鱼笔记与 Fatfish Notes 的完整组合，会随当前视图切换深浅色并适配窄窗口。手册书本、设置齿轮等功能图标保留。

实际体验双击 [Open-Fatfish-Notes.cmd](../scripts/Open-Fatfish-Notes.cmd)，使用原独立测试资料；日常 DSH 不会因此自动更新；当前版本的实测与发布状态见[开发入口](README.md#当前状态)与 [0.13.0 验收记录](releases/0.13.0/review.zh.md)；品牌图标首次接入的历史记录见[品牌接入交付](plans/2026-11-16-brand-logo-results.zh.md)与 [0.9.0 发布记录](releases/0.9.0/review.zh.md)。

## 用户手册

在 DSH「设置 → 通用设置 → 语言」选择简体中文或英文，主界面、会话侧栏和独立窗口会跟随所选语言。「设置 → 帮助」打开当前语种的手册，也可按需添加另一语种的手册副本。

新建的专用私有笔记库完成首次同步后，会提供“用户手册”：三篇可直接阅读、复制和修改的笔记，集中介绍使用、资料交付和保存注意事项，包含配图、表格、笔记链接与下载文件。原来的默认笔记本继续用于日常收集。

在“设置 → 帮助”中点击“打开用户手册”即可回来。既有笔记库不会因升级自动增加手册；没有手册时，入口会提供“添加用户手册”，由你主动加入。删除的手册不会在重启或同步后自行出现；再次添加的是新的副本。你的改名、移动和正文修改都保留。

手册和普通笔记一样需要检查保存与同步状态。内容与图片已随包提供，完成初始化后可离线阅读；不用加载外部图片网站。阅读态任务清单不会直接改动笔记，练习时先复制，再进入编辑。

2026-11-13 的文件添加与同步响应改进沿用原有操作，可通过下方隔离入口体验。测量结果和仍可能出现的等待见[本轮记录](plans/2026-11-13-local-data-path-results.zh.md)；测试资料与日常笔记分开。

## 外观、阅读与资料区

主界面或独立窗口的「设置 → 外观」可选择三套布局（柔和卡片三栏、经典秩序分栏、目录树双栏）、六种配色（莓紫春芽、DSH 原生、松青、暖琥珀、莓红、石墨）和三档对比，采用圆角分区卡片与分段控件。默认是「经典秩序分栏 + DSH 原生 + 标准」，深色采用中性炭黑表面层级；从旧版升级时，已退役布局与配色在共享配置、本地缓存及待写队列中均会自动平滑迁移。笔记主界面和会话侧栏跟随 DSH。点笔记主界面顶栏的太阳或月亮，可切换并保存 DSH 的明暗。若要恢复「跟随系统」，在 DSH 自己的外观设置中选择。独立窗口可临时切换本次视图的明暗，DSH 切换明暗或重新打开窗口后恢复跟随。不同布局共用同一笔记和编辑器，切换时保留正在输入的内容。窄会话侧栏采用单列阅读与返回列表。

设置分为「外观」「阅读与代码」「工作区」「同步与存储」「帮助」。进入「分类管理」或「设置」时，页面使用完整宽度。返回「笔记」后恢复原有的笔记本栏及栏宽。字体和代码显示放在阅读与代码，资料区、笔记标签和会话操作按钮放在工作区。主界面与独立窗口使用同一分类；会话侧栏不设全局外观入口，沿用这里的共享设置，保留当前工作区的笔记本设置。点击标签切换，标签获得焦点后可用左右方向键及 Home/End；空间很窄时改用分类选择器。内容较多时，在内容或两侧留白上均可滚动，分类导航保持可见。切换分类会保留本次尚未提交的输入；「恢复全部外观默认」恢复所有外观偏好，不仅限于当前分类。

正文默认跟随 DSH 字体；中文与西文字体可分别选择，提供预览，缺失时使用系统回退。现代清晰、书页或混排及字号、行高可以独立调整；顶部仍可选标准宽度或全宽。代码提供语法高亮、复制、折行和行号；默认 Cascadia Code Regular 14 px，可选 Light/Medium。高亮不格式化或修改代码；未知语言、超大代码或处理失败时仍完整显示原文。代码字库随包提供，中文等字符使用本机字体回退。

补充附件和引用放在资料面板。默认入口位于字词统计底栏中部：回形针表示补充附件数，链接表示引用本篇数。点击向上展开；未固定时点击正文或按 Esc 收起。固定按钮只在展开后出现，固定面板按内容占高，最多约正文三分之一。底部模式不重复显示顶部入口，右侧模式只在正文工具栏提供入口。也可设在右侧，选择与目录切换显示或上下分区。实际正文空间不足时回到底部，文件名含后缀和大小同排；内容多时面板内部滚动。正文里已有的图片/下载链接仍保留原位，面板计数是补充资料，不重复列出正文文件。

本次打开的笔记以标签显示，点击切换并定位所属笔记本与列表条目，各篇保留本次阅读位置。可拖动标签排序。标签获得焦点后可用左右方向键、Home/End 移动，再按回车打开。标签过多时，从尾部下拉访问。主界面和独立窗口可点末尾的「+」打开概览，再从概览进入正文。右键可关闭当前、其他或所有笔记标签。关闭全部会先自动保存当前编辑，保存失败时保留编辑和全部标签。关闭正在阅读的笔记时优先切到右侧还开着的标签，其次向左查找。关闭后台标签时保持当前正文。标签按当前窗口或入口独立保留，可在设置中隐藏标签栏。

概览里的「最近打开」和「最近修改」可直接进入正文。访问记录留在当前浏览器和当前笔记库，最近修改包括已同步到本机的笔记。

外观设置保存在当前 DSH 的本机资料中，主界面、会话侧栏和独立窗口共享布局、配色、字体和资料区等偏好；在主界面或独立窗口修改，其他视图随之更新。窗口尺寸、阅读位置和已经打开的笔记标签仍各自保留。首次升级以主界面原设置为准，两边旧值都保留；如果独立窗口提示等待合并，先打开 DSH 中的肥鱼笔记即可。设置暂未同步时会提示并自动重试，未确认的选择在刷新后仍可继续重试。外观不上传私人笔记库，也不跨设备共享。

独立窗口的“跟随 DSH”通过宿主连接获得明暗；手动明暗仍只影响本次视图，侧栏始终跟随 DSH。布局、配色和字体等选择不受明暗切换影响。弹窗和菜单沿用发起区域的明暗。恢复默认会同步恢复共享的外观选项，不删除笔记。图片导出沿用当前阅读排版，当前宽度包括全宽；资料面板开合不影响勾选素材是否导出。

笔记本、笔记条目及图片/图片文件链接旁的「…」不占用内容空间，显示时覆盖末端；悬停、键盘焦点进入或菜单打开时可见，选中条目的菜单也会显示，触摸设备保持显示。笔记列表标题只占一行，超长显示省略号，悬停可看完整标题；简介仍使用原有行数。会话侧栏的「引用」采用气泡加号图标，表示加入当前会话，操作方式不变。

## 三栏与独立窗口

本机[隔离体验入口](../scripts/Open-Fatfish-Notes.cmd)用于测试示例，不连接日常资料。

- 拉宽窗口后，左侧显示笔记本，中间显示笔记列表，右侧阅读或编辑。窗口变窄时，笔记本栏自动收起，可在列表顶部下拉选择。
- 顶栏按「笔记 / 分类管理 / 设置」切换页面。笔记本栏右上角按钮用于收起；空间充足时，列表标题旁提供展开按钮。顶栏不重复放置折叠按钮。手动收起会被记住，不会因为拉宽就自动弹回；窄窗口在列表顶部下拉选择笔记本。
- 拖动两条列分隔线调整宽度，双击恢复该列默认值。也可用 Tab 聚焦分隔线，再用左右方向键调整。
- 「管理笔记本」与顶栏「分类管理 → 笔记本」进入同一个管理页面。返回「笔记」会保留当前阅读位置。回收站在展开的笔记本栏底部，收起后位于笔记列表底部。
- 在笔记顶栏点「独立窗口打开」图标，会先保存当前内容，再在单独窗口显示这篇笔记。可以留着它，回到 DSH 会话继续工作；重复点击会找回原窗口。
- 两处可以分别编辑不同的笔记。同一篇正在另一处编辑时，会显示提示；点「在这里继续编辑」，原处保存后将编辑交给当前窗口。等待时可以取消，中文组词或附件导入尚未完成时请稍候。
- 若独立窗口正在编辑其他笔记，主窗口传来打开请求时可选「保存并切换」或「留在当前笔记」。列表和阅读内容会在本机保存后自动更新，无需手动云端同步。
- 独立窗口需要 DSH 保持运行。关闭 DSH 后会暂停编辑并保留本机恢复记录；重新启动同一套 DSH 资料后会自动重新连接、核对恢复内容并返回阅读态。不要为恢复内容清空浏览器资料。
- 当前自动开窗支持 Windows 上已安装的 Chrome 或 Edge。Windows 偶尔不允许其他窗口抢焦点，此时可从任务栏切回；不需要反复新开。

建议使用「阶段 A · 两处窗口从同一篇继续」测试笔记，依次体验宽窄布局、同篇交接和在 DSH 会话中保存图文。截图、完整体验步骤及验证边界见[阶段 A 交付记录](plans/2026-11-10-stage-a-results.zh.md)。

## 查找、整理与复用

收藏与置顶分别用于收集和优先排列；搜索、标签与批量操作帮助整理已有资料。

- **收藏与最近访问**：阅读工具条的星标用于收藏；列表工具栏通过「全部 / 收藏 / 最近」分段控件切换视图。收藏不等于置顶，条目/正文更多菜单中的“置顶笔记”用于优先排列。收藏随私库同步；最近访问只保留当前浏览器、当前笔记库的最近 50 篇，不上传。两种窗口的浏览记录各自保留。
- **搜索与全局快速切换**：在搜索框输入关键词或附件名，多个词用空格分隔，结果显示命中片段或文件名，点带正文片段的结果可跳到原句。主界面与独立窗口还可按 **`Alt+K`**（macOS 为 **`⌥K`**）或点顶栏快速切换入口，一步检索笔记标题、正文、附件名、笔记本、全量标签及常用命令，支持 `↑/↓/Enter/Tab/Esc` 键盘操作。
- **组合筛选**。可以先搜「全部笔记」再选择笔记本，也可以先限定笔记本。点搜索框旁的筛选按钮可叠加一个标签、修改时间和「有附件」。常用标签随空间安排，点「查看全部」可找其他标签。点条件旁的 × 可单独移除。
- **标签建议**：编辑态的标签输入下方显示已有标签与使用篇数；点击即可添加。标签仍是平面分类，不建立层级。
- **历史版本**：阅读工具条「更多操作 → 历史版本」，选左侧时间查看内容、图片与附件。可「恢复为副本」，也可确认后恢复到当前笔记；后者生成新版本，原始素材与恢复前版本保留。历史对话框可关闭或取消，不做逐字合并。
- **批量整理**：列表「多选」，勾选笔记后选择「批量整理」。可移动到笔记本、添加标签或移除标签，其他标签保留；多个标签用逗号分隔。「全选」覆盖当前筛选结果。另一处正在编辑其中某篇时，本次整批操作会被拦住，先完成编辑再重试。若操作报错，请刷新核对结果后再操作。
- **复制**：「更多操作 → 复制笔记」生成独立副本，保留正文、摘要、标签、图片、附件和来源素材；以后分别修改。
- **内链与反向链接**：点击正文中的笔记链接先看预览，再点「打开笔记」进入；可返回上一篇。预览最多显示前 6,000 个字符。资料面板内有引用时默认展开「引用这篇的笔记」，显示精确总数并先列出五篇，可继续加载；收起仍显示数量，零引用时隐藏，不统计代码、图片、无效引用定义、回收站中的伪关联。
- **排序与置顶**：笔记可按修改时间、创建时间或标题升降序排列；置顶笔记在当前筛选中优先显示。收藏与置顶不会改变正文修改时间。笔记本默认按添加时间，拖动或菜单上移/下移后以自定义顺序为准；新本追加，设置默认本不强制改变顺序。笔记本管理的名称/时间排序是临时查看，不覆盖手工排列。

0.9.0 移除模板机制。旧模板作为普通笔记显示，ID、正文、附件和历史继续保留；占位文字不再自动替换。需要相似结构时使用“创建副本”。

置顶及笔记本手工顺序使用独立的同步整理记录。本轮已使用上一隔离候选验证：旧版可以读写正文并保留这些记录，但不会显示新整理能力。不同更早版本的兼容性不据此推断。两台设备同时改变完整笔记本顺序时会确定地采用其中一份顺序，可在同步后重新调整。

## 章节目录

此功能从 `0.6.0` 起提供。

阅读或编辑时，点击正文右上角的「章节目录」图标，即可查看正文中的各级标题。点击章节跳转；编辑态同时将光标移到标题，之后可继续输入，撤销和重做照常保留。修改标题后目录自动更新，中文组词完成后再刷新。

宽窗口使用固定宽度的右栏，正文包含章节标题时默认展开、无章节标题时自动收起空目录列；窄窗口使用浮层，进入时默认收起。切换笔记或阅读/编辑时保留本次手动开关选择，窗口跨越宽窄布局时采用对应默认状态。目录展开、收起时，顶部操作按钮的位置保持不变。

正文可视区域中间的贴边圆角药丸手柄也能控制目录：展开时点击 `》` 收起；收起时点击阅读区右侧的 `《` 展开，悬停或聚焦时边框与图标高亮，并显示「收起目录」或「展开目录」提示。窄窗点击章节后目录继续显示，可连续选择；鼠标移开稍后收起，点击正文等外部区域、按 Esc 或用 Tab 离开也可收起。宽窗目录会保持展开，直到主动关闭。

滚动正文时，目录高亮当前章节；必要时目录会自行滚动，让高亮条目可见。收起后再次展开也会跟随当前位置。目录很长时可单独滚动；标题过长时悬停查看全文。没有章节时，在正文中插入标题即可，笔记名称和摘要不计入目录。

正文的滚动条在正文右侧，展开右栏时位于正文与目录之间；目录有自己的滚动条。目录靠近窗口右边缘。正文、目录和笔记列表的滑块悬停后会加粗、加深，也可以从滑块周围较宽的区域按住拖动；悬停不会挤动正文。

## 安装、升级与卸载

安装 0.13.0 前准备符合 `>=0.2.2-rc.3 <0.2.3-0` 的 DSH、Git 和 GitHub CLI。从 0.10.0–0.12.0 升级时使用原 DSH 资料，安装后重启；原有私库、笔记、已编辑手册以及旧外观配置与待写队列都会平滑保留和迁移。[安装命令](../README.md#安装与升级)

升级前确认同步完成，关闭独立笔记窗口及 DSH，备份本机笔记资料夹和 `DSH_HOME/fatfish-notes`。按同一安装命令换入新包，重启后检查原仓库和「已同步」状态。

如已有内容，升级前完成编辑、确认已同步，并记下「设置 → 同步与存储」中的本机资料夹。关闭 DSH 后备份该资料夹及本设备的 `DSH_HOME/fatfish-notes/` 控制目录；没有设置 `DSH_HOME` 时，控制目录在用户主目录下的 `.dsh/fatfish-notes/`。如果两者是同一目录，只需备份一份。新版保存可采用 v3/v4 格式，旧 0.8.0 不支持；仅打开旧库不会强制迁移，但同库各端仍应一起升级。回退必须使用相配套的资料备份，不能只重装旧包继续写新版资料。0.5.x 的旧品牌迁移另见[历史规划](plans/2026-11-06-fatfish-notes-rename.zh.md)。

卸载先保存并同步，再关闭 DSH，运行：

```powershell
dsh plugin --profile desktop remove dsh-fatfish-notes
```

Web 使用者替换 profile 名称。卸载只移除插件包，本机笔记资料与远端私有仓库保留；重新安装后可继续使用。不要将删除笔记资料夹作为卸载步骤。

## 首次设置

笔记和图片保存在本机，并同步到你自己的 GitHub 私有笔记库；云端资料默认不公开，也不存放在插件作者的服务器。GitHub「仓库」就是专门保存这些文件的空间。首次设置需要联网，完成后可临时离线编辑。

首次设置与重置笔记库均采用三步进度条向导（1. 同步工具 → 2. 账号与云端库 → 3. 位置与首次同步），环境就绪时自动定位到未完成步骤，支持点回前序步骤修改：

1. **准备同步工具**：Git 负责下载和上传笔记，GitHub CLI 负责登录授权。页面会自动检测，缺少时点击 [Git 官网](https://git-scm.com/downloads) 或 [GitHub CLI 官网](https://cli.github.com/) 的安装入口。Windows 用户下载对应安装程序并按默认选项安装；返回插件点「重新检测」，仍未检测到时完全退出并重新打开 DSH。工具由插件自动使用，无需手动配置仓库或输入同步命令。
2. **登录并选择云端笔记库**：没有账号时点击「没有账号？注册 GitHub」，注册完成后回到插件点「登录 GitHub」。在浏览器完成授权；没有自动打开浏览器时，点「打开验证页面」，输入插件显示的一次性验证码。首次使用默认推荐「新建私人笔记库」，保留建议名称 `fatfish-notes` 即可；换电脑或恢复资料时选择「连接已有笔记库」，填写同一账号下原有的名称。
3. **确认保存位置并同步**：可以直接使用默认位置，或点「更改位置」在目录选择窗口中选择父目录。插件会自动追加云端笔记库名称，例如选择 `E:\我的资料`、库名为 `fatfish-notes`，最终位置就是 `E:\我的资料\fatfish-notes`。取消选择保留原位置，已选自定义位置可点「恢复默认位置」。点「检查并继续」核对 GitHub 账号、云端笔记库和最终完整路径；需要调整时点「返回修改」，最终确认后才创建新云端库或接入已有库并开始首次同步。

首次初始化只使用不存在或为空的最终资料夹，不接管旧本地笔记。如果同名资料夹已有内容，新建云端库时可在第二步修改新库名称（本地名称自动跟随），或更换父目录；连接已有云端库时更换父目录即可。不会自动改名、覆盖或清空原资料。新建本地副本仍会从已连接的云端笔记库下载原有笔记；初始化中断可重试本次位置。

本机 Desktop 使用系统目录选择窗口；本机 Web 使用宿主提供的系统选择窗口。当前未提供系统选择能力的宿主可使用默认位置，或在本机 Desktop 选择位置。

工具显示「已安装」和账号显示「已登录」并不代表同步成功。插件在连接过程中检查资料并执行首次同步，成功后才开放笔记功能。失败时根据提示检查网络、账号或位置，重试当前操作；无需为了重试删除已有资料。普通项目仓库或手动创建的无标识空仓库不能作为已有笔记库接入，应由插件新建专用私有库。

已连接后如果提示登录问题，进入「设置 → 同步与存储 → 同步账号」点击「登录 GitHub」，使用提示中的原绑定账号授权。验证码和「打开验证页面」会显示在该区域；失败可重试。登录正确账号后会恢复同步，登录其他账号时会提示切回原账号，原笔记库和本机位置不变。

## 图片、正文文件与补充附件

| 目的 | 操作 | 显示位置 |
| --- | --- | --- |
| 图片属于文章内容 | 将一张或多张图片粘贴、拖入正文，或使用「插入图片」 | 纯图片批次显示图片；截图同样默认展示 |
| 正文需要引用一个文件 | 将文件粘贴或拖入正文，或使用「插入文件」 | 下载链接；工具栏「插入文件」即使选了图片，也按文件链接插入 |
| 随笔记携带参考文件 | 拖到「补充附件」区，点击此区后粘贴，或点击加号 | 图片与其他文件均为独立文件卡片，不插入正文 |

可在资源管理器里同时复制图片和普通文件，再粘贴到所需区域。**图片和其他文件混合粘贴或拖入正文时，这一批全部显示为下载链接**；补充附件区出现焦点边框时，Ctrl / ⌘ + V 会添加到该区。常规文件直接添加；大文件先确认，确认后返回编辑界面显示进度，可以继续写正文或取消传输。取消传输保留已经完成的文件；「取消编辑」仍放弃本次全部修改。一批正文文件可用一次撤销移除。仅复制路径文字不等于复制文件。

正文图片及受支持图片文件链接旁的省略号提供「显示为下载链接」「显示为图片」和下载原件。编辑源码时，把光标放在对应图片或链接内，也可点「图片显示方式」或右键。切换只影响这一处，可撤销 / 重做；同一图片的其他引用保持原样。阅读态操作会进入编辑，再按正常方式完成或取消。显示方式随正文保存、同步与导出；历史版本、原始素材及回收站不提供修改入口。

已有普通附件首次改成图片时会校验本机原件，后续切换复用图片资源，无需重新上传。正文展示支持 PNG、JPEG、GIF、WebP，受现有 20 MiB / 3200 万像素限制。不符合要求但能安全保存的图片保留下载链接并提示原因。远程图片仍按原有明确导入流程处理。

主列表、独立窗口及会话侧栏进入多选后，点击标题、摘要、时间、复选框或条目留白都只切换选择，双击只切换一次；聚焦复选框可用空格或 Enter。单篇菜单暂时隐藏，退出多选后恢复。主列表改变筛选会清空选择；侧栏可以跨笔记本保留选择。

2026-11-13 开发候选已优化小文件添加及后台同步接收，操作方式不变。同步时会复用未变化资源，并分批接收新增文件，减少连续占用本机处理队列；大文件写入、资料合并期间仍可能等待。实际显示耗时与适用范围见[本机访问优化交付](plans/2026-11-13-local-data-path-results.zh.md)。

补充附件卡片的「插入正文」图标会把文件移到当前光标处，并从补充区移走；常规图片会内嵌显示，其他文件为下载链接。可以撤销或重做这次移动。之后若从正文删除引用，不会自动回到补充区；需要时可重新添加。卡片的叉号只移除当前补充附件，原始素材与已有历史不变。编辑时「取消」放弃本次草稿。

从会话转存时，消息里的图片留在相应位置；新转存的用户上传文件在所属消息原位置显示为下载链接；没有正文位置的 AI 交付卡片放入补充附件区。旧转存笔记保留原来的正文与来源。正文已经实际使用的文件不在下面重复展示。只提到文件名的句子仍是文字，不会据此去电脑中找文件。

引用到会话时，正文使用的图片和文件一起带入，补充附件默认选中、可以取消。Markdown 资源包按当前内容打包，PDF/图片只展示选定内容或文件标签，不附带原件；已移除的补充项不会带出；只有另选「含原始素材」，才会包含原始会话中的材料。

## 日常操作

- 第一次打开笔记库或从会话转存时，按上方[首次设置](#首次设置)完成引导。
- 换设备请选择「连接已有笔记库」，输入同一账号下插件创建的私有笔记库名称。首次建库选「新建私人笔记库」。
- 新建建议名称为 `fatfish-notes`。默认本机目录跟随仓库名；选择其他父目录后仍自动追加仓库名。检查通过后在独立确认页核对账号、仓库与路径，点「返回修改」可继续调整。绑定完成后，设置页显示当前仓库和资料夹。文档在其中的 `notes/documents/`，图片在 `notes/assets/`。
- 更换硬盘时，在「设置 → 同步与存储」点「更换本机位置」，填写新目录的完整路径并点「确认搬迁」。待同步修订、原始素材、图片及 Git 资料一并搬迁。校验成功才切换，目录中自行放入的其他文件仍在原处。已有绑定升级后沿用原位置。
- 日常在不同设备上使用同一个私库即可。只有要换用另一套独立资料时，才需要设置页底部的「重置笔记库」。先保存编辑并同步当前库，再选择接入另一个专用私库或新建私库，核对本机位置。插件会同步目标库，并在离开前取回当前库在其他设备上的更新，确认当前库的本机笔记与远端最新提交一致。两边都成功才切换，取消或失败仍使用原库。原库的云端和本机资料保留。如果已经确认创建目标仓库，取消操作可能留下该私有仓库，可重试同一目标。
- 从 A 切到 B 后，若要回到 A，在「重置笔记库」选择「连接已有笔记库」并检查 A。路径留空即可自动查找。看到「找到原资料夹，是否继续使用？」后核对路径，点「使用原资料夹并切换」。如果在原位置找不到可验证的 A，选「选择原资料夹位置」输入它现在的位置，或选「新建本机资料夹」从同一个远程 A 同步。取消会继续使用 B。
- 每个仓库最后使用的位置记录保存在当前设备的 DSH 资料中，成功搬迁或切换后更新。换电脑时需在新设备确认本机资料夹。
- 在笔记库点击列表顶部主色「+ 新建」，或在阅读页点击顶部「编辑」即可原地写 Markdown；阅读时双击用于选择文字。图片可从剪贴板粘贴、文件选择器选取、拖入或通过公网 HTTPS 图片地址导入。只有路径文字时请选择文件。
- 进入编辑态后，标题下方默认展示一行紧凑属性摘要，点击「编辑属性」可原地展开抽屉修改所属笔记本、标签与摘要，避免切入编辑时正文大幅下跳。编辑期间自动保存本机草稿，不必惦记保存按钮。「完成编辑」返回阅读态，切换会话或插件、刷新以及正常关闭后重新打开，也会显示最后的编辑。编辑期间仍可撤销重做。空白新建页面直接离开不会留下笔记。
- 从已完成的回答下方点击「保存到笔记」，默认勾选这一轮。可以继续点其他回答下方的「选中本轮」。底部转存条显示已选轮次和消息数，点「下一步」打开保存选项。宽窗按内容自适应高度，左栏直接调整轮次（已勾选轮次带高亮标识），中栏直接展示可用图片缩略图与文件列表，右栏填写笔记本与元信息并提供胶囊式「AI 建议」，底部提供「取消」与「保存到笔记」。窄窗的紧凑布局可分别打开范围和文件核对，点确定应用，取消保留原选项。标题栏可以展开、收起或恢复自动布局，切换时保留选材与已填内容。在「设置 → 工作区」可把转存入口改成「仅图标」。[保存问答图解](user-guide.zh.md#保存会话里的问答)
- 0.9.0 从会话回答下移除独立「导出」入口。需要分享或带走会话时，先保存为笔记，再在笔记页导出；公开 0.8.0 的原入口保持原版本行为。
- 阅读页标题下方显示本机最后修改时间，例如 `2026-11-03 18:21`。标签在其右侧，空间不足时换到下一行。点击标签可筛选左栏，再点同一标签，或点搜索框下「标签：… ×」即可取消；搜索词、笔记本和排序保持原选择。
- 左栏排序默认为「最近修改在前」，也可按创建时间或标题升降序排列，重新打开会记住选择。「回收站」在左栏底部。阅读页右上角的垃圾桶图标，悬停会显示「移到回收站」；点击后先展开确认，可取消或点「确认移入」。移入后可立即撤销，也可以日后从回收站打开并恢复。
- 点「导出」在弹窗中选择 Markdown、PDF 或图片。「包含标签」「包含摘要」独立控制输出，默认包含笔记已有的字段。顺序为标题、最后修改时间、标签、摘要、正文；未勾选的字段也不会出现在 Markdown 文件头。点取消、右上角关闭或按 Esc 即可退出；生成中可点「取消生成」中止。图片、PDF、Markdown 和原图发起下载后自动关闭，并短暂提示「已开始下载」，最终文件请在浏览器或系统下载位置核对；失败时保留弹窗和参数，可调整后重试。纯文本 Markdown 可直接下载。图文推荐标题命名的 ZIP，解压后包含同名 Markdown 与 `assets/`。图片可选当前阅读宽度、默认宽度（740 px）或预设宽度，背景跟随当前主题；从列表导出尚未显示的笔记时使用默认宽度，不显示「当前阅读宽度」；外围额外留 24px。1×/2× 保持排版一致，仅改变像素密度。表格太宽时请增加正文宽度。图片只输出一张 PNG；超限时可降低清晰度、减少所选图片或原始素材，或改用 PDF / Markdown，不会自动截断。PDF 保留原来的文档排版，不作为阅读截图。原始会话素材只有手动勾选时才加入导出。
- 已绑定后可以断网编辑、转存和保存。编辑时「草稿已保存到本机」表示本次草稿已落盘；顶部「已保存」表示正式版本已保存在本机、尚待同步；只有实际同步时转圈，绿色对号「已同步」表示本机修改已同步到云端。网络失败时显示简短重试提示，本机编辑仍保留，恢复网络后会自动同步。悬停或点击状态即可查看提示和重试，不会离开文章；鼠标移出提示区域或按 Esc 即收起。只有需处理账号等问题时才提供进入设置的按钮。
- 前台打开笔记库时，每 5 分钟检查其他设备的更新。自动和手动同步都包含上传与拉取。换设备前可查看「已同步」，也可在「设置 → 同步与存储」点「立即同步」；该页会实时显示进度和上次成功时间，不会一直显示首次完成通知。出现分歧时保留带冲突版本后缀的独立笔记，可分别处置。

编辑保存规则：编辑期间自动保存本机草稿，不会把每次输入都放进历史版本或上传。点击「完成编辑」、切换笔记或离开笔记界面时统一保存正式版本并同步；临时切换应用或选择文件仍保留编辑态。点击「取消」并确认，丢弃本次草稿，原笔记不变；新建草稿直接丢弃，不进回收站。意外退出后，下次打开自动完成已落盘的草稿并显示最新正文。若网络未连通，先保存在本机，联网后继续同步。

侧栏的「工作区笔记本」名称右侧可新建笔记；点齿轮可改名、更换或解除关联，点下载图标导出该本。窄侧栏只显示笔记列表，点本名弹出笔记本选择器，选择后自动收起。

## 笔记本管理

首次初始化会创建「默认笔记本」。在「全部笔记」中新建，以及保存会话时没有另选位置，笔记会进入默认本；在某本笔记本内新建则放在当前本。旧的未分类笔记会自动归入默认本，正文和原始素材保留。

在顶栏进入「分类管理 → 笔记本」即可查看各本的笔记数量。点击右上方「新建笔记本」、行末铅笔或星形按钮进行新建、改名和设为默认。新建与改名在页面内完成。默认本旁有「默认」标记，设置会同步到其他设备。更换默认本不会自动搬动其他笔记；当前默认本不能直接移除。

点击某本的名称，会回到笔记库并显示该本内容，同时清除之前的搜索和标签筛选。只切换顶部选项卡再返回，则保留原筛选和阅读位置；编辑中的内容会自动保存，返回后以阅读态显示。左栏下拉框仍可快速筛选，其中「管理笔记本…」也会进入此页面。

点击普通笔记本的垃圾桶图标后，在确认弹窗中选择：

- **保留笔记，移入默认笔记本**：推荐选项，只移除原笔记本。
- **将笔记一起移入回收站**：核对名称及笔记数量后，再点击醒目的确认按钮。之后可在左栏回收站恢复，笔记回到默认本。

点击取消、右上角关闭或按 Esc 均不执行移除。旧运行版本不支持新增加的默认设置；多端使用时请将参与同步的插件一并升级。

## 标签管理

进入「分类管理 → 标签」，也可从主界面「筛选笔记 → 管理标签…」进入。左侧按名称查找标签，中间可按笔记本或关键词收窄关联笔记，点选后在右侧读全文。两处分隔线可以拖动，长列表可继续加载。

- **改名**　选中标签，点「改名」并输入新名称。要改成库里已有的标签名时，先核对合并的影响。
- **合并**　选中来源标签，点「合并」，在左侧找到要保留的标签。出现「核对近似名称…」时，可以从建议里开始比对。核对来源与保留方向，切换两组关联笔记看全文和本篇标签变化。已同时带有两枚标签的笔记，合并后只留保留标签。
- **移除标签**　先核对全库影响，再确认移除这枚标签。笔记、正文及其他标签都会保留。

操作区的影响统计以全库为准。中间列表的筛选只改变当前查看范围。确认后会生成新笔记版本。

## 导入、整库导出与附件

1. 点击笔记列表底部「导入 / 导出」，选择 Markdown 文件、文件夹或 ZIP。有图片、附件时推荐选择整个来源文件夹或 ZIP，以便找到相对路径文件。
2. 查看预览和提示，选择目标笔记本，或勾选按一级目录建立笔记本。网络图片只有勾选归档后才下载；失败的引用会保留并出现在报告里。确认后逐篇新增，原有笔记和来源文件保持不变。
3. 导入中可以停止，已完成的笔记保留。未取消的同一批次重试会跳过已完成项；取消后需重新选择文件，再导入同一份资料会新增另一份，请只选择尚未完成的笔记，不是覆盖更新。支持常见 Obsidian 图片和笔记链接，不承诺迁移它的插件、白板、数据库或全部属性。
4. 「导出笔记库」选择全部笔记或某个笔记本，生成 Markdown ZIP。解压后，可以在 Obsidian 里将解压目录作为一个新库打开；图片、附件和已导出文章之间的链接使用相对路径。不要用 Obsidian 打开肥鱼笔记内部的同步资料夹共同编辑。

编辑工具栏的回形针可添加 PDF、音频、视频或其他文件，正文内插入附件链接，阅读页底部也会显示文件卡片。点击「下载 / 另存」由浏览器或系统下载设置决定保存位置；插件不预览或播放这些文件。

普通文件超过 50 MiB 时确认提醒，超过 100 MiB 拒绝；图片在 20 MiB 且 3200 万像素以内可内嵌，超出则按普通附件保留原图。每篇最多 128 张图片和 128 个普通附件；单次导入最多 10,000 个条目、5,000 篇笔记。取消旧的批次 200 MiB 和整库 512 MiB 封顶。较大导入由后台工作线程处理，显示进度、可取消，也可收起后继续会话；关闭运行窗口则停止后续工作，已经保存的笔记保留。

PDF 和单张 PNG 直接下载，不附带原件。文件在正文中显示为标签或补充卡片，不播放或预览。需要附件原件时选择 Markdown 资源包。高密度图片的 PDF/图片转换仍有内存保护，遇到提示可减少所选图片或改用 Markdown ZIP，原图保存规则不变。设置页可查看当前文件与 Git 历史占用，约 1 GiB / 5 GiB 提醒不会停止保存。反复替换大文件会增加 Git 历史和同步时间。

在编辑器点击「链接 → 链接到笔记」，搜索并选择另一篇文章，然后应用链接。阅读时点链接跳转，点「返回上一篇」回到原文；目标改名或换笔记本不影响链接。

## 多选和清空回收站

点击列表上方「多选」勾选文章，也可「全选筛选结果」。普通笔记确认后移入回收站，并提供撤销。在回收站可选一篇或多篇彻底删除；「清空回收站」针对所有回收站笔记，即使正在搜索筛选也一样，确认框会显示实际数量。

彻底删除不可撤销，会删除笔记的正文、修订和独有文件；其他笔记仍引用的图片与附件会保留。**Git 历史里的旧内容不会随之清除，仓库体积也不一定立刻变小。** 本功能不是敏感资料的安全擦除工具。

新格式要求使用同一私库的肥鱼笔记实例一并升级；不要将旧插件连接已经写入新格式的资料。

## 工作区笔记本设置与取消操作

同一笔记库中新建或改名不能与其他在用笔记本重名，首尾空格和英文大小写不作区分。若工作区名称已经被使用，新建时会留空名称并提示：可以“选用其他笔记本”复用已有的，也可以填写不同名称。提示出现在输入处，无需关闭额外弹窗。

按文件夹导入时，同名的来源目录会创建带“（导入）”及必要序号的新本，并在导入报告说明，不把资料直接并入已有本。

在会话侧栏「工作区笔记本」点击齿轮。点击名称旁的铅笔可原地改名；「选用其他笔记本」「新建笔记本」会展开相应字段。字段旁 ✓ 确认、× 放弃，悬停可查看操作名称。Esc 先退出当前操作，再按才关闭弹窗；已用 ✓ 保存的改名不会被后续取消操作撤回。

从侧栏新建笔记后取消，会返回原选项卡、笔记本、搜索条件与滚动位置。有输入时先确认放弃，空白直接返回；取消已有笔记的编辑则回到原文阅读态。

## 备份与恢复

- 换设备或本机资料丢失：安装插件，登录同一个 GitHub 账号，选择「连接已有笔记库」，使用新的空目录完成首次同步。只会恢复已经上传的内容，包括笔记、回收站、原始素材和归档图片。
- 离线期间的重要内容：先关闭 DSH，复制完整笔记资料夹及上述控制目录到另一个备份位置。尚未看到绿色「已同步」时，远端可能还没有最后的修改。本机保存失败时先重试，不要清理宿主浏览器资料；其中可能保留最后的恢复记录。
- 使用本机完整备份恢复原设备：关闭 DSH，先保留当前目录，再把备份放回原来的路径后启动。控制目录记录了本机路径；需要换位置时，恢复成功后使用「更换本机位置」。不要只恢复 `documents/` 而遗漏修订与附件。
- 偶发冲突会留下带版本备注的两篇笔记。先分别阅读，再手动保留、合并内容或移入回收站。

## 限制与问题反馈

首次使用需要联网完成私库接入。已绑定后可离线编辑，AI 元信息建议仍需 DSH 模型可用。只同步插件数据，DSH 登录凭据不进入笔记仓库。私有仓库访问权限由 GitHub 账号管理，导出文件由使用者自行保管。

异常退出后，下一次同步会检查遗留锁所属进程；确认进程已经退出时自动恢复。若仍提示目录被占用，先关闭使用同一资料夹的其他 DSH 实例，再重试。锁内容损坏或进程状态无法确认时会保留资料并停止同步；若仍失败，请保留错误截图联系维护者核对。不要为了清理锁停止无关应用，也不要在 DSH 运行中自行删除锁或 Git 缓存。

当前 Windows 已有实测记录，macOS 待验证。同机两个隔离实例可验证同步逻辑，两台物理电脑之间的长期使用仍需用户反馈。引用笔记时会向会话输入框加入读取提示词。你可以在发送前检查和补充内容。超长图可降低清晰度、减少所选图片或原始素材，或改用 PDF / Markdown；缺失图片或不完整会话会在导出前提示。

从主界面或独立窗口进入 **「设置 → 帮助」** 点击「问题与建议」；首次初始化页与宿主内的独立插件设置页也提供该入口。它会打开 GitHub 新建反馈页面，编辑草稿会保存，临时切换窗口后仍可继续编辑。若网页尚未登录 GitHub，请先登录，再填写标题、问题或建议，最后提交。也可直接使用[项目 Issues](https://github.com/StarWind97/dsh-fatfish-notes/issues)。

遇到问题，请提供插件与 DSH 版本、系统版本、操作步骤、预期与实际结果，以及遮去私人内容的截图。反馈会公开显示，请不要发送令牌、登录配置、完整私人会话或整个笔记资料夹。

开发机的隔离体验入口见[开发入口](README.md#本机隔离体验)。


## 在会话侧栏使用笔记

1. 在会话顶部点击「会话笔记」，使用 DSH 右侧面板阅读笔记；正文支持原地编辑和自动保存，完整笔记窗口仍可另行打开。
2. 从当前会话转存的笔记自动列在「关联的笔记」中，条目标记「从本会话保存」。也可手动关联库里的其他笔记。一篇可以关联多个会话。解除手动关联只改变当前会话的手动关系，并可撤销。笔记仍在原笔记本，转存来源也会保留。
3. 保存会话时可选任意已有笔记本。有工作区时可新建或指定该工作区的默认本，下次预选；偶尔改选不改变默认。未分组会话可新建普通本，不建立会话对应关系。笔记之后仍可换本。
4. 保存选项会列出所选消息的图片、上传文件和本轮 AI 正式交付文件，可逐项取舍。仅在正文里提到的路径不会被扫描或复制。如果 AI 后来修改过交付文件，这次保存的是修改后的版本；保存后原件再变，不影响笔记副本。
5. 同一会话侧栏打开时，新保存的笔记会立即在侧栏显示，可继续编辑；不会抢开已关闭的侧栏，也不会覆盖已经切换到另一会话的内容。
6. 阅读时点击编辑左侧的「引用」，或在侧栏列表点击引用图标、右键选择「引用到当前会话」。全文和正文中的图片、文件一起提供，仅补充附件可取消。确认后点击「加入输入框」，检查提示词、补充自己的要求并发送；不会自动发送，也不会显示为原生附件栏项目。
7. 列表的「多选」可以跨笔记本或搜索继续选择；「查看已选」可移除个别笔记，随后统一引用。也可以先引用一篇，再引用其他一篇或多篇，原输入和附件保留。退出多选会清空临时选择；引用不会自动建立会话关联。
8. 同版笔记已经在当前未发送输入中时，会提示「已加入」，避免重复堆积。发送后、手动移除后仍可再次引用。支持输入框原生撤销；准备中可取消，笔记已变化时先重新检查内容和附件。

工作区默认关系只保存在本机，并按私人仓库区分；手动会话关联随笔记同步。另一台电脑没有对应会话时，笔记本身仍可正常阅读。主页面、独立窗口和会话侧栏共用同篇编辑保护。

「查找笔记」初次从「全部笔记」开始。可以先搜索再选择笔记本、标签、时间或附件，也可以先限定笔记本。宽侧栏直接显示笔记本列，两列之间可以拖动调宽。窄侧栏点笔记本名称展开列表。打开正文后，点左上角返回，或用标签栏末尾的「+」打开「笔记列表」，继续刚才的查找。关联按钮位于条目右侧，操作后不重新排队。

设置了工作区默认本后，侧栏多一个「工作区笔记本」页，显示实际书名，点齿轮可改名、更换或解除关联。尚未设置时，「关联的笔记」右端的小图标可以选择已有本或新建，建议名为工作区名；这不是必填设置。「查找笔记」的笔记本列底部也能普通新建，按需勾选用于当前工作区。工作区改名不自动改书名；移除工作区不删除笔记本、笔记或附件。会话归档/恢复不解除关联。

侧栏顶部的新建笔记图标可直接开始写，第一次保存自动关联当前会话，默认归属工作区笔记本，没有时放进全局默认本；编辑时可更换。空白退出不会留下空笔记。「关联的笔记」和「工作区笔记本」可直接滚动浏览。

转存条的「下一步」、已选数量和空白区域都会打开保存选项。可以从「整个会话」开始减选消息和图片、文件，保存时按实际选区归档。已有会话标题会预填，也可手改。选好目标笔记本后点「保存到笔记」，随后可在笔记的「正文」和「原始素材」之间切换。Esc、右上角关闭和返回会话都保留勾选。底部转存条的「取消」结束选择。笔记本可在侧栏或主页面管理。

「AI 建议」根据所选消息的文字生成并填入标题、单段摘要和标签。使用宿主模型额度，可以停止生成，再手动填写或修改建议。标题必填，摘要和标签选填。「本机已保存」约 5 秒收起，撤销提示约 8 秒收起，鼠标或键盘停留时暂停。错误和待确认结果会保留。主界面及侧栏条目可用省略号或右键打开操作菜单，危险操作仍需确认。

阅读或编辑正文时，底部可以查看字数及快捷键说明。统计中文逐字、英文按词，排除 Markdown 标记和图片地址，包含代码文字；标题、标签和摘要另存，不计入正文统计。代码块配有独立顶栏，右上角复制按钮会保留代码缩进和换行，点击后显示高对比度「✓ 已复制」胶囊，阅读与编辑预览都可使用。

阅读区支持 Home、End、Page Up、Page Down，点击正文后即可使用；在输入框、编辑器、菜单和弹窗中按对应控件的原有规则操作。反向引用零条隐藏，有引用默认展开且收起仍显示数量；补充附件与引用区域使用独立底色区分正文。主页面、独立窗口与会话侧栏遵循同一规则。

阅读区域获得焦点时，可用 Ctrl+Tab / Ctrl+Shift+Tab 在本次打开的笔记之间切换（DSH 宿主输入路径已验证）。普通浏览器可能将组合键保留给浏览器标签；此时使用笔记标签和尾部下拉菜单。插件不接管 Ctrl+W，关闭笔记可用标签关闭按钮或右键菜单。
